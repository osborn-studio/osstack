# Implementation Plan

## Current Phases

1. Distribution: npm install smoke, launchd install, release workflow.
2. Evidence: report, scorecard, proof pack, checksums, redaction.
3. Product entry: `osstack deliver`.
4. Governed run: spec, governance verifier, PR body.
5. Learning control plane: lessons, Knowledge Cloud, agent scorecards.
6. Product surface: cockpit, examples, guide, i18n, checkpoint.
7. Trust: compliance packs, proof views, private/team knowledge.

## Execution Rule

Each slice should land with:

- focused tests
- typecheck/build verification
- no unrelated refactor
- proof that existing CLI behavior still works
