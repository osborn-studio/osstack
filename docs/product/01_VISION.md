# Vision

osstack is the local-first AI software development control plane. It coordinates multiple coding agents, keeps a durable loop running, verifies work, records evidence, and turns each run into an auditable delivery artifact.

## North Star

Make AI coding work behave like an engineering team:

```text
intent/task queue -> routing policy -> loop runtime -> verification -> proof -> cockpit/report/PR
```

## Product Promise

- Pick the right agent for the job.
- Run changes through a repeatable loop.
- Keep unsafe or unverifiable work visible.
- Preserve evidence for engineers, managers, auditors, and customers.
- Learn from failures through local lessons and Knowledge Cloud.

## Non-Goals

- osstack is not a replacement for every coding agent.
- osstack does not claim SOC 2, ISO 27001, EU AI Act, or third-party certification.
- osstack does not mirror external knowledge bases without transformation and provenance.
