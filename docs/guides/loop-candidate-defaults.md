# Native local Loop defaults

Local `osstack loop enqueue` and `osstack loop run` can read persistent preferences from `$OSSTACK_HOME/loop-defaults/config.json`. This feature supplies ordinary existing flags to the original CLI parsers, adapters, policy gate and lease. It does not activate candidate batching, CI reuse or a delivery workflow. Nothing installs the file automatically; the Wiki runtime remains unchanged.

Use a private user-owned dedicated directory (0700), direct regular single-link file (0600), and the strict schema below. Native home aliases are resolved and the directory/file identities are rechecked; a symlink for the dedicated directory or file is refused. A missing config uses legacy behavior. An existing unsafe directory, malformed/unknown schema or permission error fails before lease acquisition. Default numeric/schema validation also occurs there. Downstream command, source, reviewer and profile semantics are validated by the original route; some checks occur inside its existing leased try/finally. Disabled files still undergo the same validation. Present configuration currently requires native POSIX uid/mode and no-follow support; unsupported platforms refuse rather than guessing ACL ownership. No secrets are discovered or recorded.

```json
{"schemaVersion":1,"enabled":true,"run":[{"flag":"--source","value":"task_queue"},{"flag":"--verify","value":"pnpm test"},{"flag":"--max-iter","value":"1"}],"enqueue":[{"flag":"--capability","value":"code.write"},{"flag":"--priority","value":"50"}]}
```

Scalar run defaults support execute, agent, profile, max-iter, command-timeout-ms, discovery-policy, max-runtime-ms, max-tokens, max-cost-usd and no-progress-limit. Repeated defaults support verify, reviewer, checker, target-path, forbid-path, role and source. Boolean entries (flag only) support worktree, artifact-verification and auto-agent. Enqueue supports capability and priority only. Arrays are limited to 64 entries; the complete file to 64 KiB. Duplicate scalars, conflicting default execution selectors (execute cannot coexist with agent, auto-agent, profile or role; profile plus role is allowed), unknown flags/fields, empty values and values starting with `--` reject. This prevents a persisted value being treated as a control token by existing flat CLI scans. Ordinary command strings such as `node script.mjs --option` remain single native values.

Explicit scalar options override the corresponding default; original explicit first-occurrence semantics remain. Verify/reviewer/checker and artifact path defaults are retained with explicit values. Explicit sources replace configured sources; any explicit execute/agent/auto-agent/profile/role selector suppresses the entire configured routing selection family. Mandatory verify/reviewer/checker defaults remain in the union. Boolean defaults have no invented negative flag: edit/disable preferences to remove one. The merger consumes explicit flag values for default lookup, using the enqueue-specific native positional-value list for enqueue. With an enabled config, a trailing recognized value flag refuses as LOOP_DEFAULTS_INVALID; absent/disabled config preserves the original parser error. Explicit CLI retains its original parser behavior, including flat control-flag scans; this feature does not fix the global parser. Raw explicit `--daemon`/`--help` tokens preserve the original bypass route even when another flag consumed them as its value.

Commands and profile values retain original CLI semantics. Budget values are overridable defaults and core budgets detect usage after a run; this is not a spending cap or a measured savings claim. Preferences are not a permission system. Choosing another OSSTACK_HOME changes preference selection.

Defaults do not apply to help, daemon/background execution, start/status/doctor or guarded/autonomy delivery, including run with a first raw --autonomy value other than legacy. Those paths retain existing behavior. This slice does not complete cost-control scope2/3, install a release, invoke GitHub, merge a PR, or establish acceptance.
