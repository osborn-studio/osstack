# Supervision lifecycle R1 integration notes

- `SupervisionService.requestScan(reason?: string): Promise<void>` is the public dirty signal. It coalesces callers into one logical pass and any requested following pass. Call only after source transactions commit. Fire-and-forget callers must catch `supervision_stopped`; shutdown is terminal.
- `start()` is idempotent while active; `stop()` is idempotent and terminal. A later `start()` throws `supervision_stopped`.
- Await `supervision.stop()` before SQLite close on successful daemon shutdown and every failed-start cleanup path. It joins active scan, direct `attention.loop` logical reads, and the existing bounded notification drain. It does not await uncooperative physical filesystem promises.
- Direct `attention.loop` and scans share one stable scope/kind/id/binding slot. Maximum 100 physical slots, including timed-out and explicitly released subjects; slots clear only when original IO actually settles. Logical deadlines default to 1 second; per-instance test override is 1–1000 ms.
- Registration occurs before IO, permitting explicit release during a read. Commit synchronously checks stop/epoch, owner generation, persisted binding/admission and release; stale results cannot resurrect a subject. A new daemon owner reobserves existing bindings conservatively. Capacity-limited subjects can regain a freed admission slot; explicit release stays released.
- Loop reader receives AbortSignal, checks it between filesystem awaits, and closes an opened descriptor in finally. This is cooperative cancellation, not proof of kernel IO cancellation. Late completion only disposes an in-memory slot and never accesses SQLite.
- Keep notification `drain` unchanged in this branch. If the integrator replaces it with `drainBatch` returning statistics, normalize to `Promise<void>` for `deliveryDone`; keep its bounded shutdown guarantee.
- The CI reader remains its existing standalone implementation; the service now checks terminal lifecycle after its lazy import. R1 does not claim a new CI cancellation protocol, run seq replay, or throughput/platform qualification.
