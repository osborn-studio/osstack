## Findings

**Confirmed P0: 0. Confirmed P1: 3.** I did not run tests; this review is from reading the source.

### P1-1: Pre-send failures become `delivery_unknown` with no exit (code defect)

- **Trace:** `dispatch` consumes the grant and commits `started`. `sendOnce` then fails before any POST, for example:
  - `/user` times out or returns 503.
  - `issue.url` does not match `targetUrl`. A config owner of `OSBORN` against GitHub's canonical `osborn` triggers this.
  - `options.credential` throws `delivery_host_config_changed` after a config edit.
  - The POST itself returns a definitive 403 (locked issue) or 422.

  `boundedCall` returns `{ok:false}`, and `dispatch` writes `delivery_unknown / send_outcome_unknown`. `reconcile` then calls `lookup`, which fails the same preflight or finds no comment, so it returns `lookup_unconfirmed`. `revoke` keeps the state `delivery_unknown`, `prepare` for that obligation throws `delivery_unresolved_attempt`, and `authorize` requires `prepared`. No transition reaches `definitely_not_sent`. An operator-initiated config change therefore converts every in-window authorized attempt into a permanent wedge for a message that was never sent.
- **Fix:** Make `sendOnce` return a typed outcome. Set a flag immediately before the POST is issued. Failures before the flag, and definitive HTTP rejections, map to `not_sent`, which `dispatch` records as `definitely_not_sent`. Only failures after the flag map to `delivery_unknown`.
- **Tests to add:** preflight 503 leads to `definitely_not_sent`; POST 403 leads to `definitely_not_sent`; config revoked before POST leads to `definitely_not_sent`; timeout during `/user` leads to `definitely_not_sent`.

### P1-2: A third party can wedge reconciliation of a delivered attempt (code defect)

- **Trace:** The real comment C1 is posted by the actor and carries `osstack-delivery:A:...`. C1 is public. Any GitHub user then posts C2 on the issue containing `osstack-delivery:A:`. In `lookup`, C1 matches and sets `found`. C2 also passes the substring test, so `receipt(e, C2)` throws `github_delivery_receipt_mismatch` because `user.node_id` is not the actor. `lookup` throws, `reconcile` records `lookup_unconfirmed`, and this repeats on every call.
- **Fix:** In `lookup`, check author and `issue_url` before deciding anything. Skip comments not authored by the actor on this issue, and count only actor-authored comments toward `found` and duplicate detection. An actor-authored marker comment with a different body should still fail closed.
- **Test to add:** a foreign marker comment must not block a correct delivered receipt.

### P1-3: Reconciliation cannot see comments beyond the first 500 (code defect)

- **Trace:** GitHub issue comments list in ascending order by default, so the new comment sits at the end. With 600 comments on the issue, pages 1 to 5 never include the target comment. The loop exits and throws `github_delivery_lookup_incomplete` on every attempt, so the attempt stays unknown forever. Separately, a page of 100 long comments can exceed the 1 MiB cap, which triggers `oversized`, then `unconfirmed`, then the same wedge.
- **Fix:** Add `since` set to the attempt's `created_at_ms` minus a skew margin, or start from the `rel="last"` page. Also reduce `per_page` or size the cap for the maximum comment length (65,536 characters × 100).
- **Test to add:** a fixture with more than 500 comments, with the target comment last.
- **Live check needed:** confirm the ordering and `since` semantics against GitHub.

## Checked, no confirmed P0/P1

- **Duplicate POST:** `dispatch` claims atomically and consumes the grant in one transaction, `started` is not re-sent, and no path re-POSTs. Clean.
- **Wrong author or target receipt:** `receipt()` checks author node, `issue_url`, and exact body. The actor and target node IDs are checked in preflight. The core receipt is an echo of expected envelope fields, not observed provider data. That is an audit limitation (P2), not an acceptance bug.
- **Grant replay, stale grants, changed registry:** Grants are bound to attempt, envelope digest, destination digest, body hash, and account. Verification checks key purpose, repo, provider, and destination scope. Expiry is checked at claim time. Revocation effectively works because `credential()` checks the config fingerprint, though only through the P1-1 misclassification path. Trusted keys and targets are load-time snapshots; a restart is needed to re-enable delivery.
- **Caller authority:** Sends require a signed grant. `prepare`, `revoke`, and `authorize` are open to any RPC client, so they allow availability abuse only (P2).
- **Token leakage:** Tokens appear only in the Authorization header. Errors are generic. Redirects are not followed. No fixed-host bypass is found.
- **Unbounded network:** `boundedCall` caps each operation at 30 s. The transport itself has no total deadline, only a 5 s idle timeout (P2).
- **Fixture leakage:** The fixture base URL is rejected unless `test_only`, and the config loader cannot pass one. Clean.
- **Issuer approval:** The grant body is recomputed from the envelope, and hashes are verified. Config fingerprint and attempt state are rechecked after approval. Clean.

## Lower-priority items (P2)

- A successful POST whose attempt was revoked or reconciled mid-flight has its receipt discarded (`current.state !== "started"`). The ledger stays `delivery_unknown` until the next reconcile recovers it.
- Reconcile can convert an in-flight `started` attempt to `delivery_unknown` while the POST is still running.
- Test `noninteractive` depends on the TTY state of the test process and could block for 60 s locally.
- The approval phrase is printed by the same process that renders the preview, so it is a typing gate, not an independent check.
- When root wires the loader and issuer, `@osstack/core` and zod should be lazily imported, per the startup budget rule. The `confirm` seam must not be reachable from CLI or RPC wiring.
- A TOCTOU window exists between the second credential check and the POST. This is inherent without locking.

## Needs live qualification (not code defects)

- Whether GitHub normalizes comment bodies (CRLF or trailing whitespace). Exact-match verification would then produce permanent unknowns.
- The ordering and `since` behavior of issue comment listing.
- Whether a 403 from locked issues or secondary rate limits can be classified as definitely not sent.

export function createGithubDeliveryTransport(options: GithubDeliveryTransportOptions): FollowUpTransport {
  const base = options.fixtureBaseUrl ? new URL(options.fixtureBaseUrl) : new URL("https://api.github.com");
  if (
    options.fixtureBaseUrl &&
    (options.qualification !== "test_only" ||
      base.protocol !== "http:" ||
      base.hostname !== "127.0.0.1" ||
      base.username ||
      base.password ||
      base.pathname !== "/" ||
      base.search ||
      base.hash)
  )
    throw Error("invalid_delivery_fixture");
  const api = async (
    path: string,
    token: string,
    signal: AbortSignal,
    body?: string,
  ): Promise<JsonResponse> => {
    if (signal.aborted || !/^[\x21-\x7e]{1,4096}$/.test(token)) throw Error("github_delivery_unavailable");
    const url = new URL(path, base);
    return new Promise((resolve, reject) => {
      const fail = () => reject(Error("github_delivery_unconfirmed"));
      const request = (base.protocol === "https:" ? httpsRequest : httpRequest)(
        url,
        {
          method: body === undefined ? "GET" : "POST",
          signal,
          headers: {
            authorization: `Bearer ${token}`,
            accept: "application/vnd.github+json",
            "x-github-api-version": "2026-03-10",
            "user-agent": "osstack-follow-up-delivery",
            ...(body === undefined
              ? {}
              : {
                  "content-type": "application/json",
                  "content-length": Buffer.byteLength(body),
                }),
          },
        },
        (response) => {
          const chunks: Buffer[] = [];
          let bytes = 0;
          response.on("data", (chunk: Buffer) => {
            bytes += chunk.length;
            if (bytes > 4_194_304) {
              response.destroy();
              request.destroy();
              fail();
            } else chunks.push(chunk);
          });
          response.on("error", fail);
          response.on("end", () => {
            try {
              if (response.statusCode !== (body === undefined ? 200 : 201)) throw Error();
              const requestId = response.headers["x-github-request-id"];
              if (typeof requestId !== "string" || !/^[\x21-\x7e]{1,256}$/.test(requestId)) throw Error();
              resolve({
                value: JSON.parse(new TextDecoder("utf-8", { fatal: true }).decode(Buffer.concat(chunks))),
                requestId,
                hasNext: /rel="next"/.test(String(response.headers.link ?? "")),
              });
            } catch {
              fail();
            }
          });
        },
      );
      request.on("error", fail);
      request.setTimeout(5000, () => request.destroy(Error("github_delivery_timeout")));
      request.end(body);
    });
  };
  function record(value: unknown): Record<string, unknown> {
    if (!value || typeof value !== "object" || Array.isArray(value))
      throw Error("github_delivery_invalid_response");
    return value as Record<string, unknown>;
  }
  const targetPath = (e: FollowUpDeliveryEnvelope) =>
    `/repos/${encodeURIComponent(e.destination.owner)}/${encodeURIComponent(e.destination.repository)}/issues/${e.destination.issue_number}`;
  const targetUrl = (e: FollowUpDeliveryEnvelope) => `https://api.github.com${targetPath(e)}`;
  async function preflight(e: FollowUpDeliveryEnvelope, signal: AbortSignal): Promise<string> {
    if (
      e.destination.host !== "github.com" ||
      e.destination.provider_id !== "github_comment" ||
      sha(e.body) !== e.body_sha256
    )
      throw Error("github_delivery_invalid_envelope");
    const token = await options.credential(e);
    const actor = record((await api("/user", token, signal)).value);
    if (actor.node_id !== e.destination.actor_node_id) throw Error("github_delivery_actor_mismatch");
    const issue = record((await api(targetPath(e), token, signal)).value);
    if (
      issue.node_id !== e.destination.target_node_id ||
      issue.url !== targetUrl(e) ||
      issue.number !== e.destination.issue_number
    )
      throw Error("github_delivery_target_mismatch");
    return token;
  }
  function receipt(e: FollowUpDeliveryEnvelope, value: unknown, requestId: string): FollowUpDeliveryReceipt {
    const comment = record(value),
      user = record(comment.user);
    if (
      !Number.isSafeInteger(comment.id) ||
      Number(comment.id) < 1 ||
      comment.issue_url !== targetUrl(e) ||
      user.node_id !== e.destination.actor_node_id ||
      comment.body !== githubDeliveryBody(e)
    )
      throw Error("github_delivery_receipt_mismatch");
    return {
      provider_id: "github_comment",
      account_id: e.destination.account_id,
      target_node_id: e.destination.target_node_id,
      author_node_id: e.destination.actor_node_id,
      destination_digest: e.destination_digest,
      body_sha256: e.body_sha256,
      attempt_id: e.attempt_id,
      provider_message_id: String(comment.id),
      provider_request_id: requestId,
    };
  }
  return {
    qualification: options.qualification,
    automatic_retries: false,
    lookup_receipt: true,
    async preflight(e, signal) {
      await preflight(e, signal);
    },
    async sendOnce(e, signal) {
      const token = await preflight(e, signal);
      // Revocation or credential rotation during preflight closes admission before the sole POST.
      if ((await options.credential(e)) !== token || signal.aborted)
        throw Error("github_delivery_registration_changed");
      // Once durably started, all exceptions remain unknown; never infer non-delivery from HTTP errors.
      const response = await api(
        `${targetPath(e)}/comments`,
        token,
        signal,
        JSON.stringify({ body: githubDeliveryBody(e) }),
      );
      return receipt(e, response.value, response.requestId);
    },
    async lookup(e, signal, context) {
      const token = await preflight(e, signal);
      let found: FollowUpDeliveryReceipt | undefined;
      // Old busy threads do not hide a new attempt behind historical pages. Context comes from the durable ledger.
      const since =
        context && Number.isSafeInteger(context.createdAtMs) && context.createdAtMs >= 0
          ? `&since=${encodeURIComponent(new Date(Math.max(0, context.createdAtMs - 300000)).toISOString())}`
          : "";
      // Fixed bounded pages, never follow a provider-supplied URL. Incomplete enumeration remains unknown.
      for (let page = 1; page <= 20; page++) {
        const response = await api(
          `${targetPath(e)}/comments?per_page=10&page=${page}${since}`,
          token,
          signal,
        );
        if (!Array.isArray(response.value) || response.value.length > 10)
          throw Error("github_delivery_invalid_list");
        for (const raw of response.value) {
          const comment = record(raw);
          // A public marker copied by another author is not a candidate receipt and cannot veto one.
          if (
            !comment.user ||
            typeof comment.user !== "object" ||
            Array.isArray(comment.user) ||
            (comment.user as Record<string, unknown>).node_id !== e.destination.actor_node_id ||
            comment.issue_url !== targetUrl(e)
          )
            continue;
          if (typeof comment.body !== "string" || !comment.body.includes(`osstack-delivery:${e.attempt_id}:`))
            continue;
          const match = receipt(e, raw, response.requestId);
          if (found) throw Error("github_delivery_duplicate_correlation");
          found = match;
        }
        if (!response.hasNext && response.value.length < 10) {
          if ((await options.credential(e)) !== token || signal.aborted)
            throw Error("github_delivery_registration_changed");
          return found ?? null;
        }
      }
      throw Error("github_delivery_lookup_incomplete");
    },
  };
}

function inside(root: string, path: string): boolean {
  const rel = relative(root, path);
  return rel === "" || (!isAbsolute(rel) && rel !== ".." && !rel.startsWith(`..${sep}`));

/** Ancestors cannot let another uid replace the private home. Sticky root-owned tmp is allowed. */
function privateAncestors(path: string): void {
  const uid = process.getuid?.();
  if (
    uid === undefined ||
    !isAbsolute(path) ||
    resolve(path) !== path ||
    realpathSync(dirname(path)) !== dirname(path)
  )
    throw Error("delivery_host_config_invalid");
  for (let current = dirname(path); ; current = dirname(current)) {
    const entry = lstatSync(current);
    const privateParent = current === dirname(path);
    const stickyRoot = entry.uid === 0 && (entry.mode & 0o1000) !== 0;
    if (
      !entry.isDirectory() ||
      entry.isSymbolicLink() ||
      (entry.uid !== 0 && entry.uid !== uid) ||
      (privateParent
        ? entry.uid !== uid || (entry.mode & 0o077) !== 0
        : (entry.mode & 0o022) !== 0 && !stickyRoot)
    )
      throw Error("delivery_host_config_invalid");
    if (dirname(current) === current) break;
  }
}
/** Bounded synchronous fence needed immediately before a grant is persisted or consumed. */
function assertRegistryFingerprint(path: string, fingerprint: string): void {
  privateAncestors(path);
  const fd = openSync(path, constants.O_RDONLY | constants.O_NOFOLLOW | constants.O_NONBLOCK);
  try {
    const before = fstatSync(fd),
      bytes = Buffer.alloc(131073);
    let length = 0;
    if (
      !before.isFile() ||
      before.uid !== process.getuid?.() ||
      (before.mode & 0o077) !== 0 ||
      before.nlink !== 1 ||
      before.size > 131072
    )
      throw Error("delivery_host_config_invalid");
    while (length < bytes.length) {
      const n = readSync(fd, bytes, length, bytes.length - length, null);
      if (!n) break;
      length += n;
    }
    const after = fstatSync(fd),
      current = lstatSync(path);
    if (
      length > 131072 ||
      !current.isFile() ||
      current.isSymbolicLink() ||
      current.ino !== before.ino ||
      current.dev !== before.dev ||
      current.ctimeMs !== before.ctimeMs ||
      after.ctimeMs !== before.ctimeMs ||
      hash(bytes.subarray(0, length)) !== fingerprint
    )
      throw Error("delivery_host_config_changed");
    privateAncestors(path);
  } finally {
    closeSync(fd);
  }
}
/** Host private files: canonical directory, same uid, no symlinks, strict modes, finite reads and identity checks. */
export async function readPrivateDeliveryFile(path: string, maximum = 131072): Promise<Buffer> {
  privateAncestors(path);
  if (!isAbsolute(path) || resolve(path) !== path || (await realpath(dirname(path))) !== dirname(path))
    throw Error("delivery_host_config_invalid");
  const directory = await lstat(dirname(path));
  if (
    !directory.isDirectory() ||
    typeof process.getuid !== "function" ||
    directory.uid !== process.getuid() ||
    (directory.mode & 0o077) !== 0
  )
    throw Error("delivery_host_config_invalid");
  const file = await open(path, constants.O_RDONLY | constants.O_NOFOLLOW | constants.O_NONBLOCK);
  try {
    const before = await file.stat();
    if (
      !before.isFile() ||
      before.uid !== process.getuid() ||
      (before.mode & 0o077) !== 0 ||
      before.nlink !== 1 ||
      before.size > maximum
    )
      throw Error("delivery_host_config_invalid");
    const bytes = Buffer.alloc(maximum + 1);
    let length = 0;
    while (length < bytes.length) {
      const result = await file.read(bytes, length, bytes.length - length, null);
      if (!result.bytesRead) break;
      length += result.bytesRead;
    }
    const after = await file.stat(),
      current = await lstat(path);
    if (
      length > maximum ||
      !current.isFile() ||
      current.isSymbolicLink() ||
      before.dev !== current.dev ||
      before.ino !== current.ino ||
      before.ctimeMs !== current.ctimeMs ||
      before.mtimeMs !== current.mtimeMs ||
      before.size !== after.size ||
      before.ctimeMs !== after.ctimeMs ||
      (await realpath(dirname(path))) !== dirname(path)
    )
      throw Error("delivery_host_config_changed");
    privateAncestors(path);
    return bytes.subarray(0, length);
  } finally {
    await file.close();
  }
}

      (await realpath(dirname(output))) !== dirname(output) ||
      !directory.isDirectory() ||
      directory.uid !== process.getuid?.() ||
      (directory.mode & 0o077) !== 0

      throw Error();

      output,
      constants.O_WRONLY | constants.O_CREAT | constants.O_EXCL | constants.O_NOFOLLOW,
      0o600,
    );

      await file.writeFile(`${JSON.stringify(grant)}\n`);
      await file.sync();
    } finally {
      await file.close();
    }

    try {
      await parent.sync();
    } finally {
      await parent.close();
    }
    out(
      `${serializeFollowUpDelivery({ outcome: "grant_created_not_authorized", attempt_id: attempt.attempt_id, preview_sha256: digest, expires_at_ms: body.expires_at_ms, output })}\n`,
    );
    return 0;
  } catch {
    err("delivery_issuer_refused\n");
    return 1;
  }
}

export class FollowUpDeliveryService {
  private observedClock = 0;
  constructor(

  async handle(method: string, input: unknown): Promise<FollowUpDeliveryResult | FollowUpDeliveryListResult> {
    switch (method) {
      case "follow-up-delivery.prepare":
        return this.prepare(input);
      case "follow-up-delivery.list":
        return this.list(input);
      case "follow-up-delivery.inspect":
        return this.inspect(input);
      case "follow-up-delivery.authorize":
        return this.authorize(input);
      case "follow-up-delivery.revoke":
        return this.revoke(input);
      case "follow-up-delivery.dispatch":
        return this.dispatch(input);
      case "follow-up-delivery.reconcile":
        return this.reconcile(input);
      default:
        throw new FollowUpDeliveryError("delivery_unsupported_method");
    }
  }
  prepare(input: unknown): FollowUpDeliveryResult {
    const p = parsed(FollowUpDeliveryPrepareParams, input),
      repo = repoPath(p.repo_path),
      createDigest = hash({ ...p, repo_path: repo });
    return this.safe(() =>
      this.durableWrite(() => {
        const existing = this.db
          .prepare(
            "SELECT * FROM follow_up_delivery_attempts WHERE repo_path=? AND tenant='default' AND idempotency_key=?",
          )
          .get(repo, p.idempotency_key) as Row | undefined;
        if (existing) {
          if (existing.create_digest !== createDigest)
            throw new FollowUpDeliveryError("delivery_idempotency_conflict");
          return this.result(existing, "unchanged", true);
        }
        this.obligation(repo, p.obligation_id, p.expected_obligation_revision);
        if (
          this.db
            .prepare(
              "SELECT 1 FROM follow_up_delivery_attempts WHERE repo_path=? AND tenant='default' AND obligation_id=? AND state IN ('prepared','started','delivery_unknown')",
            )
            .get(repo, p.obligation_id)
        )
          throw new FollowUpDeliveryError("delivery_unresolved_attempt");
        const target = this.target(repo, p.destination_ref),
          now = this.clock(),
          attemptId = randomUUID();
        const payload = {
          repo_path: repo,
          default_tenant: true as const,
          attempt_id: attemptId,
          obligation_id: p.obligation_id,
          obligation_revision: p.expected_obligation_revision,
          destination: target,
          destination_digest: hash(target),
          body: p.body,
          body_sha256: bodyHash(p.body),
        };
        const envelope = FollowUpDeliveryEnvelope.parse({ ...payload, envelope_digest: hash(payload) });
        if (Buffer.byteLength(JSON.stringify(envelope)) > 49152)
          throw new FollowUpDeliveryError("delivery_response_too_large");
        this.db
          .prepare(
            "INSERT INTO follow_up_delivery_attempts(attempt_id,repo_path,tenant,obligation_id,obligation_revision,idempotency_key,create_digest,envelope_json,state,revision,created_at_ms,updated_at_ms,qualification) VALUES(?,?,'default',?,?,?,?,?,'prepared',1,?,?,'qualification_pending')",

            repo,
            p.obligation_id,
            p.expected_obligation_revision,
            p.idempotency_key,
            createDigest,

        this.reserveReceiptSpace(row);

        )

          ...rest,

          body_sha256: envelope.body_sha256,
        });

            schema_version: 1 as const,

  authorize(input: unknown): FollowUpDeliveryResult {

      this.durableWrite(() => {

            grant_id: p.grant.body.grant_id,
            key_id: p.grant.key_id,
          }),

        );
      }),
    );

      repo = storedRepoPath(p.repo_path);
    return this.safe(() =>
      this.durableWrite(() => {
        const row = this.row(repo, p.attempt_id);
        this.revision(row, p.expected_revision);
        if (["delivered", "definitely_not_sent"].includes(row.state))
          return this.result(row, "unchanged", true);
        const now = this.evidenceClock(row.updated_at_ms);
        this.db
          .prepare(
            "UPDATE follow_up_delivery_grants SET state='revoked',updated_at_ms=? WHERE attempt_id=? AND state='active'",
          )
          .run(now, row.attempt_id);
        return this.result(
          this.bump(
            row,
            row.state === "prepared" ? "definitely_not_sent" : "delivery_unknown",
            row.state === "prepared" ? "revoked_before_send" : "revoked_after_start",
            now,
            { reason: p.reason, timestamp_basis: "monotone_revocation_record" },
          ),
          "revoked",
        );
      }),
    );
  }
  async dispatch(input: unknown): Promise<FollowUpDeliveryResult> {
    const p = parsed(FollowUpDeliveryActionParams, input),
      repo = repoPath(p.repo_path);
    // A transient read-only provider preflight does not consume or wedge a still-prepared attempt.
    const admission = this.safe(() => this.durableWrite(() => {
      const row = this.row(repo, p.attempt_id);
      this.revision(row, p.expected_revision);
      if (row.state !== "prepared") return undefined;
      const envelope = this.envelope(row), transport = this.transport(envelope);
      if (!transport?.preflight) return undefined;
      const grant = this.grant(row.attempt_id);
      if (!grant) throw new FollowUpDeliveryError("delivery_authorization_required");
      if (grant.state !== "active") throw new FollowUpDeliveryError("delivery_authorization_revoked");
      this.options.assertHostConfiguration?.();
      this.verifyGrant(row, SignedFollowUpDeliveryGrant.parse(JSON.parse(grant.signed_json)), this.clock(row.updated_at_ms));
      return {envelope: frozen(envelope), transport};
    }));
    if (admission) {
      const readiness = await this.boundedCall(signal => admission.transport.preflight!(admission.envelope, signal));
      if (!readiness.ok) throw new FollowUpDeliveryError("delivery_destination_unavailable");
    }
    const claim = this.safe(() =>
      this.durableWrite(() => {
        const row = this.row(repo, p.attempt_id);
        this.revision(row, p.expected_revision);
        if (row.state !== "prepared")
          return {
            result: this.result(
              row,
              row.state === "started"
                ? "in_flight"
                : row.state === "delivery_unknown"
                  ? "delivery_unknown"
                  : "unchanged",
              true,
            ),
          };
        const envelope = this.envelope(row),
          transport = this.transport(envelope);
        if (!transport) return { result: this.result(row, "qualification_pending") };
        const grant = this.grant(row.attempt_id);
        if (!grant) throw new FollowUpDeliveryError("delivery_authorization_required");
        if (grant.state !== "active") throw new FollowUpDeliveryError("delivery_authorization_revoked");
        const now = this.clock(row.updated_at_ms);
        this.options.assertHostConfiguration?.();
        // Verify current key, exact target, immutable content and time INSIDE the consuming transaction.
        this.verifyGrant(row, SignedFollowUpDeliveryGrant.parse(JSON.parse(grant.signed_json)), now);
        this.obligation(repo, row.obligation_id, row.obligation_revision);
        const consumed = this.db
          .prepare(
            "UPDATE follow_up_delivery_grants SET state='consumed',updated_at_ms=? WHERE attempt_id=? AND state='active'",
          )
          .run(now, row.attempt_id);
        if (consumed.changes !== 1) throw new FollowUpDeliveryError("delivery_authorization_revoked");
        const started = this.bump(
          row,
          "started",
          "send_started",
          now,
          { grant_id: grant.grant_id },
          transport.qualification,
        );
        return { row: started, envelope: frozen(envelope), transport };
      }),
    );
    if ("result" in claim) return claim.result;
    // No retry or fallback exists here. A throw after this call cannot prove non-delivery.
    const outcome = await this.boundedCall((signal) => claim.transport.sendOnce(claim.envelope, signal));
    return this.safe(() =>
      this.durableWrite(() => {
        const current = this.row(repo, p.attempt_id);
        if (current.state !== "started" || current.revision !== claim.row.revision)
          return this.result(current, "unchanged", true);
        const now = this.evidenceClock(current.updated_at_ms),
          receipt = outcome.ok ? this.receipt(claim.envelope, outcome.value) : null;
        if (!receipt)
          return this.result(
            this.bump(
              current,
              "delivery_unknown",
              outcome.ok ? "receipt_unconfirmed" : "send_outcome_unknown",
              now,
              {},
            ),
            "delivery_unknown",
          );
        return this.result(
          this.bump(
            current,
            "delivered",
            "provider_receipt",
            now,
            { receipt_sha256: hash(receipt) },
            current.qualification,
            receipt,
          ),
          "delivered",
        );
      }),
    );
  }
  async reconcile(input: unknown): Promise<FollowUpDeliveryResult> {
    const p = parsed(FollowUpDeliveryActionParams, input),
      repo = storedRepoPath(p.repo_path);
    const claim = this.safe(() =>
      this.durableWrite(() => {
        let row = this.row(repo, p.attempt_id);
        this.revision(row, p.expected_revision);
        if (row.state === "prepared") throw new FollowUpDeliveryError("delivery_authorization_required");
        if (["delivered", "definitely_not_sent"].includes(row.state))
          return { result: this.result(row, "unchanged", true) };
        const envelope = this.envelope(row),
          transport = this.transport(envelope);
        if (!transport?.lookup_receipt || transport.qualification !== row.qualification)
          return { result: this.result(row, "qualification_pending") };
        const now = this.evidenceClock(row.updated_at_ms);
        if (row.state === "started") row = this.bump(row, "delivery_unknown", "started_unconfirmed", now, {});
        return { row, envelope: frozen(envelope), transport };
      }),
    );
    if ("result" in claim) return claim.result;
    const outcome = await this.boundedCall((signal) => claim.transport.lookup(claim.envelope, signal, {createdAtMs: claim.row.created_at_ms}));
    return this.safe(() =>
      this.durableWrite(() => {
        const row = this.row(repo, p.attempt_id);
        if (row.state !== "delivery_unknown" || row.revision !== claim.row.revision)
          return this.result(row, "unchanged", true);
        const now = this.evidenceClock(row.updated_at_ms),
          receipt = outcome.ok ? this.receipt(claim.envelope, outcome.value) : null;
        if (!receipt)
          return this.result(
            this.bump(row, "delivery_unknown", "lookup_unconfirmed", now, {}),
            "delivery_unknown",
          );
        return this.result(
          this.bump(
            row,
            "delivered",
            "provider_lookup_receipt",
            now,
            { receipt_sha256: hash(receipt) },
            row.qualification,
            receipt,
          ),
          "delivered",
        );
      }),
    );
  }
  private async boundedCall(
    call: (signal: AbortSignal) => Promise<unknown>,
  ): Promise<{ ok: true; value: unknown } | { ok: false }> {
    const controller = new AbortController();
    let timer: NodeJS.Timeout | undefined;
    try {
      return await Promise.race([
        Promise.resolve()
          .then(() => call(controller.signal))
          .then(
            (value) => ({ ok: true as const, value }),
            () => ({ ok: false as const }),
          ),
        new Promise<{ ok: false }>((resolve) => {
          timer = setTimeout(
            () => {
              controller.abort();
              resolve({ ok: false });
            },
            Math.max(1, Math.min(30000, this.options.timeoutMs ?? 5000)),
          );
        }),
      ]);
    } finally {
      if (timer) clearTimeout(timer);
      controller.abort();
    }
  }

  private verifyGrant(row: Row, grant: SignedFollowUpDeliveryGrant, now: number): void {
    const envelope = this.envelope(row),
      body = grant.body,
      { grant_id: _id, issued_at_ms, expires_at_ms, max_calls: _calls, ...subject } = body,
      key = this.options.trustedKeys?.get(grant.key_id);
    if (
      key?.purpose !== "follow_up_delivery" ||
      key.publicKey.type !== "public" ||
      key.publicKey.asymmetricKeyType !== "ed25519" ||
      key.repo_path !== row.repo_path ||
      key.provider_id !== envelope.destination.provider_id ||
      !key.destination_refs.includes(envelope.destination.destination_ref) ||
      !Number.isSafeInteger(key.max_validity_ms) ||
      key.max_validity_ms < 1 ||
      expires_at_ms - issued_at_ms > key.max_validity_ms ||
      deliveryCanonical(subject) !== deliveryCanonical(this.subject(envelope))
    )
      throw new FollowUpDeliveryError("delivery_invalid_authorization");
    if (now < issued_at_ms || now >= expires_at_ms)
      throw new FollowUpDeliveryError("delivery_authorization_expired");
    if (
      hash(this.target(row.repo_path, envelope.destination.destination_ref)) !== envelope.destination_digest
    )
      throw new FollowUpDeliveryError("delivery_destination_unavailable");
    if (
      !verify(
        null,
        Buffer.from(deliveryCanonical(body)),
        key.publicKey,
        Buffer.from(grant.signature, "base64"),
      )
    )
      throw new FollowUpDeliveryError("delivery_invalid_authorization");
  }
  private receipt(envelope: FollowUpDeliveryEnvelope, raw: unknown): FollowUpDeliveryReceipt | null {
    const result = FollowUpDeliveryReceipt.safeParse(raw);
    if (!result.success) return null;
    const r = result.data;
    return r.provider_id === envelope.destination.provider_id &&
      r.account_id === envelope.destination.account_id &&
      r.target_node_id === envelope.destination.target_node_id &&
      r.author_node_id === envelope.destination.actor_node_id &&
      r.destination_digest === envelope.destination_digest &&
      r.body_sha256 === envelope.body_sha256 &&
      r.attempt_id === envelope.attempt_id

      : null;
  }
  private envelope(row: Row): FollowUpDeliveryEnvelope {

  private readClock(): number {
    const now = (this.options.nowMs ?? Date.now)();
    if (Number.isSafeInteger(now) && now >= 0 && now <= 8_640_000_000_000_000)
      this.observedClock = Math.max(this.observedClock, now);

  private clock(minimum = 0): number {
    const now = this.readClock();
    if (
      !Number.isSafeInteger(now) ||
      now < Math.max(minimum, this.highWater()) ||
      now > 8_640_000_000_000_000

  /** FULL commit is required before an irreversible call. No await permits connection sharing here. */
  private durableWrite<T>(call: () => T): T {
    if (this.db.inTransaction || this.db.pragma("journal_mode", { simple: true }) !== "wal")
      throw new FollowUpDeliveryError("delivery_durability_unavailable");
    const observedBefore = this.observedClock;
    const previous = this.db.pragma("synchronous", { simple: true }) as number;
    const previousFullFsync = this.db.pragma("fullfsync", { simple: true }) as number;
    const persistClock = () => {
      this.db
        .prepare("UPDATE follow_up_delivery_clock SET observed_at_ms=MAX(observed_at_ms,?) WHERE singleton=1")
        .run(this.observedClock);
    };
    try {
      this.db.pragma("synchronous=FULL");
      if (process.platform === "darwin") this.db.pragma("fullfsync=ON");
      if (
        this.db.pragma("synchronous", { simple: true }) !== 2 ||
        (process.platform === "darwin" && this.db.pragma("fullfsync", { simple: true }) !== 1)
      )
        throw new FollowUpDeliveryError("delivery_durability_unavailable");
      try {
        preflightDiskSpace(this.dbPath);
        return this.db
          .transaction(() => {
            const result = call();
            persistClock();
            return result;
          })
          .immediate();
      } catch (error) {
        // Failed expiry checks also advance the observed clock: a later rollback cannot revive the grant.
        if (this.observedClock > observedBefore) {
          preflightDiskSpace(this.dbPath);
          this.db.transaction(persistClock).immediate();
        }
        throw error;
      }
    } finally {
      this.db.pragma(`synchronous=${previous}`);
      if (process.platform === "darwin") this.db.pragma(`fullfsync=${previousFullFsync}`);
    }
  }
  private safe<T>(call: () => T): T {
    try {
      return call();
    } catch (error) {
      if (error instanceof FollowUpDeliveryError) throw error;
      throw new FollowUpDeliveryError("delivery_database_unavailable");
    }
  }
  private bump(
    row: Row,
    state: Row["state"],
    reason: string,
    now: number,
    evidence: unknown,
    qualification = row.qualification,
    receipt: FollowUpDeliveryReceipt | null = null,

    if (row.revision >= Number.MAX_SAFE_INTEGER - 1)
      throw new FollowUpDeliveryError("delivery_revision_conflict");

      .prepare(
        "UPDATE follow_up_delivery_attempts SET state=?,revision=revision+1,updated_at_ms=?,qualification=?,receipt_json=?,receipt_sha256=?,reason=? WHERE attempt_id=? AND revision=?",
      )
      .run(
        state,
        now,
        qualification,
        receipt ? JSON.stringify(receipt) : null,
        receipt ? hash(receipt) : null,
        reason,
        row.attempt_id,
        row.revision,
      );
    if (result.changes !== 1) throw new FollowUpDeliveryError("delivery_revision_conflict");
    this.event(row.attempt_id, row.revision + 1, reason, evidence, now);
    return this.row(row.repo_path, row.attempt_id);
  }
  private event(id: string, revision: number, transition: string, evidence: unknown, now: number) {
    this.db
      .prepare(
        "INSERT INTO follow_up_delivery_events(attempt_id,revision,transition,evidence_json,created_at_ms) VALUES(?,?,?,?,?)",
      )
      .run(id, revision, transition, JSON.stringify(evidence), now);
  }
  private view(row: Row): FollowUpDeliveryAttempt {
    const envelope = this.envelope(row);
    return FollowUpDeliveryAttempt.parse({
      attempt_id: row.attempt_id,
      repo_path: row.repo_path,
      default_tenant: true,
      obligation_id: row.obligation_id,
      obligation_revision: row.obligation_revision,
      state: row.state,
      revision: row.revision,
      created_at_ms: row.created_at_ms,
      updated_at_ms: row.updated_at_ms,

      authorization_subject: this.subject(envelope),
      authorization_status: this.grant(row.attempt_id)?.state ?? "missing",
      qualification: row.qualification,
      receipt: row.receipt_json === null ? null : JSON.parse(row.receipt_json),
      receipt_sha256: row.receipt_sha256,
      reason: row.reason,
      delivery_uncertain: row.state === "started" || row.state === "delivery_unknown",
      promise_fulfillment: "independent_local_obligation",
    });
  }
  /** Reserve the largest valid receipt before an irreversible transport call is possible. */
  private reserveReceiptSpace(row: Row): void {
    const view = this.view(row),
      e = view.envelope;
    const receipt: FollowUpDeliveryReceipt = {
      provider_id: e.destination.provider_id,
      account_id: e.destination.account_id,
      target_node_id: e.destination.target_node_id,
      author_node_id: e.destination.actor_node_id,
      destination_digest: e.destination_digest,
      body_sha256: e.body_sha256,
      attempt_id: e.attempt_id,
      provider_message_id: "x" + "\0".repeat(255),
      provider_request_id: "x" + "\0".repeat(255),
    };
    bounded({
      schema_version: 1,
      outcome: "delivery_unknown",
      attempt: {
        ...view,
        state: "delivery_unknown",
        revision: Number.MAX_SAFE_INTEGER - 1,
        updated_at_ms: 8_640_000_000_000_000,
        qualification: "production_qualified",
        authorization_status: "consumed",
        receipt,
        receipt_sha256: "f".repeat(64),
        reason: "x".repeat(128),
        delivery_uncertain: true,
      },
      duplicate: false,
    });
  }
  private result(
    row: Row,
    outcome: FollowUpDeliveryResult["outcome"],
    duplicate = false,
  ): FollowUpDeliveryResult {
    return bounded(
      FollowUpDeliveryResult.parse({ schema_version: 1, outcome, attempt: this.view(row), duplicate }),
    );
  }
