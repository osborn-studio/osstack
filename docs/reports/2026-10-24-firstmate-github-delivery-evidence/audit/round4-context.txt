## Final audit result

**Confirmed P0: 0. Confirmed P1: 1, availability only. Safety P1: 0.** This is from reading the source; I ran no tools or tests.

## P1: Transient GitHub failures after consume wedge an unsent message

**Source:** `sendOnce` in `packages/cli/src/follow-up-github-transport.ts` calls `preflight(e, signal)`, which issues GET `/user` and GET issue, before the POST. `dispatch` in `packages/core/src/state/follow-up-delivery.ts` commits consume plus `started` before calling `sendOnce`.

**Trace:**
1. Admission preflight succeeds (GET `/user` 200, GET issue 200). The attempt stays `prepared`.
2. The claim transaction consumes the grant and commits `started`. No POST has been issued.
3. Inside `sendOnce`, the second `preflight` gets a 403 secondary rate limit, a 503, or a timeout. The cumulative 5 s `boundedCall` budget also covers both GETs, so slow responses trigger this too.
4. `api` rejects with `github_delivery_unconfirmed`. `boundedCall` returns `{ok:false}`, and `dispatch` bumps the attempt to `delivery_unknown / send_outcome_unknown`.
5. The POST line never executed. `reconcile` goes to `lookup`, which succeeds this time, finds nothing, and records `lookup_unconfirmed`.
6. No transition reaches `definitely_not_sent`. `prepare` for that obligation throws `delivery_unresolved_attempt`, `authorize` requires `prepared`, and `revoke` leaves `delivery_unknown`.

**Result:** the obligation is permanently blocked and zero messages were sent. No duplicate send occurs. The contract's "started stays unknown" rule does not require this case. The rule applies to failures after the send attempt, and this one happens before any POST.

**Fix (no protocol or migration change):** `sendOnce` should make no network calls. Admission already verified actor and target. Keep only the local credential and fingerprint fence and the `signal.aborted` check, then POST.

**Test:** a fixture counts requests. Assert that `sendOnce` issues exactly one request (the POST), and that a GET failure during admission leaves the attempt `prepared`.

## Verified fixes

- **Synchronous fence:** `assertHostConfiguration` runs inside the `authorize` and claim transactions.
- **Effect-free preflight:** `dispatch` admission runs preflight before consume. Grant, revision, expiry, and obligation are rechecked in the claim transaction.
- **Started is terminal-unknown:** no path from `started` to `definitely_not_sent` exists. `revoke` and `reconcile` both map `started` to `delivery_unknown`.
- **Foreign marker copy:** `lookup` skips comments whose author or `issue_url` does not match before the marker test, so a foreign copy cannot block a correct receipt.
- **Lookup bounds:** `since` is applied, and the 4 MiB cap is sufficient for 10 comments of at most 65,536 characters.
- **Issuer:** `issue-grant` reruns `readHostDeliveryConfig` after the key read and before signing.
- **Protocol integrity:** the grant signature regex matches Ed25519 base64 length.

## Remaining P2 (availability and correctness, no safety impact)

1. **`since` anchored on prepare time.** `lookup` uses `claim.row.created_at_ms`. An attempt prepared 7 days before dispatch gets a 7-day window. In a busy thread, reconcile then becomes `lookup_incomplete` permanently. Fix: anchor on the `send_started` event time from the existing events table.
2. **The 20-page bound is not the effective limit.** `boundedCall` caps the whole lookup at 5 s, which covers the preflight and every page GET. Realistically this is about 5 to 10 pages, so busy threads hit an unknown well before 200 comments. Fix: give lookup its own budget, up to the 30 s clamp.
3. **Locked issues are not rejected pre-consume.** Preflight ignores `issue.locked`. A locked issue returns 403 on POST after consume, which wedges an attempt that was never sent. Fix: reject `locked === true` in preflight.
4. **Actor-authored marker copies fail closed.** If the operator's own account, which is probably the actor, posts the wire body or preview, the duplicate or mismatch makes reconcile throw permanently. Not a false delivery. Document it, and avoid posting wire bodies under the actor account.
5. **Reconcile races in-flight `started`.** `reconcile` converts `started` to `delivery_unknown`, and then `dispatch` discards the success receipt because `current.state !== "started"`. Recoverable by a later reconcile.
6. **Error codes.** `assertRegistryFingerprint` throws plain `Error("delivery_host_config_changed")`, which `safe()` maps to `delivery_database_unavailable`. No state effect, but operators see the wrong code.
7. **Clock regression** makes every `authorize` and `dispatch` refuse until the clock recovers. `revoke` still works.
8. **Any local RPC client can `prepare` a bogus attempt**, which blocks the obligation with `delivery_unresolved_attempt` until someone revokes it. Availability only, since sending still requires a grant bound to the previewed body.

## Accepted by contract, not counted

- **Started-without-POST wedge.** A crash after the `started` commit, a config or token race between consume and POST, or any post-consume HTTP 403 leaves the obligation permanently blocked with no operator recovery path. The safety property holds. Recoverability is nil. Root needs an explicit decision here, which would require a protocol or schema change and is out of scope.

## Live qualification (not code defects, but gating)

1. **Body normalization.** If GitHub alters the stored body (CRLF, trailing whitespace), `receipt()` throws after a successful POST. Every send becomes unknown, and every lookup fails. This affects 100% of deliveries and should gate production.
2. **`since` semantics.** Confirm it filters on `updated_at`, and confirm ascending order.
3. **Locked-issue and secondary-rate-limit responses.** Confirm whether they arrive as 403, and whether they carry a Retry-After.
4. **Link header and `x-github-request-id`.** Confirm both are present on every paginated and POST response.

import { request as httpsRequest } from "node:https";
import { request as httpRequest } from "node:http";
import type { FollowUpDeliveryEnvelope, FollowUpDeliveryReceipt } from "@osstack/protocol";
import type { FollowUpTransport } from "@osstack/core";

const sha = (value: string) => createHash("sha256").update(value).digest("hex");
/** Included in the human preview. Correlation is not itself proof: author, target and exact body must match. */
export function githubDeliveryBody(envelope: FollowUpDeliveryEnvelope): string {
  return `${envelope.body}\n\n<!-- osstack-delivery:${envelope.attempt_id}:${envelope.envelope_digest} -->`;
}
export interface GithubDeliveryTransportOptions {
  qualification: FollowUpTransport["qualification"];
  /** Host-owned resolver rechecks current registration and reads a private credential for each operation. */
  credential(envelope: FollowUpDeliveryEnvelope): Promise<string>;
  /** Only local HTTP fixtures are accepted, and only under test_only qualification. */
  fixtureBaseUrl?: string;
}
interface JsonResponse {
  value: unknown;
  requestId: string;
  hasNext: boolean;
}
/** No redirects, retry middleware, shell, proxy environment, or provider error bodies are used. */
export function createGithubDeliveryTransport(options: GithubDeliveryTransportOptions): FollowUpTransport {
  const base = options.fixtureBaseUrl ? new URL(options.fixtureBaseUrl) : new URL("https://api.github.com");
  if (
    options.fixtureBaseUrl &&
    (options.qualification !== "test_only" ||
      base.protocol !== "http:" ||
      base.hostname !== "127.0.0.1" ||
      base.username ||
      base.password ||
      base.pathname !== "/" ||
      base.search ||
      base.hash)
  )
    throw Error("invalid_delivery_fixture");
  const api = async (
    path: string,
    token: string,
    signal: AbortSignal,
    body?: string,
  ): Promise<JsonResponse> => {
    if (signal.aborted || !/^[\x21-\x7e]{1,4096}$/.test(token)) throw Error("github_delivery_unavailable");
    const url = new URL(path, base);
    return new Promise((resolve, reject) => {
      const fail = () => reject(Error("github_delivery_unconfirmed"));
      const request = (base.protocol === "https:" ? httpsRequest : httpRequest)(
        url,
        {
          method: body === undefined ? "GET" : "POST",
          signal,
          headers: {
            authorization: `Bearer ${token}`,
            accept: "application/vnd.github+json",
            "x-github-api-version": "2026-03-10",
            "user-agent": "osstack-follow-up-delivery",
            ...(body === undefined
              ? {}
              : {
                  "content-type": "application/json",
                  "content-length": Buffer.byteLength(body),
                }),
          },
        },
        (response) => {
          const chunks: Buffer[] = [];
          let bytes = 0;
          response.on("data", (chunk: Buffer) => {
            bytes += chunk.length;
            if (bytes > 4_194_304) {
              response.destroy();
              request.destroy();
              fail();
            } else chunks.push(chunk);
          });
          response.on("error", fail);
          response.on("end", () => {
            try {
              if (response.statusCode !== (body === undefined || path === "/graphql" ? 200 : 201))
                throw Error();
              const requestId = response.headers["x-github-request-id"];
              if (typeof requestId !== "string" || !/^[\x21-\x7e]{1,256}$/.test(requestId)) throw Error();
              resolve({
                value: JSON.parse(new TextDecoder("utf-8", { fatal: true }).decode(Buffer.concat(chunks))),
                requestId,
                hasNext: /rel="next"/.test(String(response.headers.link ?? "")),
              });
            } catch {
              fail();
            }
          });
        },
      );
      request.on("error", fail);
      request.setTimeout(5000, () => request.destroy(Error("github_delivery_timeout")));
      request.end(body);
    });
  };
  function record(value: unknown): Record<string, unknown> {
    if (!value || typeof value !== "object" || Array.isArray(value))
      throw Error("github_delivery_invalid_response");
    return value as Record<string, unknown>;
  }
  const targetPath = (e: FollowUpDeliveryEnvelope) =>
    `/repos/${encodeURIComponent(e.destination.owner)}/${encodeURIComponent(e.destination.repository)}/issues/${e.destination.issue_number}`;
  const targetUrl = (e: FollowUpDeliveryEnvelope) => `https://api.github.com${targetPath(e)}`;
  async function preflight(e: FollowUpDeliveryEnvelope, signal: AbortSignal): Promise<string> {
    if (
      e.destination.host !== "github.com" ||
      e.destination.provider_id !== "github_comment" ||
      sha(e.body) !== e.body_sha256
    )
      throw Error("github_delivery_invalid_envelope");
    const token = await options.credential(e);
    const actor = record((await api("/user", token, signal)).value);
    if (actor.node_id !== e.destination.actor_node_id) throw Error("github_delivery_actor_mismatch");
    const issue = record((await api(targetPath(e), token, signal)).value);
    if (
      issue.node_id !== e.destination.target_node_id ||
      issue.url !== targetUrl(e) ||
      issue.number !== e.destination.issue_number ||
      issue.locked === true
    )
      throw Error("github_delivery_target_mismatch");
    return token;
  }
  function receipt(e: FollowUpDeliveryEnvelope, value: unknown, requestId: string): FollowUpDeliveryReceipt {
    const comment = record(value),
      user = record(comment.user);
    if (
      !Number.isSafeInteger(comment.id) ||
      Number(comment.id) < 1 ||
      comment.issue_url !== targetUrl(e) ||
      user.node_id !== e.destination.actor_node_id ||
      comment.body !== githubDeliveryBody(e)
    )
      throw Error("github_delivery_receipt_mismatch");
    return {
      provider_id: "github_comment",
      account_id: e.destination.account_id,
      target_node_id: e.destination.target_node_id,
      author_node_id: e.destination.actor_node_id,
      destination_digest: e.destination_digest,
      body_sha256: e.body_sha256,
      attempt_id: e.attempt_id,
      provider_message_id: String(comment.id),
      provider_request_id: requestId,
    };
  }
  const tickets = new Map<string, { token: string; expiresAt: number }>();
  let preflights = 0;
  const ticketKey = (e: FollowUpDeliveryEnvelope) => `${e.attempt_id}:${e.envelope_digest}`;
  return {
    qualification: options.qualification,
    automatic_retries: false,
    lookup_receipt: true,
    async preflight(e, signal) {
      for (const [key, ticket] of tickets) if (ticket.expiresAt <= performance.now()) tickets.delete(key);
      if (tickets.size + preflights >= 64) throw Error("github_delivery_busy");
      preflights++;
      try {
        const token = await preflight(e, signal);
        if (signal.aborted) throw Error("github_delivery_cancelled");
        tickets.set(ticketKey(e), { token, expiresAt: performance.now() + 30000 });
      } finally {
        preflights--;
      }
    },
    async sendOnce(e, signal) {
      const ticket = tickets.get(ticketKey(e));
      tickets.delete(ticketKey(e));
      if (!ticket || ticket.expiresAt <= performance.now()) throw Error("github_delivery_preflight_required");
      const token = ticket.token;
      // No network readiness calls after consume: only local credential/config fence, then the sole POST.
      if ((await options.credential(e)) !== token || signal.aborted)
        throw Error("github_delivery_registration_changed");
      // Once durably started, all exceptions remain unknown; never infer non-delivery from HTTP errors.
      const response = await api(
        "/graphql",
        token,
        signal,
        JSON.stringify({
          query:
            "mutation OSStackFollowUp($input:AddCommentInput!){addComment(input:$input){clientMutationId subject{id} commentEdge{node{databaseId body author{... on User{id} ... on Bot{id}}}}}}",
          variables: {
            input: {
              subjectId: e.destination.target_node_id,
              body: githubDeliveryBody(e),
              clientMutationId: e.attempt_id,
            },
          },
        }),
      );
      const result = record(response.value);
      if (result.errors !== undefined && (!Array.isArray(result.errors) || result.errors.length))
        throw Error("github_delivery_graphql_error");
      const payload = record(record(result.data).addComment),
        subject = record(payload.subject),
        comment = record(record(payload.commentEdge).node),
        author = record(comment.author);
      if (payload.clientMutationId !== e.attempt_id || subject.id !== e.destination.target_node_id)
        throw Error("github_delivery_receipt_mismatch");
      // The mutation is addressed by immutable subject ID, not a mutable owner/repository URL.
      return receipt(
        e,
        { id: comment.databaseId, body: comment.body, user: { node_id: author.id }, issue_url: targetUrl(e) },
        response.requestId,
      );
    },
    async lookup(e, signal, context) {
      const token = await preflight(e, signal);
      let found: FollowUpDeliveryReceipt | undefined;
      // Old busy threads do not hide a new attempt behind historical pages. Context comes from the durable ledger.
      const since =
        context && Number.isSafeInteger(context.createdAtMs) && context.createdAtMs >= 0
          ? `&since=${encodeURIComponent(new Date(Math.max(0, context.createdAtMs - 300000)).toISOString())}`
          : "";
      // Fixed bounded pages, never follow a provider-supplied URL. Incomplete enumeration remains unknown.
      for (let page = 1; page <= 20; page++) {
        const response = await api(
          `${targetPath(e)}/comments?per_page=10&page=${page}${since}`,
          token,
          signal,
        );
        if (!Array.isArray(response.value) || response.value.length > 10)
          throw Error("github_delivery_invalid_list");
        for (const raw of response.value) {
          const comment = record(raw);
          // A public marker copied by another author is not a candidate receipt and cannot veto one.
          if (
            !comment.user ||
            typeof comment.user !== "object" ||
            Array.isArray(comment.user) ||
            (comment.user as Record<string, unknown>).node_id !== e.destination.actor_node_id ||
            comment.issue_url !== targetUrl(e)
          )
            continue;
          if (typeof comment.body !== "string" || !comment.body.includes(`osstack-delivery:${e.attempt_id}:`))
            continue;
          const match = receipt(e, raw, response.requestId);
          if (found) throw Error("github_delivery_duplicate_correlation");
          found = match;
        }
        if (!response.hasNext && response.value.length < 10) {
          if ((await options.credential(e)) !== token || signal.aborted)
            throw Error("github_delivery_registration_changed");
          return found ?? null;
        }
      }
      throw Error("github_delivery_lookup_incomplete");
    },
  };
}

export interface FollowUpTransport {
  qualification: "test_only" | "sandbox_qualified" | "production_qualified";
  /** The adapter must disable SDK retries; declaration is not provider qualification. */
  automatic_retries: boolean;
  lookup_receipt: boolean;
  /** Effect-free readiness checks, before consuming a grant. Implementations MUST NOT POST here. */
  preflight?(envelope: Readonly<FollowUpDeliveryEnvelope>, signal: AbortSignal): Promise<void>;
  sendOnce(envelope: Readonly<FollowUpDeliveryEnvelope>, signal: AbortSignal): Promise<unknown>;
  /** Trusted provider lookup; caller-supplied receipt objects never enter this port. */
  lookup(envelope: Readonly<FollowUpDeliveryEnvelope>, signal: AbortSignal, context?: { createdAtMs: number }): Promise<unknown>;
}

  private async boundedCall(
    call: (signal: AbortSignal) => Promise<unknown>,
  ): Promise<{ ok: true; value: unknown } | { ok: false }> {
    const controller = new AbortController();
    let timer: NodeJS.Timeout | undefined;
    try {
      return await Promise.race([
        Promise.resolve()
          .then(() => call(controller.signal))
          .then(
            (value) => ({ ok: true as const, value }),
            () => ({ ok: false as const }),
          ),
        new Promise<{ ok: false }>((resolve) => {
          timer = setTimeout(
            () => {
              controller.abort();
              resolve({ ok: false });
            },
            Math.max(1, Math.min(30000, this.options.timeoutMs ?? 5000)),
          );
        }),
      ]);
    } finally {
      if (timer) clearTimeout(timer);
      controller.abort();
    }
  }

      throw new FollowUpDeliveryError("delivery_destination_unavailable");
