## Verdict

I found no confirmed P0 in the admission-before-receipt change. The pre-admission wedge from the prior review is resolved for both manual routes, as far as the supplied code shows. I did find two confirmed lifecycle defects in the admission and executor paths that the 26-case suite does not exercise, plus one latent defect that is unreachable under current invariants. These are code-reading findings. I did not reproduce them by running code.

## Verified by reading

- **Pre-admission wedge resolved.** In `handleSessionSend` and in `attention.answer`, `reserveSessionInstruction` / `actions.reserve` run only after `acquireManualSessionAdmission` resolves. A queued request holds only the `activeSessionSends` marker and the `activeRuns` controller, with no accepted receipt. A failed or cancelled admission is cleaned up by `clear()` in the rejection path and by `admission.release()` when `handedOff` is false.
- **No duplicate execution from this change.** The pre-check `activeSessionSends.has` and the `set` in `acquireManualSessionAdmission` run in the same synchronous turn, with no `await` between them, so two requests cannot both pass the check. A concurrent retry of the same `message_id` during admission gets `session_busy` (not a second adapter call), and the `reserveSessionInstruction` duplicate branch is still covered by the existing `outcome === "duplicate"` path.
- **Cancellation transfer.** `executeReservedSessionTurn` receives the same `AbortController` that is registered in `activeRuns`. `task.cancel` and shutdown abort queued admissions as well as running turns.
- **Shutdown** iterates `activeRuns` and aborts queued manual work, so queued manual sends are cancelled during shutdown.

## Confirmed defects

**1. Permanent in-process quarantine after a failed lock release during admission rejection (P1, availability, low likelihood).**
In `GovernedExecution.acquireOwned`, the catch block calls `this.quarantine(scope.repoId, input.runId)` when `lock.release()` throws, then rethrows an `AggregateError`. The `finally` still runs `releasePermits()`. Nothing clears the quarantine on this path. The acquisition never returned a lease, so no `releaseAfterReconciliation` handle exists. The top-of-function check `quarantinedRepositories.has(scope.repoId)` then rejects every later write to that repository until the daemon restarts. The comment in the same file says "Ownership failure must not free the in-process writer authority," which contradicts the permits being freed here.

**2. Early return in `executeReservedSessionTurn` leaks the admitted lease and the reserved message (latent P1).**
The line `if (session.native_session_id === null) return singleErr(...)` runs before the `try`/`finally`. When the caller supplies `admittedLease` (both manual routes do), that return skips `lease.release()`, skips `activeSessionSends.delete`, and skips `activeRuns` cleanup. The caller has already reserved the message, so it stays `accepted`. The result is a session wedge until restart. Current code makes this unreachable: the manual path checks `native_session_id` before admission, and no repository method sets it back to null. It is still a real defect in the code shape. Fix: move the guard inside the `try`, or perform it before the lease is handed over, and route it through the same failed-receipt and release logic.

**3. Queued admission has no bound when a holder is retained (P2, liveness).**
`retain()` sets `retained`, clears the timer, and quarantines the repository. It does not call `releasePermits()`, so the global and per-repository FIFO permits stay held. A manual request already waiting in `queue.acquire(signal)` or `writes.acquire(signal)` waits without a timeout. The quarantine check runs only after acquisition, and the early check runs only at call time, so it never fires for a waiter. The waiter ends only on `task.cancel` or shutdown. The RPC socket stays open, the session reports `session_busy`, and `run.status` reports `active: true`. This is much better than the prior receipt wedge, but it is still an unbounded hang. The suite does not cover it.

## Qualifications (not confirmed defects)

- `daemon.drain` does not cancel queued manual admissions. Because they are registered in `activeRuns`, drain waits on them until its timeout. They are denied only after they acquire. This is safe but extends drain time.
- `publicSessionWait` uses `ctx.activeSessionSends.has(sessionId)` to set `applying`. During the queued phase, no instruction has been reserved yet, so `applying: true` can misdescribe the state.
- The synthetic `pending:${action_id}` value is passed into `actions.replay` as the in-flight identifier. Confirm that `AttentionActions` only uses it for busy classification and never persists or returns it.
- The attention branch checks `ctx.draining` before replay, so even a completed answer replay is refused during drain. `session.send` allows completed replays during drain. The inconsistency is conservative but should be intentional.
- Turn, terminal-state, and `resume_supported` checks run before admission and are not rechecked afterward. Safety depends on `reserveSessionInstruction` and `actions.reserve` rejecting stale versions and revisions. That code is outside the supplied files, so I could not verify it. Terminal transitions go through `setState` and `completeInboundTurn`, which bump the version, which supports the version guard.

## Not verified

- The body of `AttentionActions` (`replay`, `reserve`, `reconcile`) and `reserveSessionInstruction`.
- `FifoSemaphore` internals and `acquireRepoWriteLock` behavior on release failure.
- The full monorepo suite. The 26-case pass says nothing about the three defects above, which have no test coverage.

  req: DaemonRequest,

  if (p instanceof Error) return singleErr(req.id, "bad_request", p.message);

  // instruction may reserve a message or invoke an adapter during an upgrade.
  if (ctx.draining && ctx.sessions.getMessage(p.message_id)?.state !== "applied") {
    return singleErr(req.id, "draining", "daemon is not accepting session instructions");
  }

  const session = ctx.sessions.getSession(p.session_id);
  if (session === undefined) return singleErr(req.id, "not_found", "session not found");

    return singleErr(req.id, "runtime_mismatch", "session belongs to another runtime");
  }
  // Idempotency wins over moving state: a retry may arrive after the first
  // delivery already appended a newer turn or completed the conversation.
  // Let the repository compare the complete canonical envelope before any
  // current-turn/current-state guards reject it.
  const existingMessage = ctx.sessions.getMessage(p.message_id);
  if (existingMessage !== undefined) {

      const replay = ctx.sessions.applyInbound({
        message_id: p.message_id,
        session_id: p.session_id,
        turn_id: p.turn_id,
        direction: "inbound",
        kind: "instruction.send",
        payload: { text: p.text, ...(p.requested_by === undefined ? {} : { requested_by: p.requested_by }) },
        state: "accepted",
        created_at: Date.now() / 1000,
      }, p.expected_version, Date.now() / 1000);
      if (existingMessage.state === "applied") {
        return singleOk(req.id, { state: replay.outcome, session_version: replay.session_version });
      }
      if (replay.session_version !== p.expected_version + 1) {
        return singleErr(req.id, "version_conflict", "accepted message cannot be recovered safely");
      }

        return ctx.activeSessionSends.has(session.session_id)

              req.id,

              "the previous delivery may have reached the agent; inspect the session before using a new message_id",
            );
      }
      if (existingMessage.state !== "failed") {
        return singleErr(req.id, "version_conflict", "reserved message is not retryable");
      }
      return singleErr(req.id, "delivery_uncertain", "Failed execution may have had side effects; reconcile the existing receipt before retrying");
    } catch (err) {
      if (err instanceof SessionMessageIdConflict) {
        return singleErr(req.id, "message_id_conflict", "message_id was already used for different content");
      }
      throw err;
    }
  }
  if (TERMINAL_SESSION_STATES.has(session.state)) {
    return singleErr(req.id, "session_terminal", `session state=${session.state}`);
  }
  if (!session.resume_supported || session.native_session_id === null) {
    return singleErr(req.id, "resume_unsupported", "session cannot be resumed");
  }
  const snapshot = ctx.sessions.latestSnapshot(p.session_id);
  if (snapshot.turn_id !== p.turn_id) {
    return singleErr(req.id, "turn_conflict", "message does not target the current turn");
  }
  const adapter = ctx.adapters.get(session.agent_id);
  if (adapter === undefined || !isSessionCapableAdapter(adapter) || !adapter.sessionCapabilities().resume) {
    return singleErr(req.id, "resume_unsupported", "agent does not support resume");
  }
  if (ctx.activeSessionSends.has(session.session_id)) {
    return singleErr(req.id, "session_busy", "session is already applying another instruction");

  let admission: Awaited<ReturnType<typeof acquireManualSessionAdmission>>;

        state: "accepted",
        created_at: now,
      }, p.expected_version, now);
    } catch (err) {
      if (err instanceof SessionVersionConflict) {

      }
      if (err instanceof SessionMessageIdConflict) {
        return singleErr(req.id, "message_id_conflict", "message_id was already used for different content");

/** Track queued manual work before awaiting admission so drain/cancel can stop it.
 * No durable receipt exists until admission succeeds; callers transfer both
 * ownership and the same cancellation signal to the reserved-turn executor.
 */
async function acquireManualSessionAdmission(
  ctx: DaemonContext,
  session: NonNullable<ReturnType<SessionRepository["getSession"]>>,
  pendingMessageId: string,
) {
  const controller = new AbortController();
  ctx.activeSessionSends.set(session.session_id, pendingMessageId);
  ctx.activeRuns.set(session.run_id, controller);
  const clear = () => {
    if (ctx.activeSessionSends.get(session.session_id) === pendingMessageId) ctx.activeSessionSends.delete(session.session_id);
    if (ctx.activeRuns.get(session.run_id) === controller) ctx.activeRuns.delete(session.run_id);
  };
  try {
    const lease = await acquireSessionAdmission(ctx, session.agent_id, session.repo_path, session.run_id, controller.signal);
    return { lease, controller, release: async () => { try { await lease.release(); } finally { clear(); } } };
  } catch (error) {
    clear();
    throw error;
  }
}

    yield { type: "native_session.started", native_session_id: "native-secret-started" };
    yield task.prompt === "structured-start-event" ? { type: "decision.requested", ...structuredDecision } : {
      type: "assistant.message", message_id: "reply_started",
      text: task.prompt === "structured-start" ? JSON.stringify({ ostag_decision: structuredDecision }) : "CANARY_READY",
    };
    yield { type: "session.terminal", state: "completed" };
  }
  async *resumeSession(input: AgentSessionInput, signal: AbortSignal): AsyncIterable<AgentSessionEvent> {
    this.resumed.push(input);
    yield { type: "native_session.started", native_session_id: input.native_session_id };
    yield { type: "session.state", state: "running" };
    if (input.prompt === "wait-for-cancel") {
      await new Promise<void>((resolve) => signal.addEventListener("abort", () => resolve(), { once: true }));
      yield { type: "session.terminal", state: "cancelled" };
      return;
    }
    if (input.prompt === "structured-event" || input.prompt === "structured-directive") {
      yield input.prompt === "structured-event"
        ? { type: "decision.requested", ...structuredDecision }
        : { type: "assistant.message", message_id: "structured_reply", text: JSON.stringify({ ostag_decision: structuredDecision }) };
      yield { type: "session.terminal", state: "completed" };
      return;
    }
    if (input.prompt === "leak") {
      yield { type: "assistant.message", message_id: `reply_${input.message_id}`, text: input.native_session_id };
      return;
    }
    if (input.prompt === "fail-once" && !this.failedOnce.has(input.session_id)) {
      this.failedOnce.add(input.session_id);
      yield {
        type: "session.terminal",
        state: "failed",
        error_code: "auth_unavailable",
        summary: "agent authentication is unavailable",
      };
      return;
    }
    if (input.prompt === "decision") {
      yield {
        type: "assistant.message",
        message_id: `reply_${input.message_id}`,
        text: JSON.stringify({
          ostag_decision: {
            decision_id: "decision_canary",
            question: "请选择灰度方向",
            choices: [
              { choice_id: "a", label: "方案 A" },
              { choice_id: "b", label: "方案 B" },
            ],
          },
        }),
      };
      yield { type: "session.terminal", state: "completed" };
      return;
    }
    yield { type: "assistant.message", message_id: `reply_${input.message_id}`, text: `收到：${input.prompt}` };
    yield { type: "session.terminal", state: "completed" };
  }
}

function rpc(method: string, params?: unknown, timeoutMs = 5_000): Promise<RpcResponse> {
  return new Promise((resolve, reject) => {
    const sock = connect(socketPath);
    const decoder = new FrameDecoder();
    const timer = setTimeout(() => { sock.destroy(); reject(new Error("rpc timeout")); }, timeoutMs);
    sock.on("connect", () => sock.write(encodeFrame({ id: 1, method, params })));
    sock.on("data", (chunk) => {
      const frames = decoder.push(chunk);
      if (frames.length === 0) return;
      clearTimeout(timer);
      sock.end();
      resolve(frames[0] as RpcResponse);
    });
    sock.on("error", (err) => { clearTimeout(timer); reject(err); });
  });
}

function seedSession(
  id: string,
  state: "idle" | "completed" = "idle",
  resumeSupported = true,
): void {
  const db = openDb({ path: handle.dbPath });
  try {
    const taskId = `task_${id}`;
    const runId = `run_${id}`;
    insertTask(db, handle.dbPath, { task_id: taskId, title: `Relay ${id}`, created_at: 1 });
    insertRun(db, handle.dbPath, {
      run_id: runId,
      task_id: taskId,
      session_id: id,
      agent_id: adapter.id,
      capability_id: "fake.resume",
      phase: "code",
      started_at: 1,
    });
    const repo = new SessionRepository(db, handle.dbPath);
    repo.createSession({
      session_id: id,
      task_id: taskId,
      run_id: runId,
      agent_id: adapter.id,
      request_sha256: "a".repeat(64),
      native_session_id: `native-secret-${id}`,
      repo_path: sessionRepo(id),
      state,
      resume_supported: resumeSupported,
      version: 2,
      updated_at: 2,
    });
    repo.appendTurn({
      turn_id: `turn_${id}`,
      session_id: id,
      ordinal: 1,
      state: "awaiting_decision",
      assistant_text: "请选择方向",
      decision: { choices: ["A", "B"] },
      created_at: 2,
      updated_at: 2,
    });
  } finally {
    db.close();
  }
}

import { join } from "node:path";
import { acquireRepoWriteLock, FifoSemaphore, SemaphoreAcquireAbortedError, type SemaphoreLease, type RepoWriteLock } from '@osstack/autonomy';
import { resolveRepositoryScope } from '@osstack/core';

export interface ExecutionLease {
  release(): Promise<void>;
  /** Keep ownership until a trusted caller has confirmed external exit. */
  retain(reason: string): void;
  /** Trusted host only; never accept a worker-provided proof callback. */
  releaseAfterReconciliation?(verify: () => Promise<void>): Promise<void>;
  /** Assert this exact canonical writer lease is still live. */
  assertActive?(): Promise<void>;
  /** Scoped synchronous file operations under the canonical writer lock. This
   * capability is absent on read leases. Failures retain admission until recovery. */
  withWriteGuard?<T>(workspacePath: string, operation: (assertActive: () => void) => T): Promise<T>;
}
export interface AdmissionInput {
  kind: 'read' | 'write';
  runId: string;
  /** Supplied by the daemon registration, never by an adapter context. */
  workspacePath?: string;
  repoId?: string;
  signal?: AbortSignal;
  authorize?: () => Promise<void>;
  /** Host-only synchronous proof: acquisition rejected with no lease or cleanup obligation. */
  onNotAcquired?: () => void;
}
export class GovernedExecution {
  private readonly activeRuns = new Set<string>();
  private readonly quarantinedRepositories = new Map<string, Set<string>>();
  private quarantine(repoId: string, runId: string): void {
    const owners = this.quarantinedRepositories.get(repoId) ?? new Set<string>();
    owners.add(runId); this.quarantinedRepositories.set(repoId, owners);
  }
  constructor(private readonly options: {
    reads: FifoSemaphore;
    writes: FifoSemaphore;
    repositories: Map<string, FifoSemaphore>;
    checkHealth: () => Promise<void>;
  }) {}

  get hasWriters(): boolean { return this.options.writes.in_use > 0; }

  async acquire(input: AdmissionInput): Promise<ExecutionLease> {
    const cleanup = { confirmed: true };
    try { return await this.acquireOwned(input, cleanup); }
    catch (error) {
      if (cleanup.confirmed && !this.activeRuns.has(input.runId)) input.onNotAcquired?.();
      throw error;
    }
  }

  private async acquireOwned(input: AdmissionInput, cleanup: { confirmed: boolean }): Promise<ExecutionLease> {
    const check = async (): Promise<void> => {
      if (input.signal?.aborted) throw new SemaphoreAcquireAbortedError();
      if (input.kind === 'write') await this.options.checkHealth();
      await input.authorize?.();
    };
    await check();
    const scope = input.workspacePath === undefined ? undefined
      : await resolveRepositoryScope(input.workspacePath, input.repoId === undefined ? {} : { repoId: input.repoId });
    if (input.kind === 'write' && !scope) throw new Error('trusted repository scope required for writes');
    if (input.kind === "write" && scope && this.quarantinedRepositories.has(scope.repoId)) throw new Error("repository external stop unconfirmed; reconciliation required");
    if (this.activeRuns.has(input.runId)) {
      cleanup.confirmed = false;
      throw new Error("run already admitted or queued");
    }
    this.activeRuns.add(input.runId);
    let local: SemaphoreLease | undefined;
    let global: SemaphoreLease | undefined;
    let lock: RepoWriteLock | undefined;
    let queue: FifoSemaphore | undefined;
    const releasePermits = (): void => {
      global?.release(); local?.release();
      this.activeRuns.delete(input.runId);
      if (scope && queue?.in_use === 0 && queue.pending === 0) this.options.repositories.delete(scope.repoId);
    };
    let released = false;
    let retained = false;
    let writeGuardActive = false;
    // Start as soon as the filesystem lock exists, including the final policy
    // wait. Once admitted, a renewal failure retains the unknown producer.
    let renewing: Promise<void> = Promise.resolve();
    let timer: ReturnType<typeof setInterval> | undefined;
    const startRenewal = () => {
      timer = setInterval(() => {
        if (writeGuardActive) return;
        renewing = renewing.then(async () => {
          if (!released && !writeGuardActive) await lock!.renew();
        }).catch((error: unknown) => {
          retained = true;
          if (scope) this.quarantine(scope.repoId, input.runId);
          process.stderr.write(`repository lease renewal failed; retained ${input.runId}: ${String(error)}\n`);
          if (timer) clearInterval(timer);
        });
      }, 20_000);
      timer.unref();
    };
    try {
      if (input.kind === 'write' && scope) {
        queue = this.options.repositories.get(scope.repoId) ?? new FifoSemaphore(1);
        this.options.repositories.set(scope.repoId, queue);
        local = await queue.acquire(input.signal);
      }
      global = await (input.kind === 'read' ? this.options.reads : this.options.writes).acquire(input.signal);
      if (input.kind === 'write' && scope) {
        // A failed filesystem acquisition may have left an ownership obligation.
        cleanup.confirmed = false;
        lock = await acquireRepoWriteLock({ root_dir: join(scope.commonDir, "osstack", "writer-locks"), recover_stale: false, repo_id: scope.repoId, autonomy_run_id: input.runId });
        // Authorization may wait behind another branch's synchronous work.
        // Start ownership renewal before that wait, not after publishing admission.
        startRenewal();
      }
      if (input.kind === "write" && scope && this.quarantinedRepositories.has(scope.repoId)) throw new Error("repository external stop unconfirmed; reconciliation required");
      await check();
      await renewing;
      if (retained) throw new Error("repository lease renewal failed during admission");
      await lock?.assertActive();
      if (retained) throw new Error("repository lease renewal failed during admission");
      if (input.signal?.aborted) throw new SemaphoreAcquireAbortedError();
    } catch (error) {
      if (timer) clearInterval(timer);
      await renewing;
      try {
        await lock?.release();
        if (lock) cleanup.confirmed = true;
        // No executor was admitted. Remove only this rejected acquisition's quarantine.
        if (scope) {
          const owners = this.quarantinedRepositories.get(scope.repoId);
          owners?.delete(input.runId);
          if (owners?.size === 0) this.quarantinedRepositories.delete(scope.repoId);
        }
      } catch (releaseError) {
        if (scope) this.quarantine(scope.repoId, input.runId);
        throw new AggregateError([error, releaseError], 'admission rejected and ownership cleanup failed');
      } finally { releasePermits(); }
      throw error;
    }
    let reconciled: Promise<void> | undefined;
    return {
      ...(lock && scope ? { withWriteGuard: async <T>(workspacePath: string, operation: (assertActive: () => void) => T): Promise<T> => {
        if (workspacePath !== scope.workspacePath) throw new Error('write guard workspace mismatch');
        if (released || retained || writeGuardActive || reconciled) throw new Error('execution lease unavailable');
        writeGuardActive = true;
        try {
          await renewing;
          if (released || retained) throw new Error('execution lease unavailable');
          // Do not let the timer contend with our metadata guard. Renew on both
          // sides while still excluding release; renewal never revives expiry.
          await lock!.renew();
          const value = await lock!.withActiveGuard(check => {
            const assertActive = () => {
              if (released || retained) throw new Error('execution lease unavailable');
              check();
            };
            assertActive(); const result = operation(assertActive);
            if (result !== null && (typeof result === 'object' || typeof result === 'function') && 'then' in result) {
              void Promise.resolve(result).catch(() => {});
              throw new Error('write guard operation must be synchronous');
            }
            assertActive(); return result;
          });
          await lock!.renew();
          return value;
        } catch (error) {
          retained = true; if (timer) clearInterval(timer);
          this.quarantine(scope.repoId, input.runId);
          throw error;
        } finally { writeGuardActive = false; }
      } } : {}),
      assertActive: async () => {
        if (released || retained) throw new Error("execution lease unavailable");
        await lock?.assertActive();
        if (released || retained) throw new Error("execution lease unavailable");
      },
      releaseAfterReconciliation: (verify) => {
        if (writeGuardActive) return Promise.reject(new Error('write guard in progress'));
        if (released) return Promise.resolve();
        if (reconciled) return reconciled;
        if (typeof verify !== 'function') return Promise.reject(new Error('trusted reconciliation verifier required'));
        reconciled = (async () => {
          // Stop renewal first. No authority is freed until the verifier succeeds
          // and the canonical token is released under its filesystem guard.
          if (timer) clearInterval(timer);
          await renewing;
          const result: unknown = await verify();
          if (result !== undefined) throw new Error('invalid reconciliation authority');
          await lock?.release();
          released = true; retained = false;
          if (scope) {
            const owners = this.quarantinedRepositories.get(scope.repoId);
            owners?.delete(input.runId);
            if (owners?.size === 0) this.quarantinedRepositories.delete(scope.repoId);
          }
          releasePermits();
        })().catch((error: unknown) => {
          retained = true;
          if (scope) this.quarantine(scope.repoId, input.runId);
          throw error;
        }).finally(() => { reconciled = undefined; });
        return reconciled;
      },
      retain: (reason) => { retained = true; if (timer) clearInterval(timer); if (scope) this.quarantine(scope.repoId, input.runId); process.stderr.write(`osstack: retaining write lease ${input.runId}: ${reason}\n`); },
      release: async () => {
        if (writeGuardActive) throw new Error('write guard in progress');
        if (released) return;
        if (retained) throw new Error("external stop unconfirmed; reconciliation required before release");
        released = true;
        if (timer) clearInterval(timer);
        await renewing;
        if (retained) { released = false; throw new Error("external stop unconfirmed; reconciliation required before release"); }
        // Ownership failure must not free the in-process writer authority.
        try { await lock?.release(); }
        catch (error) {
          released = false; retained = true;
          if (scope) this.quarantine(scope.repoId, input.runId);
          process.stderr.write(`repository lock release failed; retained ${input.runId}: ${String(error)}\n`);
          throw error;
        }
        releasePermits();
      },
    };
  }
}

import { realpathSync } from "node:fs";
import { randomUUID } from "node:crypto";
import type Database from "better-sqlite3";
import { SessionDecision } from "@osstack/protocol";
import { withWrite } from "./db.js";
import { SessionRepository, type SessionMessageInput } from "./sessions.js";
import {
  AttentionStore,
  attentionDigest,
  type AttentionOwner,
} from "./attention-store.js";
/** Common human reservation, serialized with collaborator writes in the same DB. */
export function reserveSessionInstruction(
  db: Database.Database,
  path: string,
  message: SessionMessageInput,
  version: number,
  now: number,
  takeover = false,
  takeoverGrantId?: string
) {
  return withWrite(db, path, () => {
    const sessions = new SessionRepository(db, path);
    if (sessions.getMessage(message.message_id))
      return sessions.applyInbound(message, version, now);
    if (
      db
        .prepare(
          "SELECT 1 FROM session_messages WHERE session_id=? AND direction='inbound' AND state IN ('accepted','failed') AND message_id NOT IN (SELECT message_id FROM attention_receipt_resolutions) LIMIT 1"
        )
        .get(message.session_id)
    )
      throw new Error("delivery_uncertain");
    if (
      db
        .prepare(
          "SELECT 1 FROM session_continuation_attempts a JOIN session_continuation_grants g ON a.grant_id=g.grant_id WHERE g.session_id=? AND a.status IN ('checking','reserved') LIMIT 1"
        )
        .get(message.session_id)
    )
      throw new Error("continuation_in_flight");
    const grant = db
      .prepare(
        "SELECT grant_id FROM session_continuation_grants WHERE session_id=? AND status='active'"
      )
      .get(message.session_id) as { grant_id: string } | undefined;
    if (grant && takeover && takeoverGrantId !== grant.grant_id)
      throw new Error("takeover_grant_changed");
    if (grant && !takeover) throw new Error("grant_owned");
    const snapshot = sessions.latestSnapshot(message.session_id);
    if (snapshot.state === "awaiting_decision" && snapshot.decision === null)
      throw new Error("invalid_decision");
    const decision = SessionDecision.safeParse(snapshot.decision);
    const raw = snapshot.decision as Record<string, unknown> | null;
    const legacy =
      raw !== null &&
      typeof raw === "object" &&
      !Array.isArray(raw) &&
      Object.keys(raw).every((k) => ["question", "choices"].includes(k)) &&
      Array.isArray(raw["choices"]) &&
      raw["choices"].every((v) => typeof v === "string") &&
      (raw["question"] === undefined || typeof raw["question"] === "string");
    if (snapshot.decision !== null && !decision.success && !legacy)
      throw new Error("invalid_decision");

    if (
      decision.success &&
      ["risk_approval", "task_authorization"].includes(
        decision.data.continuation?.gate_kind ?? ""
      )
    )
      throw new Error("signed_approval_required");
    if (grant)
      db.prepare(
        "UPDATE session_continuation_grants SET status='blocked',reason='human_takeover',updated_at=? WHERE grant_id=?"
      ).run(now, grant.grant_id);
    return sessions.applyInbound(message, version, now);
  });
}
export interface AttentionAnswer {
  scope_id: string;
  item_id: string;
  action_id: string;
  revision: number;
  content_hash: string;
  text: string;
  takeover: boolean;
  takeover_grant_id?: string;
}
interface Action {
  action_id: string;
  scope_id: string;
  item_id: string;
  payload_hash: string;
  message_id: string;
  state: string;
  created_at: number;
  updated_at: number;
}
export class AttentionActions {
  constructor(readonly store: AttentionStore, readonly owner: AttentionOwner) {}
  reserve(input: AttentionAnswer, now = Date.now()) {
    if (
      !input.action_id ||
      input.action_id.length > 256 ||
      !input.text.trim() ||
      input.text.length > 16000
    )
      throw new Error("invalid_answer");
    return this.store.write(this.owner, () => {
      const db = this.store.db;
      const digest = attentionDigest(input);
      const prior = db
        .prepare("SELECT * FROM attention_actions WHERE action_id=?")
        .get(input.action_id) as Action | undefined;
      if (prior) {
        if (prior.payload_hash !== digest)
          throw new Error("action_id_conflict");
        return {
          ...this.reconcile(prior, now),
          replay: true,
          reservation_version: 0,
        };
      }
      const item = this.store.getItem(input.scope_id, input.item_id);
      const scope = this.store.getScope(input.scope_id);
      if (!item || !scope) throw new Error("not_found");
      if (
        item.state !== "open" ||
        item.revision !== input.revision ||
        item.content_hash !== input.content_hash
      )
        throw new Error("stale_item");
      if (
        db
          .prepare("SELECT 1 FROM attention_actions WHERE item_id=?")
          .get(item.item_id)
      )
        throw new Error("action_already_reserved");
      const repo = new SessionRepository(db, this.store.path);
      const source = repo.getSession(item.session_id);
      const latest = repo.latestSnapshot(item.session_id);
      if (source && source.state !== "awaiting_decision")
        throw new Error("session_not_awaiting_decision");
      if (
        !source ||
        source.task_id !== scope.task_id ||
        realpathSync(source.repo_path) !== scope.repo_path ||
        latest.turn_id !== item.turn_id ||
        source.version !== item.source_version ||
        attentionDigest(SessionDecision.parse(latest.decision)) !==
          item.content_hash
      )
        throw new Error("source_changed");
      if (
        !db
          .prepare(
            "SELECT 1 FROM tasks t JOIN runs r ON r.task_id=t.task_id WHERE t.task_id=? AND r.run_id=? AND t.tenant_id IS NULL AND r.tenant_id IS NULL"
          )
          .get(scope.task_id, source.run_id)
      )
        throw new Error("source_changed");
      const messageId = `attention-${randomUUID()}`;
      const reservation = reserveSessionInstruction(
        db,
        this.store.path,
        {
          message_id: messageId,
          session_id: item.session_id,
          turn_id: item.turn_id,
          direction: "inbound",
          kind: "instruction.send",
          payload: { text: input.text },
          state: "accepted",
          created_at: now / 1000,
        },
        source.version,
        now / 1000,
        input.takeover,
        input.takeover_grant_id
      );
      db.prepare(
        "INSERT INTO attention_actions VALUES(?,?,?,?,?,'reserved',?,?)"
      ).run(
        input.action_id,
        input.scope_id,
        input.item_id,
        digest,
        messageId,
        now,
        now
      );
      db.prepare(
        "UPDATE attention_items SET state='answer_reserved',revision=revision+1,updated_at=? WHERE item_id=?"
      ).run(now, item.item_id);
      return {
        action_id: input.action_id,
        scope_id: input.scope_id,
        item_id: input.item_id,
        payload_hash: digest,
        message_id: messageId,
        state: "reserved",
        created_at: now,
        updated_at: now,
        replay: false,
        reservation_version: reservation.session_version,
      };
    });
  }
  replay(input: AttentionAnswer, applyingMessageId?: string) {
    const prior = this.store.db
      .prepare("SELECT * FROM attention_actions WHERE action_id=?")
      .get(input.action_id) as Action | undefined;
    if (!prior) return undefined;
    if (prior.payload_hash !== attentionDigest(input))
      throw new Error("action_id_conflict");
    if (prior.message_id === applyingMessageId)
      return { ...prior, state: "in_flight", replay: true };
    return { ...this.reconcile(prior), replay: true };
  }
  abandon(
    input: {
      scope_id: string;
      session_id: string;
      message_id: string;
      expected_version: number;
      reason: string;
      evidence_sha256: string;
    },
    now = Date.now()
  ) {
    if (
      !input.reason ||
      input.reason.length > 1000 ||
      !/^[a-f0-9]{64}$/.test(input.evidence_sha256)
    )
      throw new Error("resolution_evidence_required");
    return this.store.write(this.owner, () => {
      const db = this.store.db;
      const session = new SessionRepository(db, this.store.path).getSession(
        input.session_id
      );
      if (!session || session.version !== input.expected_version)
        throw new Error("version_conflict");
      const scope = this.store.getScope(input.scope_id);
      if (
        !scope ||
        scope.task_id !== session.task_id ||
        scope.repo_path !== realpathSync(session.repo_path)
      )
        throw new Error("scope_mismatch");
      const message = db
        .prepare(
          "SELECT state FROM session_messages WHERE message_id=? AND session_id=? AND direction='inbound'"
        )
        .get(input.message_id, input.session_id) as
        | { state: string }
        | undefined;
      if (!message || !["accepted", "failed"].includes(message.state))
        throw new Error("receipt_not_uncertain");
      if (
        db
          .prepare(
            "SELECT 1 FROM session_continuation_attempts a JOIN session_continuation_grants g ON a.grant_id=g.grant_id WHERE g.session_id=? AND a.status IN ('checking','reserved')"
          )
          .get(input.session_id)
      )
        throw new Error("continuation_in_flight");
      const prior = db
        .prepare(
          "SELECT * FROM attention_receipt_resolutions WHERE message_id=?"
        )
        .get(input.message_id) as
        | { reason: string; evidence_sha256: string }
        | undefined;
      if (
        prior &&
        (prior.reason !== input.reason ||
          prior.evidence_sha256 !== input.evidence_sha256)
      )
        throw new Error("resolution_conflict");
      db.prepare(
        "INSERT OR IGNORE INTO attention_receipt_resolutions VALUES(?,?,?,'abandoned_unknown',?,?,?)"
      ).run(
        input.message_id,
        input.session_id,
        input.expected_version,
        input.reason,
        input.evidence_sha256,
        now
      );
      db.prepare(
        "UPDATE attention_actions SET state='abandoned_unknown',updated_at=? WHERE message_id=?"
      ).run(now, input.message_id);
      db.prepare(
        "UPDATE attention_items SET state='answer_abandoned',revision=revision+1,updated_at=? WHERE item_id IN (SELECT item_id FROM attention_actions WHERE message_id=?) AND state<>'answer_abandoned'"
      ).run(now, input.message_id);
      return {
        disposition: "abandoned_unknown",
        message_id: input.message_id,
        replayed: false,
        execution_outcome: "unknown",
        next_action:
          "New manual instruction only; original message is never resent",
      };
    });
  }
  recover(): void {
    const rows = this.store.db
      .prepare(
        "SELECT * FROM attention_actions WHERE state IN ('reserved','uncertain')"
      )
      .all() as Action[];
    for (const row of rows) this.reconcile(row);
  }
  reconcile(action: Action, now = Date.now()): Action {
    return this.store.write(this.owner, () => {
      if (
        this.store.db
          .prepare(
            "SELECT 1 FROM attention_receipt_resolutions WHERE message_id=?"
          )
          .get(action.message_id)
      )
        return { ...action, state: "abandoned_unknown" };
      const receipt = this.store.db
        .prepare("SELECT state FROM session_messages WHERE message_id=?")
        .get(action.message_id) as { state: string } | undefined;
      const state =
        receipt?.state === "applied"
          ? "applied"
          : receipt?.state === "failed"
          ? "uncertain"
          : "uncertain";
      this.store.db
        .prepare(
          "UPDATE attention_actions SET state=?,updated_at=? WHERE action_id=?"
        )
        .run(state, now, action.action_id);

export class SessionVersionConflict extends Error {
  constructor(
    readonly session_id: string,
    readonly expected_version: number,
    readonly actual_version: number | null,
  ) {
    super(
      `session ${session_id} version conflict: expected ${expected_version}, `
      + `actual ${actual_version ?? "missing"}`,
    );
    this.name = "SessionVersionConflict";
  }
}

export class SessionMessageIdConflict extends Error {
  constructor(readonly message_id: string) {

  }

function parseSession(row: RawSessionRow): AgentSessionRowType {
  return AgentSessionRow.parse({ ...row, resume_supported: row.resume_supported === 1 });
}

function canonicalJson(value: unknown): string {
  if (value === null || typeof value !== "object") return JSON.stringify(value);
  if (Array.isArray(value)) return `[${value.map(canonicalJson).join(",")}]`;
  const entries = Object.entries(value as Record<string, unknown>)
    .sort(([left], [right]) => left.localeCompare(right));
  return `{${entries.map(([key, item]) => `${JSON.stringify(key)}:${canonicalJson(item)}`).join(",")}}`;
}

  applyInbound(
    input: SessionMessageInput,
    expectedVersion: number,
    appliedAt: number,
  ): ApplyMessageResult {
    const { payload, ...stored } = input;
    const payloadJson = canonicalJson(payload);
    const row = SessionMessageRow.parse({
      ...stored,
      payload_json: payloadJson,
      applied_at: input.applied_at ?? null,
    });

    return withWrite(this.db, this.path, (db) => {
      const existing = db.prepare("SELECT * FROM session_messages WHERE message_id = ?")
        .get(row.message_id) as SessionMessageRowType | undefined;
      if (existing) {
        if (
          existing.session_id !== row.session_id
          || existing.turn_id !== row.turn_id
          || existing.kind !== row.kind
          || existing.payload_json !== payloadJson
        ) {
          throw new SessionMessageIdConflict(row.message_id);
        }
        const session = this.readSession(db, row.session_id);
        return { outcome: "duplicate", session_version: session.version };
      }

      const result = db.prepare(`
        UPDATE agent_sessions
        SET version = version + 1, updated_at = ?
        WHERE session_id = ? AND version = ?
      `).run(appliedAt, row.session_id, expectedVersion);
      if (result.changes !== 1) {
        const actual = db.prepare("SELECT version FROM agent_sessions WHERE session_id = ?")
          .get(row.session_id) as { version: number } | undefined;
        throw new SessionVersionConflict(row.session_id, expectedVersion, actual?.version ?? null);
      }

      db.prepare(`
        INSERT INTO session_messages(
          message_id,session_id,turn_id,direction,kind,payload_json,state,created_at,applied_at
        ) VALUES (?,?,?,?,?,?,?,?,?)
      `).run(
        row.message_id, row.session_id, row.turn_id, row.direction, row.kind,
        payloadJson, row.state, row.created_at, row.applied_at,
      );
      return { outcome: "applied", session_version: expectedVersion + 1 };
    });
  }

      const result = db.prepare(`
        UPDATE session_messages
        SET state = 'applied', applied_at = ?
        WHERE message_id = ? AND state = 'accepted'

      values.push(filter.agent_id);

    if (filter.state !== undefined) {

      where.push("state = ?");

      `).run(...values, updatedAt, sessionId, expectedVersion);

        const actual = db.prepare("SELECT version FROM agent_sessions WHERE session_id = ?")
          .get(sessionId) as { version: number } | undefined;

      }

    });

      .get(sessionId) as RawSessionRow | undefined;
    if (!row) throw new SessionVersionConflict(sessionId, 0, null);
    return parseSession(row);
  }
