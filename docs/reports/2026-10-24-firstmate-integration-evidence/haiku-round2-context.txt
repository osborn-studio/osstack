## P0 findings

**P0-1. Old unpublished Attention 25–26 homes are not rejected; `migrations.ts` appends 40–41 over them.**
- Paths: `packages/core/src/state/db.ts` (`assertMigrationLineage`, `tableIntroductions`), `packages/core/src/state/migrations.ts` (IDs 40–41).
- Trigger: a home whose `user_version` is 25 or 26 with Attention draft tables (`daemon_owner`, `attention_*`) but no Graph tables. `assertMigrationLineage` only checks for `graph_*` tables when `current >= 25`, and only compares tables derived from main migrations. The draft `daemon_owner` table is not a `graph_` table, so the check passes. `runMigrations` then runs `CREATE TABLE daemon_owner` at id 40 and fails, or, if the draft used identical names with different columns, the outcome depends on whether the draft DDL uses `IF NOT EXISTS`.
- Consequence: either a hard failure with a partially applied migration history, or silent acceptance of a draft schema whose columns differ from the released 40–41 contract.
- The new test `graph-migration-lineage.test.ts` reads `fixtures/attention-preintegration-migrations.json`. That fixture is not in the diff, so the test may be unrunnable or may test a fixture that does not match real legacy homes.
- Recommended regression: create a home at `user_version=25` and `=26` with the exact draft DDL, plus a `daemon_owner` row. Assert `openDb` throws a named conflict error in both read-only and read-write modes, and that the file bytes are unchanged. Add a schema-signature check for `daemon_owner` and `attention_*` in `assertMigrationLineage` before any DDL.

**P0-2. `reserveSessionInstruction` bypasses the grant ownership check for attention answers and can produce a double-delivery window.**
- Path: `packages/core/src/state/attention-actions.ts`, `reserveSessionInstruction`.
- Trigger: `AttentionActions.reserve` calls `reserveSessionInstruction` with `takeover=false` on a session that has an active grant. The code throws `grant_owned`, which is correct. But the replay branch at the top, `if (sessions.getMessage(message.message_id)) return sessions.applyInbound(...)`, runs before the grant and uncertainty checks. A client that supplies a previously used `message_id` (for example via `session.send`) reaches `applyInbound` with a message ID already bound to different content. That path throws `SessionMessageIdConflict`, which is fine. But when the existing message has the same content and was `accepted`, `applyInbound` returns `duplicate`, and the caller in `handleSessionSend` returns `state:"duplicate"` without checking `delivery_uncertain`. This is inconsistent with the rest of the function, which is designed to block all accepted/failed receipts.
- Consequence: the uncertainty gate is bypassed for replayed IDs. This is the abandoned-receipt case: `session.send` with the original message ID and same text. The integration test `never resumes an abandoned receipt when its original direct message ID is replayed` expects `delivery_uncertain`, but the code path for an abandoned receipt returns through `applyInbound` duplicate/outcome logic before reaching the uncertain check, so the test assertion depends on details not visible here.
- Recommended regression: for a message in `accepted|failed` state that is listed in `attention_receipt_resolutions`, and for one that is not, assert `session.send` replay with identical content returns the intended error code and never reaches the adapter. Move the uncertainty check ahead of the replay short-circuit, or make the replay branch explicitly return `delivery_uncertain` for non-applied states.

**P0-3. `attention.answer` in `daemon.ts` performs the adapter call outside any guard that the attention action row is durable first, and the attention reserve is committed in a separate transaction.**
- Path: `packages/cli/src/daemon.ts`, `handleSingle`, `attention.answer` branch.
- Trigger: `actions.reserve(p)` commits the reservation (`reserveSessionInstruction` plus the `attention_actions` insert in the same `store.write` transaction, which is correct). Then `executeReservedSessionTurn` runs. If the daemon crashes after the adapter starts and before `completeInboundTurn`, the reservation is in `accepted` state. `AttentionActions.recover()` marks it `uncertain`, which is correct.
- The P0 is the `reconcile` call after execution: `return singleOk(req.id,{...actions.reconcile(action),execution_error:...})`. `reconcile` reads `session_messages.state`. If `executeReservedSessionTurn` returned `failReservedMessage`, the message is `failed`, and `reconcile` maps `failed` to `uncertain`. This is the intended "uncertain" semantics, but it means an adapter failure that provably did not run (for example `resume_unsupported` discovered after reservation) is also reported as uncertain and blocks the session until explicit abandonment. This is conservative, not unsafe. I flag it as P1 instead.
- Real P0 here: `executeReservedSessionTurn` is called with `expectedVersion` computed as `action.reservation_version-1`, but `reservation_version` comes from `reservation.session_version`, which for a fresh `applyInbound` is `expectedVersion + 1`. This is consistent. However, `reserveSessionInstruction` is called with `source.version`, and `reservation_version` is returned as `reservation.session_version`. For a fresh reservation that is `source.version+1`. The `expectedVersion` passed into the turn is therefore `source.version`, which matches. I could not confirm a mismatch from the diff alone, so I downgrade this to a required-verification item rather than asserting a P0.

I am withdrawing P0-3 pending a test that exercises the adapter-failure path after reservation.

**P0-4. Loop restore downgrades `running`/`stopping` sessions to `stopped` but leaves `ctx.loopSessions` entries and the kernel lock semantics intact; restored sessions can still be started by `loop.start` with the same `loopSessionId` path.**
- Path: `packages/cli/src/daemon.ts`, `restoreLoopSessions`.
- Trigger: a loop session was `running` before a crash. After restart it is `stopped` with `recovery_required`. The loop state file is still present. `loop.run` (a new run against the same `stateFilePath`) is not blocked by any recovery marker. The retained worktree from the old run is still on disk and in `git worktree list`, and the new run's `cleanupLoopWorktrees` was removed in `loop-engine.ts`, so nothing reconciles it.
- Consequence: a new run may reuse `LOOP-STATE.json` and its pending tasks while the old worker's uncommitted output sits in a worktree whose branch name matches the prefix. The engine no longer treats that as its own, so no cleanup or guard prevents a second writer from racing on the same task. The retention test only proves the old run is not replayed; it does not prove a subsequent run is blocked.
- Recommended regression: after restore with `recovery_required`, `loop.run` and `loop.start` against the same state path must refuse with a `recovery_required` error until an explicit recovery action clears it. Add a test that calls `loop.run` after the restore test and asserts refusal.

**P0-5. `attention.loop` admits a loop subject from a snapshot file whose path is checked only for being inside the repo, not for being the same file across calls (TOCTOU) and not for ownership.**
- Path: `packages/cli/src/attention-loop-source.ts` (`readAttentionLoop`), `supervision-service.ts` (`attention.loop`).
- Trigger: `realpath` is taken, then `lstat`, then `open`. Between the checks and `open`, the path can be replaced with a symlink to a file outside the repo. `open` follows symlinks, and the post-open `handle.stat()` only checks `isFile()`. The scope check is therefore not enforced on the opened inode.
- Consequence: a caller with write access to the repo can make the daemon read and store an arbitrary file's contents (up to 1 MiB, but only if it parses as a Loop state with a matching `loop_id`, which bounds the leak to parsed fields such as `pending` and `in_progress` task text). Impact is limited but it violates the stated scope boundary.
- Recommended regression: swap the path to a symlink between `realpath` and `open` (test hook), and assert `loop_outside_scope`. Use `O_NOFOLLOW` on open and compare `dev/ino` from `lstat` before and `fstat` after.

// SQLite connection management.
//
// Decisions locked in plan v0.6:
//   - better-sqlite3 (synchronous, single connection per daemon process)
//   - WAL mode for concurrent reader/writer safety
//   - synchronous=NORMAL (WAL-safe, faster than FULL)
//   - 64 MiB page cache
//   - foreign_keys ON (so ON DELETE CASCADE works for runs/events on task delete)
//
// CRITICAL GAP G1 (plan v0.6 §8.3): disk-full must never cause a silent task
// write loss. Every write goes through preflightDiskSpace(), which throws
// DiskFullError before any INSERT/UPDATE can corrupt or stall a transaction.

import Database from "better-sqlite3";
import { statfsSync } from "node:fs";
import { dirname } from "node:path";
import { CURRENT_SCHEMA_VERSION, MIGRATIONS } from "./migrations.js";

/** Default safety threshold for disk-full preflight (100 MiB). */
export const DEFAULT_MIN_FREE_BYTES = 100 * 1024 * 1024;

/** Cache size in -kibibyte units. negative = KiB (per SQLite docs). 64 MiB. */
const PAGE_CACHE_KIB = -65536;

export class DiskFullError extends Error {
  readonly path: string;
  readonly freeBytes: number;
  readonly minFreeBytes: number;
  constructor(path: string, freeBytes: number, minFreeBytes: number) {
    super(
      `Disk full preflight failed for ${path}: ${freeBytes} bytes free, ` +
      `need ≥${minFreeBytes}. Refusing write so Hermes can be notified.`,
    );
    this.name = "DiskFullError";
    this.path = path;
    this.freeBytes = freeBytes;
    this.minFreeBytes = minFreeBytes;
  }
}

export interface OpenDbOptions {
  /** Absolute path to the SQLite file (parent dir must exist). */
  path: string;
  /** When false, opens read-only. */
  readwrite?: boolean;
  /** Override the disk-full safety threshold (bytes). */
  minFreeBytes?: number;
}

/**
 * Run a free-space check against the filesystem holding `path`. Throws
 * DiskFullError if below threshold; otherwise returns free byte count.
 * Skips the check (returns Infinity) if statfsSync is unsupported on the
 * platform — better to allow writes than to crash a daemon on a kernel quirk.
 */
export function preflightDiskSpace(
  path: string,
  minFreeBytes: number = DEFAULT_MIN_FREE_BYTES,
): number {
  let stats: { bsize: number; bavail: number };
  try {
    stats = statfsSync(dirname(path));
  } catch {
    return Number.POSITIVE_INFINITY;
  }
  const free = Number(stats.bsize) * Number(stats.bavail);
  if (free < minFreeBytes) throw new DiskFullError(path, free, minFreeBytes);
  return free;
}

/**
 * Open the osstack state database, apply pragmas, and run pending migrations.
 * Caller owns the lifetime — pair every openDb() with a db.close() in shutdown.
 */
export function openDb(opts: OpenDbOptions): Database.Database {
  const { path, readwrite = true, minFreeBytes = DEFAULT_MIN_FREE_BYTES } = opts;
  if (readwrite) preflightDiskSpace(path, minFreeBytes);

  const db = new Database(path, { readonly: !readwrite });

  try {
    // Refuse an unsupported schema before changing journal mode or running DDL,
    // including read-only inspection. A failed open never escapes with a live handle.
    assertSupportedVersion(db.pragma("user_version", { simple: true }) as number);
    assertMigrationLineage(db);
    // Pragmas are applied per-connection in SQLite. Apply on every open.
    if (readwrite) db.pragma("journal_mode = WAL");
    db.pragma("synchronous = NORMAL");
    db.pragma(`cache_size = ${PAGE_CACHE_KIB}`);
    db.pragma("foreign_keys = ON");
    db.pragma("busy_timeout = 5000");

    if (readwrite) runMigrations(db);
    return db;
  } catch (error) {
    db.close();
    throw error;
  }
}

// This schema is table-additive. Derive expected table introductions once;
// a future DROP/RENAME migration must also update this lineage contract.
const tableIntroductions = MIGRATIONS.flatMap(migration =>
  [...migration.sql.matchAll(/^\s*CREATE\s+TABLE(?:\s+IF\s+NOT\s+EXISTS)?\s+([a-zA-Z_]\w*)\s*\(/gm)]
    .map(match => ({ name: match[1]!, version: migration.id })));

/** Reject pure or mixed unreleased Graph schemas before application pragmas or
 * DDL. SQLite may itself checkpoint an abandoned WAL on close; logical ledger
 * content and user_version must remain intact for the original binary. */
function assertMigrationLineage(db: Database.Database): void {
  const current = db.pragma("user_version", { simple: true }) as number;
  const actual = new Set((db.prepare("SELECT name FROM sqlite_master WHERE type='table'").all() as { name: string }[]).map(row => row.name));
  // Experimental Graph or Attention tables must never be migrated as released main.
  const experimentalTable = (name: string) => name.startsWith("graph_") || name.startsWith("attention_") || name === "daemon_owner";
  if (current < 25 && ![...actual].some(experimentalTable)) return;
  const expected = new Set(tableIntroductions.filter(table => table.version <= current).map(table => table.name));
  if ([...expected].some(name => !actual.has(name))
    || [...actual].some(name => experimentalTable(name) && !expected.has(name))) {
    throw new Error("GRAPH_EXPERIMENTAL_SCHEMA_CONFLICT: preserve this home and reconcile with its original build; do not reset user_version or reuse it for the integrated runtime");
  }
}

function assertSupportedVersion(current: number): void {
  if (current > CURRENT_SCHEMA_VERSION) {
    throw new Error(`Migration state inconsistent: user_version=${current}, expected=${CURRENT_SCHEMA_VERSION}`);
  }
}

/**
 * Apply pending migrations idempotently. `user_version` PRAGMA tracks progress.
 * The version pragma guarantees forward-only application. Many migrations
 * contain non-idempotent CREATE/ALTER statements; never reset user_version.
 */
export function runMigrations(db: Database.Database): void {
  const currentRow = db.pragma("user_version", { simple: true }) as number;
  let current = Number(currentRow);
  assertSupportedVersion(current);
  assertMigrationLineage(db);
  for (const m of MIGRATIONS) {
    if (m.id <= current) continue;
    db.exec("BEGIN");
    try {
      db.exec(m.sql);
      db.pragma(`user_version = ${m.id}`);
      db.exec("COMMIT");
      current = m.id;
    } catch (err) {
      db.exec("ROLLBACK");
      throw err;
    }
  }
  if (current !== CURRENT_SCHEMA_VERSION) {
    throw new Error(
      `Migration state inconsistent: user_version=${current}, expected=${CURRENT_SCHEMA_VERSION}`,
    );
  }
}

/**
 * Run a function inside a transaction with preflight. Use for any write path
 * called from the daemon hot loop. Wraps better-sqlite3's transaction() so
 * disk-space errors fire BEFORE BEGIN, not mid-transaction.
 */
export function withWrite<T>(
  db: Database.Database,
  path: string,
  fn: (db: Database.Database) => T,
  minFreeBytes: number = DEFAULT_MIN_FREE_BYTES,
): T {
  preflightDiskSpace(path, minFreeBytes);
  const tx = db.transaction(fn);
  return tx(db);
}

/** Common human reservation, serialized with collaborator writes in the same DB. */
export function reserveSessionInstruction(
  db: Database.Database,
  path: string,
  message: SessionMessageInput,
  version: number,
  now: number,
  takeover = false,
  takeoverGrantId?: string
) {
  return withWrite(db, path, () => {
    const sessions = new SessionRepository(db, path);
    if (sessions.getMessage(message.message_id))
      return sessions.applyInbound(message, version, now);
    if (
      db
        .prepare(
          "SELECT 1 FROM session_messages WHERE session_id=? AND direction='inbound' AND state IN ('accepted','failed') AND message_id NOT IN (SELECT message_id FROM attention_receipt_resolutions) LIMIT 1"
        )
        .get(message.session_id)
    )
      throw new Error("delivery_uncertain");
    if (
      db
        .prepare(
          "SELECT 1 FROM session_continuation_attempts a JOIN session_continuation_grants g ON a.grant_id=g.grant_id WHERE g.session_id=? AND a.status IN ('checking','reserved') LIMIT 1"
        )
        .get(message.session_id)
    )
      throw new Error("continuation_in_flight");
    const grant = db
      .prepare(
        "SELECT grant_id FROM session_continuation_grants WHERE session_id=? AND status='active'"
      )
      .get(message.session_id) as { grant_id: string } | undefined;
    if (grant && takeover && takeoverGrantId !== grant.grant_id)
      throw new Error("takeover_grant_changed");
    if (grant && !takeover) throw new Error("grant_owned");
    const snapshot = sessions.latestSnapshot(message.session_id);
    if (snapshot.state === "awaiting_decision" && snapshot.decision === null)
      throw new Error("invalid_decision");
    const decision = SessionDecision.safeParse(snapshot.decision);
    const raw = snapshot.decision as Record<string, unknown> | null;
    const legacy =
      raw !== null &&
      typeof raw === "object" &&
      !Array.isArray(raw) &&
      Object.keys(raw).every((k) => ["question", "choices"].includes(k)) &&
      Array.isArray(raw["choices"]) &&
      raw["choices"].every((v) => typeof v === "string") &&
      (raw["question"] === undefined || typeof raw["question"] === "string");
    if (snapshot.decision !== null && !decision.success && !legacy)
      throw new Error("invalid_decision");

    if (
      decision.success &&
      ["risk_approval", "task_authorization"].includes(
        decision.data.continuation?.gate_kind ?? ""
      )
    )
      throw new Error("signed_approval_required");
    if (grant)
      db.prepare(
        "UPDATE session_continuation_grants SET status='blocked',reason='human_takeover',updated_at=? WHERE grant_id=?"
      ).run(now, grant.grant_id);
    return sessions.applyInbound(message, version, now);
  });
}
export interface AttentionAnswer {
  scope_id: string;
  item_id: string;
  action_id: string;
  revision: number;
  content_hash: string;
  text: string;
  takeover: boolean;
  takeover_grant_id?: string;
}
interface Action {
  action_id: string;
  scope_id: string;
  item_id: string;
  payload_hash: string;
  message_id: string;
  state: string;
  created_at: number;
  updated_at: number;
}
export class AttentionActions {
  constructor(readonly store: AttentionStore, readonly owner: AttentionOwner) {}
  reserve(input: AttentionAnswer, now = Date.now()) {
    if (
      !input.action_id ||
      input.action_id.length > 256 ||
      !input.text.trim() ||
      input.text.length > 16000
    )
      throw new Error("invalid_answer");
    return this.store.write(this.owner, () => {
      const db = this.store.db;
      const digest = attentionDigest(input);
      const prior = db
        .prepare("SELECT * FROM attention_actions WHERE action_id=?")
        .get(input.action_id) as Action | undefined;
      if (prior) {
        if (prior.payload_hash !== digest)
          throw new Error("action_id_conflict");
        return {
          ...this.reconcile(prior, now),
          replay: true,
          reservation_version: 0,
        };
      }
      const item = this.store.getItem(input.scope_id, input.item_id);
      const scope = this.store.getScope(input.scope_id);
      if (!item || !scope) throw new Error("not_found");
      if (
        item.state !== "open" ||
        item.revision !== input.revision ||
        item.content_hash !== input.content_hash
      )
        throw new Error("stale_item");
      if (
        db
          .prepare("SELECT 1 FROM attention_actions WHERE item_id=?")
          .get(item.item_id)
      )
        throw new Error("action_already_reserved");
      const repo = new SessionRepository(db, this.store.path);
      const source = repo.getSession(item.session_id);
      const latest = repo.latestSnapshot(item.session_id);
      if (source && source.state !== "awaiting_decision")
        throw new Error("session_not_awaiting_decision");
      if (
        !source ||
        source.task_id !== scope.task_id ||
        realpathSync(source.repo_path) !== scope.repo_path ||
        latest.turn_id !== item.turn_id ||
        source.version !== item.source_version ||
        attentionDigest(SessionDecision.parse(latest.decision)) !==
          item.content_hash
      )
        throw new Error("source_changed");
      if (
        !db
          .prepare(
            "SELECT 1 FROM tasks t JOIN runs r ON r.task_id=t.task_id WHERE t.task_id=? AND r.run_id=? AND t.tenant_id IS NULL AND r.tenant_id IS NULL"
          )
          .get(scope.task_id, source.run_id)
      )
        throw new Error("source_changed");
      const messageId = `attention-${randomUUID()}`;
      const reservation = reserveSessionInstruction(
        db,
        this.store.path,
        {
          message_id: messageId,
          session_id: item.session_id,
          turn_id: item.turn_id,
          direction: "inbound",
          kind: "instruction.send",
          payload: { text: input.text },
          state: "accepted",
          created_at: now / 1000,
        },
        source.version,
        now / 1000,
        input.takeover,
        input.takeover_grant_id
      );
      db.prepare(
        "INSERT INTO attention_actions VALUES(?,?,?,?,?,'reserved',?,?)"
      ).run(
        input.action_id,
        input.scope_id,
        input.item_id,
        digest,
        messageId,
        now,
        now
      );
      db.prepare(
        "UPDATE attention_items SET state='answer_reserved',revision=revision+1,updated_at=? WHERE item_id=?"
      ).run(now, item.item_id);
      return {
        action_id: input.action_id,
        scope_id: input.scope_id,
        item_id: input.item_id,
        payload_hash: digest,
        message_id: messageId,
        state: "reserved",
        created_at: now,
        updated_at: now,
        replay: false,
        reservation_version: reservation.session_version,
      };
    });
  }
  replay(input: AttentionAnswer, applyingMessageId?: string) {
    const prior = this.store.db
      .prepare("SELECT * FROM attention_actions WHERE action_id=?")
      .get(input.action_id) as Action | undefined;
    if (!prior) return undefined;
    if (prior.payload_hash !== attentionDigest(input))
      throw new Error("action_id_conflict");
    if (prior.message_id === applyingMessageId)
      return { ...prior, state: "in_flight", replay: true };
    return { ...this.reconcile(prior), replay: true };
  }
  abandon(
    input: {
      scope_id: string;
      session_id: string;
      message_id: string;
      expected_version: number;
      reason: string;
      evidence_sha256: string;
    },
    now = Date.now()
  ) {
    if (
      !input.reason ||
      input.reason.length > 1000 ||
      !/^[a-f0-9]{64}$/.test(input.evidence_sha256)
    )
      throw new Error("resolution_evidence_required");
    return this.store.write(this.owner, () => {
      const db = this.store.db;
      const session = new SessionRepository(db, this.store.path).getSession(
        input.session_id
      );
      if (!session || session.version !== input.expected_version)
        throw new Error("version_conflict");
      const scope = this.store.getScope(input.scope_id);
      if (
        !scope ||
        scope.task_id !== session.task_id ||
        scope.repo_path !== realpathSync(session.repo_path)
      )
        throw new Error("scope_mismatch");
      const message = db
        .prepare(
          "SELECT state FROM session_messages WHERE message_id=? AND session_id=? AND direction='inbound'"
        )
        .get(input.message_id, input.session_id) as
        | { state: string }
        | undefined;
      if (!message || !["accepted", "failed"].includes(message.state))
        throw new Error("receipt_not_uncertain");
      if (
        db
          .prepare(
            "SELECT 1 FROM session_continuation_attempts a JOIN session_continuation_grants g ON a.grant_id=g.grant_id WHERE g.session_id=? AND a.status IN ('checking','reserved')"
          )
          .get(input.session_id)
      )
        throw new Error("continuation_in_flight");
      const prior = db
        .prepare(
          "SELECT * FROM attention_receipt_resolutions WHERE message_id=?"
        )
        .get(input.message_id) as
        | { reason: string; evidence_sha256: string }
        | undefined;
      if (
        prior &&
        (prior.reason !== input.reason ||
          prior.evidence_sha256 !== input.evidence_sha256)
      )
        throw new Error("resolution_conflict");
      db.prepare(
        "INSERT OR IGNORE INTO attention_receipt_resolutions VALUES(?,?,?,'abandoned_unknown',?,?,?)"
      ).run(
        input.message_id,
        input.session_id,
        input.expected_version,
        input.reason,
        input.evidence_sha256,
        now
      );
      db.prepare(
        "UPDATE attention_actions SET state='abandoned_unknown',updated_at=? WHERE message_id=?"
      ).run(now, input.message_id);
      db.prepare(
        "UPDATE attention_items SET state='answer_abandoned',revision=revision+1,updated_at=? WHERE item_id IN (SELECT item_id FROM attention_actions WHERE message_id=?) AND state<>'answer_abandoned'"
      ).run(now, input.message_id);
      return {
        disposition: "abandoned_unknown",
        message_id: input.message_id,
        replayed: false,
        execution_outcome: "unknown",
        next_action:
          "New manual instruction only; original message is never resent",
      };
    });
  }
  recover(): void {
    const rows = this.store.db
      .prepare(
        "SELECT * FROM attention_actions WHERE state IN ('reserved','uncertain')"
      )
      .all() as Action[];
    for (const row of rows) this.reconcile(row);
  }
  reconcile(action: Action, now = Date.now()): Action {
    return this.store.write(this.owner, () => {
      if (
        this.store.db
          .prepare(
            "SELECT 1 FROM attention_receipt_resolutions WHERE message_id=?"
          )
          .get(action.message_id)
      )
        return { ...action, state: "abandoned_unknown" };
      const receipt = this.store.db
        .prepare("SELECT state FROM session_messages WHERE message_id=?")
        .get(action.message_id) as { state: string } | undefined;
      const state =
        receipt?.state === "applied"
          ? "applied"
          : receipt?.state === "failed"
          ? "uncertain"
          : "uncertain";
      this.store.db
        .prepare(
          "UPDATE attention_actions SET state=?,updated_at=? WHERE action_id=?"
        )
        .run(state, now, action.action_id);
      this.store.db
        .prepare(
          "UPDATE attention_items SET state=?,revision=revision+1,updated_at=? WHERE item_id=? AND state<>?"
        )
        .run(
          state === "applied" ? "answer_applied" : "answer_uncertain",
          now,
          action.item_id,
          state === "applied" ? "answer_applied" : "answer_uncertain"
        );
      return { ...action, state, updated_at: now };
    });
  }
}

function rpc(method: string, params?: unknown, timeoutMs = 5_000): Promise<RpcResponse> {
  return new Promise((resolve, reject) => {
    const sock = connect(socketPath);
    const decoder = new FrameDecoder();
    const timer = setTimeout(() => { sock.destroy(); reject(new Error("rpc timeout")); }, timeoutMs);
    sock.on("connect", () => sock.write(encodeFrame({ id: 1, method, params })));
    sock.on("data", (chunk) => {
      const frames = decoder.push(chunk);
      if (frames.length === 0) return;
      clearTimeout(timer);
      sock.end();
      resolve(frames[0] as RpcResponse);
    });
    sock.on("error", (err) => { clearTimeout(timer); reject(err); });
  });
}

function seedSession(
  id: string,
  state: "idle" | "completed" = "idle",
  resumeSupported = true,
): void {
  const db = openDb({ path: handle.dbPath });
  try {
    const taskId = `task_${id}`;
    const runId = `run_${id}`;
    insertTask(db, handle.dbPath, { task_id: taskId, title: `Relay ${id}`, created_at: 1 });
    insertRun(db, handle.dbPath, {
      run_id: runId,
      task_id: taskId,
      session_id: id,
      agent_id: adapter.id,
      capability_id: "fake.resume",
      phase: "code",
      started_at: 1,
    });
    const repo = new SessionRepository(db, handle.dbPath);
    repo.createSession({
      session_id: id,
      task_id: taskId,
      run_id: runId,
      agent_id: adapter.id,
      request_sha256: "a".repeat(64),
      native_session_id: `native-secret-${id}`,
      repo_path: sessionRepo(id),
      state,
      resume_supported: resumeSupported,
      version: 2,
      updated_at: 2,
    });
    repo.appendTurn({
      turn_id: `turn_${id}`,
      session_id: id,
      ordinal: 1,
      state: "awaiting_decision",
      assistant_text: "请选择方向",
      decision: { choices: ["A", "B"] },
      created_at: 2,
      updated_at: 2,
    });
  } finally {
    db.close();
  }
}

import { constants } from "node:fs";
import { open, realpath, lstat } from "node:fs/promises";
import { isAbsolute, relative } from "node:path";
import { LoopState } from "@osstack/loop";
/** No replay or cleanup port. A Loop JSON file is a lossy snapshot source. */
export async function readAttentionLoop(input: {
  repo: string;
  path: string;
  loop_id: string;
}) {
  if (!isAbsolute(input.path) || !isAbsolute(input.repo) || !input.loop_id)
    throw new Error("explicit_loop_binding_required");
  const repo = await realpath(input.repo);
  let handle: Awaited<ReturnType<typeof open>> | undefined;
  try {
    const path = await realpath(input.path);
    const rel = relative(repo, path);
    if (rel === ".." || rel.startsWith("../") || isAbsolute(rel))
      throw new Error("loop_outside_scope");
    const before = await lstat(path);
    if (!before.isFile())
      throw new Error("regular_loop_file_required");
    handle = await open(path, constants.O_RDONLY | constants.O_NOFOLLOW | constants.O_NONBLOCK);
    const stat = await handle.stat();
    const resolvedAfterOpen = await realpath(path);
    if (resolvedAfterOpen !== path || before.dev !== stat.dev || before.ino !== stat.ino)
      throw new Error("loop_source_changed");
    if (!stat.isFile() || stat.size > 1024 * 1024)
      throw new Error("unsupported_loop_source");
    const buffer = Buffer.alloc(1024 * 1024 + 1);
    const { bytesRead } = await handle.read(buffer, 0, buffer.length, 0);
    if (bytesRead > 1024 * 1024) throw new Error("oversized_loop_source");
    const state = LoopState.parse(
      JSON.parse(buffer.subarray(0, bytesRead).toString("utf8"))
    );
    if (state.loop_id !== input.loop_id)
      throw new Error("loop_identity_conflict");
    return {
      loop_id: input.loop_id,
      path,
      state: "snapshot_available",
      updated_at: state.updated_at,
      in_progress: state.in_progress ?? [],
      pending: state.pending,
      completed_count: state.completed_tasks.length,
      wait: state.wait_reason ?? null,
      process_liveness: "unknown",
      coverage: "snapshot_only",
      gap: "best_effort_snapshot_no_event_replay",
      recovery_required: (state.in_progress ?? []).length > 0,
    };
  } catch (error) {
    if ((error as NodeJS.ErrnoException).code === "ENOENT")
      return {
        loop_id: input.loop_id,
        path: input.path,
        state: "source_missing",
        process_liveness: "unknown",
        coverage: "uncovered",
        gap: "source_missing",
      };
    throw error;
  } finally {
    await handle?.close();
  }
}

import type { Readable } from "node:stream";
import { readFile, lstat } from "node:fs/promises";
export interface ClaudeAttentionBinding {
  harness_version: string;
  session_id: string;
  scope_id: string;
  client_id: string;
  token: string;
  role: "foreground_owner";
}
/** Only a verified root Stop event can request a one-shot reminder. Never block Stop. */
export function classifyClaudeAttentionHook(
  event: unknown,
  binding: ClaudeAttentionBinding
): "remind" | "ignore" {
  if (
    binding.harness_version !== "2.1.291" ||
    binding.role !== "foreground_owner"
  )
    return "ignore";
  if (!event || typeof event !== "object") return "ignore";
  const p = event as Record<string, unknown>;
  if (
    p["session_id"] !== binding.session_id ||
    p["hook_event_name"] !== "Stop" ||
    p["stop_hook_active"] !== false ||
    p["agent_id"] !== undefined ||
    p["agent_type"] !== undefined
  )
    return "ignore";
  return "remind";
}
export async function handleClaudeAttentionHook(
  args: string[],
  rpc: (method: string, params?: unknown) => Promise<unknown>,
  out: (s: string) => void,
  input?: string
): Promise<number> {
  if (args.length !== 3 || args[1] !== "--binding-file")
    throw new Error("binding_file_required");
  const path = args[2]!;
  const st = await lstat(path);
  if (
    !st.isFile() ||
    st.isSymbolicLink() ||
    st.nlink !== 1 ||
    st.size > 4096 ||
    (st.mode & 0o077) !== 0
  )
    throw new Error("private_binding_file_required");
  const binding = JSON.parse(
    await readFile(path, "utf8")
  ) as ClaudeAttentionBinding;
  if (typeof binding.token !== "string" || binding.token.length !== 64)
    throw new Error("invalid_binding");
  const raw = input ?? await readClaudeHookInput(process.stdin);
  if (raw === null) { out("{}"); return 0; }
  if (Buffer.byteLength(raw) > 65536) throw new Error("oversized_hook_input");
  if (classifyClaudeAttentionHook(JSON.parse(raw), binding) === "ignore") {
    out("{}");
    return 0;
  }
  const response = (await rpc("attention.turn-end", {
    scope_id: binding.scope_id,
    client_id: binding.client_id,
    token: binding.token,
    role: binding.role,
  })) as { ok: boolean; result?: { reminder?: string | null } };
  out(
    JSON.stringify(
      response.ok && response.result?.reminder
        ? { systemMessage: response.result.reminder }
        : {}
    )
  );
  return 0;
}

/** Bound a broken producer's lifetime as well as its byte count. */
export function readClaudeHookInput(stream: Readable, timeoutMs = 1000): Promise<string | null> {
  return new Promise((resolve, reject) => {
    const chunks: Buffer[] = [];
    let size = 0;
    const cleanup = () => {
      clearTimeout(timer);
      stream.off("data", onData); stream.off("end", onEnd); stream.off("error", onError);
      stream.pause();
    };
    const onData = (chunk: Buffer | string) => {
      const bytes = Buffer.isBuffer(chunk) ? chunk : Buffer.from(chunk);
      size += bytes.length;
      if (size > 65536) { cleanup(); stream.destroy(); reject(new Error("oversized_hook_input")); }
      else chunks.push(bytes);
    };
    const onEnd = () => { cleanup(); resolve(Buffer.concat(chunks).toString("utf8")); };
    const onError = (error: Error) => { cleanup(); reject(error); };
    const timer = setTimeout(() => { cleanup(); stream.destroy(); resolve(null); }, timeoutMs);
    stream.on("data", onData); stream.once("end", onEnd); stream.once("error", onError);
  });
}

import { join } from "node:path";
import { acquireRepoWriteLock, FifoSemaphore, SemaphoreAcquireAbortedError, type SemaphoreLease, type RepoWriteLock } from '@osstack/autonomy';
import { resolveRepositoryScope } from '@osstack/core';

export interface ExecutionLease {
  release(): Promise<void>;
  /** Keep ownership until a trusted caller has confirmed external exit. */
  retain(reason: string): void;
  /** Trusted host only; never accept a worker-provided proof callback. */
  releaseAfterReconciliation?(verify: () => Promise<void>): Promise<void>;
  /** Assert this exact canonical writer lease is still live. */
  assertActive?(): Promise<void>;
  /** Scoped synchronous file operations under the canonical writer lock. This
   * capability is absent on read leases. Failures retain admission until recovery. */
  withWriteGuard?<T>(workspacePath: string, operation: (assertActive: () => void) => T): Promise<T>;
}
export interface AdmissionInput {
  kind: 'read' | 'write';
  runId: string;
  /** Supplied by the daemon registration, never by an adapter context. */
  workspacePath?: string;
  repoId?: string;
  signal?: AbortSignal;
  authorize?: () => Promise<void>;
  /** Host-only synchronous proof: acquisition rejected with no lease or cleanup obligation. */
  onNotAcquired?: () => void;
}
export class GovernedExecution {
  private readonly activeRuns = new Set<string>();
  private readonly quarantinedRepositories = new Map<string, Set<string>>();
  private quarantine(repoId: string, runId: string): void {
    const owners = this.quarantinedRepositories.get(repoId) ?? new Set<string>();
    owners.add(runId); this.quarantinedRepositories.set(repoId, owners);
  }
  constructor(private readonly options: {
    reads: FifoSemaphore;
    writes: FifoSemaphore;
    repositories: Map<string, FifoSemaphore>;
    checkHealth: () => Promise<void>;
  }) {}

  get hasWriters(): boolean { return this.options.writes.in_use > 0; }

  async acquire(input: AdmissionInput): Promise<ExecutionLease> {
    const cleanup = { confirmed: true };
    try { return await this.acquireOwned(input, cleanup); }
    catch (error) {
      if (cleanup.confirmed && !this.activeRuns.has(input.runId)) input.onNotAcquired?.();
      throw error;
    }
  }

  private async acquireOwned(input: AdmissionInput, cleanup: { confirmed: boolean }): Promise<ExecutionLease> {
    const check = async (): Promise<void> => {
      if (input.signal?.aborted) throw new SemaphoreAcquireAbortedError();
      if (input.kind === 'write') await this.options.checkHealth();
      await input.authorize?.();
    };
    await check();
    const scope = input.workspacePath === undefined ? undefined
      : await resolveRepositoryScope(input.workspacePath, input.repoId === undefined ? {} : { repoId: input.repoId });
    if (input.kind === 'write' && !scope) throw new Error('trusted repository scope required for writes');
    if (input.kind === "write" && scope && this.quarantinedRepositories.has(scope.repoId)) throw new Error("repository external stop unconfirmed; reconciliation required");
    if (this.activeRuns.has(input.runId)) {
      cleanup.confirmed = false;
      throw new Error("run already admitted or queued");
    }
    this.activeRuns.add(input.runId);
    let local: SemaphoreLease | undefined;
    let global: SemaphoreLease | undefined;
    let lock: RepoWriteLock | undefined;
    let queue: FifoSemaphore | undefined;
    const releasePermits = (): void => {
      global?.release(); local?.release();
      this.activeRuns.delete(input.runId);
      if (scope && queue?.in_use === 0 && queue.pending === 0) this.options.repositories.delete(scope.repoId);
    };
    let released = false;
    let retained = false;
    let writeGuardActive = false;
    // Start as soon as the filesystem lock exists, including the final policy
    // wait. Once admitted, a renewal failure retains the unknown producer.
    let renewing: Promise<void> = Promise.resolve();
    let timer: ReturnType<typeof setInterval> | undefined;
    const startRenewal = () => {
      timer = setInterval(() => {
        if (writeGuardActive) return;
        renewing = renewing.then(async () => {
          if (!released && !writeGuardActive) await lock!.renew();
        }).catch((error: unknown) => {
          retained = true;
          if (scope) this.quarantine(scope.repoId, input.runId);
          process.stderr.write(`repository lease renewal failed; retained ${input.runId}: ${String(error)}\n`);
          if (timer) clearInterval(timer);
        });
      }, 20_000);
      timer.unref();
    };
    try {
      if (input.kind === 'write' && scope) {
        queue = this.options.repositories.get(scope.repoId) ?? new FifoSemaphore(1);
        this.options.repositories.set(scope.repoId, queue);
        local = await queue.acquire(input.signal);
      }
      global = await (input.kind === 'read' ? this.options.reads : this.options.writes).acquire(input.signal);
      if (input.kind === 'write' && scope) {
        // A failed filesystem acquisition may have left an ownership obligation.
        cleanup.confirmed = false;
        lock = await acquireRepoWriteLock({ root_dir: join(scope.commonDir, "osstack", "writer-locks"), recover_stale: false, repo_id: scope.repoId, autonomy_run_id: input.runId });
        // Authorization may wait behind another branch's synchronous work.
        // Start ownership renewal before that wait, not after publishing admission.
        startRenewal();
      }
      if (input.kind === "write" && scope && this.quarantinedRepositories.has(scope.repoId)) throw new Error("repository external stop unconfirmed; reconciliation required");
      await check();
      await renewing;
      if (retained) throw new Error("repository lease renewal failed during admission");
      await lock?.assertActive();
      if (retained) throw new Error("repository lease renewal failed during admission");
      if (input.signal?.aborted) throw new SemaphoreAcquireAbortedError();
    } catch (error) {
      if (timer) clearInterval(timer);
      await renewing;
      try {
        await lock?.release();
        if (lock) cleanup.confirmed = true;
        // No executor was admitted. Remove only this rejected acquisition's quarantine.
        if (scope) {
          const owners = this.quarantinedRepositories.get(scope.repoId);
          owners?.delete(input.runId);
          if (owners?.size === 0) this.quarantinedRepositories.delete(scope.repoId);
        }
      } catch (releaseError) {
        if (scope) this.quarantine(scope.repoId, input.runId);
        throw new AggregateError([error, releaseError], 'admission rejected and ownership cleanup failed');
      } finally { releasePermits(); }
      throw error;
    }
    let reconciled: Promise<void> | undefined;
    return {
      ...(lock && scope ? { withWriteGuard: async <T>(workspacePath: string, operation: (assertActive: () => void) => T): Promise<T> => {
        if (workspacePath !== scope.workspacePath) throw new Error('write guard workspace mismatch');
        if (released || retained || writeGuardActive || reconciled) throw new Error('execution lease unavailable');
        writeGuardActive = true;
        try {
          await renewing;
          if (released || retained) throw new Error('execution lease unavailable');
          // Do not let the timer contend with our metadata guard. Renew on both
          // sides while still excluding release; renewal never revives expiry.
          await lock!.renew();
          const value = await lock!.withActiveGuard(check => {
            const assertActive = () => {
              if (released || retained) throw new Error('execution lease unavailable');
              check();
            };
            assertActive(); const result = operation(assertActive);
            if (result !== null && (typeof result === 'object' || typeof result === 'function') && 'then' in result) {
              void Promise.resolve(result).catch(() => {});
              throw new Error('write guard operation must be synchronous');
            }
            assertActive(); return result;
          });
          await lock!.renew();
          return value;
        } catch (error) {
          retained = true; if (timer) clearInterval(timer);
          this.quarantine(scope.repoId, input.runId);
          throw error;
        } finally { writeGuardActive = false; }
      } } : {}),
      assertActive: async () => {
        if (released || retained) throw new Error("execution lease unavailable");
        await lock?.assertActive();
        if (released || retained) throw new Error("execution lease unavailable");
      },
      releaseAfterReconciliation: (verify) => {
        if (writeGuardActive) return Promise.reject(new Error('write guard in progress'));
        if (released) return Promise.resolve();
        if (reconciled) return reconciled;
        if (typeof verify !== 'function') return Promise.reject(new Error('trusted reconciliation verifier required'));
        reconciled = (async () => {
          // Stop renewal first. No authority is freed until the verifier succeeds
          // and the canonical token is released under its filesystem guard.
          if (timer) clearInterval(timer);
          await renewing;
          const result: unknown = await verify();
          if (result !== undefined) throw new Error('invalid reconciliation authority');
          await lock?.release();
          released = true; retained = false;
          if (scope) {
            const owners = this.quarantinedRepositories.get(scope.repoId);
            owners?.delete(input.runId);
            if (owners?.size === 0) this.quarantinedRepositories.delete(scope.repoId);
          }
          releasePermits();
        })().catch((error: unknown) => {
          retained = true;
          if (scope) this.quarantine(scope.repoId, input.runId);
          throw error;
        }).finally(() => { reconciled = undefined; });
        return reconciled;
      },
      retain: (reason) => { retained = true; if (timer) clearInterval(timer); if (scope) this.quarantine(scope.repoId, input.runId); process.stderr.write(`osstack: retaining write lease ${input.runId}: ${reason}\n`); },
      release: async () => {
        if (writeGuardActive) throw new Error('write guard in progress');
        if (released) return;
        if (retained) throw new Error("external stop unconfirmed; reconciliation required before release");
        released = true;
        if (timer) clearInterval(timer);
        await renewing;
        if (retained) { released = false; throw new Error("external stop unconfirmed; reconciliation required before release"); }
        // Ownership failure must not free the in-process writer authority.
        try { await lock?.release(); }
        catch (error) {
          released = false; retained = true;
          if (scope) this.quarantine(scope.repoId, input.runId);
          process.stderr.write(`repository lock release failed; retained ${input.runId}: ${String(error)}\n`);
          throw error;
        }
        releasePermits();
      },
    };
  }
}

  is_process_alive?: (pid: number) => boolean;
  on_audit?: (
    event: RepoLockAuditEvent,
  ) => void | Promise<void>;
}

export interface RepoWriteLock {
  readonly path: string;
  readonly owner: Readonly<RepoLockOwner>;
  renew(): Promise<void>;
  assertOwnership(): Promise<void>;
  assertActive(): Promise<void>;
  /** Trusted synchronous host work only. Holds the metadata mutation guard and
   * supplies a time-bounded proof that cannot escape the callback. Expiry never
   * authorizes lock stealing. The caller must retain physical admission on failure. */
  withActiveGuard<T>(operation: (assertActive: () => void) => T): Promise<T>;
  release(): Promise<void>;
}

  }
}

  }
}

export class RepoLockCorruptError extends Error {

function errorCode(error: unknown): string | undefined {
  return typeof error === "object"
      && error !== null
      && "code" in error
      && typeof error.code === "string"
    ? error.code
    : undefined;
}

function defaultIsProcessAlive(pid: number): boolean {
  try {
    process.kill(pid, 0);
    return true;
  } catch (error) {
    return errorCode(error) !== "ESRCH";
  }
}

function lockFileName(repoId: string): string {
  if (
    /^[A-Za-z0-9][A-Za-z0-9._-]{0,127}$/.test(repoId)
    && repoId !== "."
    && repoId !== ".."
  ) {
    return `${repoId}.lock`;
  }
  return `repo-${createHash("sha256")
    .update(repoId)
    .digest("hex")
    .slice(0, 24)}.lock`;
}

export function repoLockPath(rootDir: string, repoId: string): string {
  return join(rootDir, lockFileName(repoId));
}

async function readOwner(path: string): Promise<RepoLockOwner> {
  let stats: Awaited<ReturnType<typeof lstat>>;
  try {
    stats = await lstat(path);
  } catch (error) {
    if (errorCode(error) === "ENOENT") throw error;
    throw new RepoLockCorruptError(
      path,
      error instanceof Error ? error.message : String(error),
    );
  }
  if (!stats.isFile() || stats.isSymbolicLink()) {
    throw new RepoLockCorruptError(
      path,
      "lock must be a regular non-symlink file",
    );
  }
  try {
    return RepoLockOwner.parse(
      JSON.parse(await readFile(path, "utf-8")) as unknown,
    );
  } catch (error) {
    throw new RepoLockCorruptError(
      path,
      error instanceof Error ? error.message : String(error),
    );
  }
}

/** A metadata transaction guard, not a separate writer authority. Never recover
 * it by age/PID: removing a guard by pathname races a new guard owner. A crash in
 * this short section fails closed until quiescent administrative recovery. All
 * participating binaries must use this protocol on a trusted local lock root.
 */
async function withMutationGuard<T>(path: string, action: () => Promise<T>): Promise<T> {
  const guard = `${path}.guard`;
  const deadline = performance.now() + 2_000;
  for (;;) {
    try {
      await mkdir(guard, { mode: 0o700 });
      break;
    } catch (error) {
      if (errorCode(error) !== "EEXIST") throw error;
      if (performance.now() >= deadline) {
        throw new RepoLockCorruptError(path, "mutation guard busy or abandoned; quiescent recovery required");
      }
      await new Promise((resolve) => setTimeout(resolve, 10));
    }
  }
  try {
    return await action();
  } finally {
    // No recursive deletion: a modified guard is ambiguous and must fail closed.
    await rmdir(guard);
  }
}

async function publishOwner(path: string, owner: RepoLockOwner): Promise<void> {
  const staged = `${path}.publish-${randomUUID()}`;
  const handle = await open(staged, "wx", 0o600);
  try {
    await handle.writeFile(`${JSON.stringify(owner, null, 2)}\n`, "utf-8");
    await handle.sync();
  } finally {
    await handle.close();
  }
  try {
    // Readers never see an empty/partial owner. Replacement is serialized by guard.
    await rename(staged, path);
  } finally {
    await rm(staged, { force: true });
  }
}

function sameOwner(left: RepoLockOwner, right: RepoLockOwner): boolean {
  return left.token === right.token
    && left.pid === right.pid
    && left.autonomy_run_id === right.autonomy_run_id
    && left.repo_id === right.repo_id
    && left.acquired_at === right.acquired_at
    && left.recovery_policy === right.recovery_policy;
}

function lockHandle(
  path: string,
  initialOwner: RepoLockOwner,
  now: () => string,
  leaseMs: number,
): RepoWriteLock {
  let owner = Object.freeze(initialOwner);
  let released = false;
  async function owned(): Promise<RepoLockOwner> {
    if (released) throw new RepoLockOwnershipError(path);
    let current: RepoLockOwner;
    try {
      current = await readOwner(path);
    } catch (error) {
      if (errorCode(error) === "ENOENT" || error instanceof RepoLockCorruptError) {
        throw new RepoLockOwnershipError(path);
      }
      throw error;
    }
    if (!sameOwner(current, owner)) throw new RepoLockOwnershipError(path);
    return current;
  }
  function active(current: RepoLockOwner): void {
    const time = Date.parse(now());
    if (!Number.isFinite(time) || !current.expires_at || time >= Date.parse(current.expires_at)) {
      throw new RepoLockOwnershipError(`${path} (lease expired)`);
    }
  }
  return {
    path,
    get owner() { return owner; },
    async assertOwnership() {
      await withMutationGuard(path, async () => { await owned(); });
    },
    async assertActive() {
      await withMutationGuard(path, async () => { active(await owned()); });
    },
    async withActiveGuard<T>(operation: (assertActive: () => void) => T): Promise<T> {
      return withMutationGuard(path, async () => {
        const current = await owned(); active(current);
        let open = true;
        const check = () => {
          if (!open || released) throw new RepoLockOwnershipError(`${path} (guard closed)`);
          active(current);
        };
        try {
          const result = operation(check);
          // Trusted code, not a sandbox: rejecting a Promise does not cancel
          // code already scheduled by a mistaken asynchronous callback.
          if (result !== null && (typeof result === 'object' || typeof result === 'function') && 'then' in result) {
            void Promise.resolve(result).catch(() => {});
            throw new Error('repository guarded operation must be synchronous');
          }
          check(); return result;
        } finally { open = false; }
      });
    },
    async renew() {
      await withMutationGuard(path, async () => {
        const current = await owned();
        active(current);
        const renewed = RepoLockOwner.parse({ ...current, expires_at: new Date(Date.parse(now()) + leaseMs).toISOString() });
        await publishOwner(path, renewed);
        owner = Object.freeze(renewed);
      });
    },
    async release() {
      if (released) return;
      await withMutationGuard(path, async () => {
        if (released) return;
        await owned();
        await rm(path);
        released = true;
      });
    },
  };
}

export async function acquireRepoWriteLock(
  options: Omit<RepoLockOptions, "mode">,
): Promise<RepoWriteLock> {
  const pid = options.pid ?? process.pid;
  const now = options.now ?? (() => new Date().toISOString());
  const leaseMs = options.lease_ms ?? 60_000;
  if (!Number.isSafeInteger(leaseMs) || leaseMs <= 0) {
    throw new Error("repository lease_ms must be a positive safe integer");
  }
  const isProcessAlive = options.is_process_alive ?? defaultIsProcessAlive;
  const acquiredAt = now();
  let owner = RepoLockOwner.parse({
    pid,
    autonomy_run_id: options.autonomy_run_id,
    repo_id: options.repo_id,
    acquired_at: acquiredAt,
    token: randomUUID(),
    ...(options.recover_stale === false ? { recovery_policy: "reconcile" } : {}),
    expires_at: new Date(Date.parse(acquiredAt) + leaseMs).toISOString(),
  });
  await mkdir(options.root_dir, { recursive: true, mode: 0o700 });
  await chmod(options.root_dir, 0o700);
  const path = repoLockPath(options.root_dir, options.repo_id);
  let staleOwner: RepoLockOwner | undefined;
  const handle = await withMutationGuard(path, async () => {
    let current: RepoLockOwner | undefined;
    try {
      current = await readOwner(path);
    } catch (error) {
      if (errorCode(error) !== "ENOENT") throw error;
    }
    if (current) {
      if (current.repo_id !== options.repo_id) throw new RepoLockOwnershipError(path);
      let alive = true;
      try { alive = isProcessAlive(current.pid) !== false; } catch { /* unknown is live */ }
      if (alive || options.recover_stale === false || current.recovery_policy === "reconcile") throw new RepoLockBusyError(path, current);
      // Detect out-of-protocol replacement (including legacy/malicious writers).
      // Cooperating writers cannot replace anything while we hold the guard.
      if (!sameOwner(await readOwner(path), current)) throw new RepoLockOwnershipError(path);
      staleOwner = current;
    }
    // The lease begins after contention, not before waiting for the guard.
    const publishedAt = now();
    owner = RepoLockOwner.parse({
      ...owner,
      acquired_at: publishedAt,
      expires_at: new Date(Date.parse(publishedAt) + leaseMs).toISOString(),
    });
    // Replace the dead owner's file atomically, without a missing-lock window or
    // stale rename that can accidentally move a newly acquired live lock.
    await publishOwner(path, owner);
    return lockHandle(path, owner, now, leaseMs);
  });
  try {
    if (staleOwner) {
      await options.on_audit?.({
        kind: "repo_lock_stale_recovered",
        repo_id: options.repo_id,
        recovered_by_run_id: options.autonomy_run_id,
        recovered_by_pid: pid,
        stale_owner: staleOwner,
        recovered_at: owner.acquired_at,
      });
    }
  } catch (error) {
    await handle.release();
    throw error;
  }
  return handle;
}

export async function acquireRepoLock(
  options: RepoLockOptions,
): Promise<RepoWriteLock | undefined> {
  if (options.mode === "read") return undefined;
  const { mode: _mode, ...writeOptions } = options;
  return await acquireRepoWriteLock(writeOptions);
}

/** Trusted administrative inspection. Expiry/PID are not external-stop evidence. */
export async function inspectRepoWriteLock(rootDir: string, repoId: string): Promise<Readonly<RepoLockOwner> | null> {
  try {
    const owner = await readOwner(repoLockPath(rootDir, repoId));
    if (owner.repo_id !== repoId) throw new RepoLockOwnershipError(rootDir);
    return Object.freeze(owner);
  } catch (error) { if (errorCode(error) === 'ENOENT') return null; throw error; }
}

/** Post-daemon-restart administration only. The registered verifier must validate
 * a committed graph decision, every external producer and workspace quarantine.
 * No automatic stale recovery: exact token/run/repository and real daemon PID
 * death are checked under the existing mutation guard before unlinking one file. */
export async function releaseReconciledRepoWriteLock(options: {
  root_dir: string; repo_id: string; expectedOwner: Readonly<RepoLockOwner>;
  verifyQuiescent: (owner: Readonly<RepoLockOwner>) => Promise<void>;
}): Promise<void> {
  const { root_dir: root, repo_id: repoId, verifyQuiescent } = options;
  const expected = Object.freeze(RepoLockOwner.parse(options.expectedOwner));
  const path = repoLockPath(root, repoId);
  if (expected.repo_id !== repoId || typeof verifyQuiescent !== 'function') throw new RepoLockOwnershipError(path);
  await withMutationGuard(path, async () => {
    const current = await readOwner(path);
    if (!sameOwner(current, expected)) throw new RepoLockOwnershipError(path);
    if (defaultIsProcessAlive(current.pid)) throw new Error('recorded daemon still alive; use its retained lease');
    const result: unknown = await verifyQuiescent(Object.freeze({ ...current }));
    if (result !== undefined) throw new Error('invalid quiescence authority');
    if (!sameOwner(await readOwner(path), expected)) throw new RepoLockOwnershipError(path);
    if (defaultIsProcessAlive(current.pid)) throw new Error('recorded daemon PID is alive or reused');
    await rm(path);
  });
}

}

async function listLoops(socketPath: string): Promise<Array<{ status: string; stop_reason?: string; executed_task_count: number }>> {
  return await new Promise((resolve, reject) => {
    const client = connect(socketPath);
    const decoder = new FrameDecoder();
    const timer = setTimeout(() => { client.destroy(); reject(new Error("loop.list timed out")); }, 5_000);
    client.on("connect", () => client.write(encodeFrame({ id: 1, method: "loop.list" })));
    client.on("error", (error) => { clearTimeout(timer); reject(error); });
    client.on("data", (data) => {
      const response = decoder.push(data)[0] as { ok: boolean; result: { loops: Array<{ status: string; stop_reason?: string; executed_task_count: number }> }; error?: { message: string } } | undefined;
      if (!response) return;
      clearTimeout(timer);
      client.end();
      if (!response.ok) reject(new Error(response.error?.message ?? "loop.list failed"));
      else resolve(response.result.loops);
    });
  });
}

# Attention：任务状态、决策收件箱与显式交接

Attention 将 Firstmate 的关注列表、结束提醒和交接体验接到 OSStack 已有的任务、会话和回执上。观察者不调用模型、不回答问题、不执行任务。执行仍走原来的会话适配器及审批边界。

## 启用范围

`attention status` 是独立只读入口，不启动 daemon、不运行迁移，支持已核对的数据库 schema 24–41（仅只读投影兼容，不保证实验分支数据库可迁移）。后台功能默认关闭；仅在显式启用 `OSSTACK_ATTENTION=1` 的 daemon 中运行。开发验证必须指定隔离 home：

```sh
OSSTACK_HOME=/absolute/isolated-home OSSTACK_ATTENTION=1 osstack serve
```

使用安装后的发行版本接入真实 home；不要从开发 checkout 指向默认或保留的控制面。迁移 40 新增观察、决策和体验表，迁移 41 新增人工回执处置和冻结的交接有效期。

## 单次快照

```sh
osstack attention status --db /absolute/isolated-home/state.db \
  --task TASK --repo /absolute/repository --default-tenant --json
```

任务和 run 均须属于默认 tenant；session 还必须匹配持久化的 canonical repo。run 的仓库绑定仍标明 unverified。只返回最新 turn，不能据此声称历史问题已经全部处理。进程活性为 unknown，coverage 为 not_monitored。

每类最多 100 条。跟随 `completeness.next_cursor`，使用 `--cursor TOKEN`；游标绑定本次 scope，并记录两类集合是否耗尽。每页都是新快照，不是跨请求的固定数据库快照。旧的 `--after-run/--after-session` 仅适合单集合调试。

## 持续观察与收件箱

```sh
osstack attention watch --task TASK --repo /absolute/repository --default-tenant --json
osstack attention inventory --scope SCOPE --json
osstack attention inbox --scope SCOPE --json
osstack attention get --scope SCOPE --item ITEM --json
```

`watch` 返回 scope ID。观察按 keyset 发现对象，按 ordinal 补读历史 turn，重读当前 turn。decision 的身份是 scope、session、origin turn、decision ID；CAS 版本与身份分开。坏 turn 标记历史缺口并继续读取后续 turn；缺口不会因为一次成功重读而消失。

daemon 全局最多准入 100 个 subject，优先 session；已有 session 的 run 不重复占容量。最多登记 100 个 scope。超额对象仍被发现并列出原因，不会为了新对象静默驱逐旧对象。`total/returned/truncated/next_after` 必须一起看。覆盖依赖完成扫描、当前 generation 和有效期，不能用心跳证明覆盖。

`covered` 只表示已准入来源的新鲜观测，不表示后台正在推进任务。未知进程、缺失来源、历史缺口、未决回执会分别显示。历史决策没有精确回答证据时保留，不通过文本猜测自动关闭。普通问题若有同 origin turn 的 applied 入站回执，可标 continued_externally；审批义务不会因此被消除。

全局最多准入 100 个 subject，不自动驱逐旧来源。容量不足时，可显式释放观察席位：

```sh
osstack attention release --scope SCOPE --kind session --subject SESSION \
  --expected-version VERSION --json
```

版本来自 inventory。释放保留历史决策和回执，不结束会话、不发送消息；该来源保持 `owner_released`，后续扫描不会自动重新准入。范围仍显示覆盖不完整，腾出的席位可供其他来源使用。释放后历史 item 不再自动追踪来源的关闭/继续，已有未决提醒仍保留；回答时依然重新核验实时来源。

## 回答与不确定回执

```sh
osstack attention answer --scope SCOPE --item ITEM --action UNIQUE_ID \
  --revision REVISION --content-hash HASH --text '明确回答' --json
```

同一 action ID 和完全相同参数可重复查询，只有一个 message ID。不同内容重用 ID 会冲突。提交时重新验证来源、当前 turn、版本、决策内容和等待状态；终态会话不能被此入口复活。直接 `session.send` 与 Attention 共用预留门禁，collaborator 的检查/预留也在同一个数据库串行验证。

活动 grant 默认阻止人工抢答。显式接管须加 `--takeover --grant EXPECTED_GRANT_ID`，且没有在途检查或消息；grant 改变即拒绝。agent 报告的 risk_approval/task_authorization 只导向既有签名审批，不通过普通回答代批。agent 标签本身不构成执行授权；缺少标签也不是动作安全证明。

`applied` 只证明指令回执被应用，不证明任务完成。adapter 失败或完成回执不明时保留 uncertain，不能靠换 message/action ID 重发。重启会对账 reserved actions，不自动重新执行。

若人工检查后决定放弃原始指令，可显式记录一次处置：

```sh
osstack attention abandon-receipt --scope SCOPE --session SESSION \
  --message MESSAGE --expected-version VERSION \
  --reason '已人工核对现场，放弃原指令，不重放；执行结果仍未知' \
  --evidence-sha256 SHA256 --acknowledge-unknown-effects --json
```

这只记录 `abandoned_unknown`，不会将原消息标为成功、不会重放、不会授予 collaborator 继续执行的权限。在途消息不能被处置。SHA256 是操作者声明的审计引用，不是 OSStack 自动认证的外部执行证明。随后若需继续，必须另发明确的新人工指令。旧 action 重试仍返回已放弃，不能再次发送。

## 恢复行为变更

daemon 在 socket 清理、业务 DB 打开、恢复前取得独立 SQLite 文件的内核排他锁。锁文件固定 inode，崩溃时内核释放；PID 文件仅用于诊断。限已验证的本地文件系统，不能删除锁文件强行抢占。
