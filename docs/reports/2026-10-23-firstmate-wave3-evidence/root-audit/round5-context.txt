## P1-A (source mutation): mitigated for detection, with residual limits

The source fence (`createDeliverySourceFence`) samples HEAD, the index, and the tracked/untracked/ignored-name snapshot of the original checkout. It runs before `engine.runOnce`, inside the candidate inspection before receipt capture, and again after the run before any success is reported. That covers the case where a builder writes into the source checkout and leaves it changed. The doc now states the limits accurately.

Residual gaps:
- Existing ignored contents, out-of-tree writes, and writes restored before a sample are not detected. This is documented.
- Symlinked intermediate directories are followed by `lstat`/`open` in `snapshotDeliveryWorkspace`, so a tracked directory replaced by a symlink can cause reads outside the checkout. This is read-only and does not affect the write boundary, but it should be fenced.
- Writes after the last sample are not covered: `writeRequestedLoopArtifacts` and `observeLoopProbeEvents(workspacePath, ...)` run after the final check. Whether either writes into the workspace is missing evidence.

## New P1: source fence is over-restrictive on real repositories

The fence reuses the candidate limits on the original checkout. `allFiles.length + ignored.length > 100000` counts ignored entries, so a checkout with a large `node_modules` (or similar dependency trees) fails closed before dispatch with `delivery_candidate_too_many_files`. The candidate worktree is fresh and does not have this problem, so this is a new regression on the changed surface.

The failure also escapes the structured path. `createDeliverySourceFence` is awaited in `handleDeliverCommand` with no `try`, so the error bypasses `deliverBlocked`. The task has already been enqueued at that point. The fix is to wrap construction in `deliverBlocked` and either exclude ignored entries from the source cap or budget them separately. This is a fail-closed availability regression, not a safety breach.

## Blocking contract defect for `pr_opened`

The guide says publication checks cover "remote/repository/ref". In `openPullRequest` the repository comparison is between `contractScope.repository` and `scope.repository`, which both come from the contract, so it is tautological at call time. The real remote check happens only at start. The remote can be rebound between start and PR creation. Until `openPullRequestToGitHub` verifies the target at call time, `pr_opened` claims are not supported by the code, and the guide should be corrected or the check added.

## Legacy `--action` (classified separately, not a V2 blocker)

`assertPostDiffActionAuthorized` returns early for legacy runs below R3, so `--action` does not restrict commit, push, or merge in legacy mode. This is pre-existing behavior, disclosed in the guide and backlog. It is not part of the V2 contract, which enforces `requested_actions` for every risk level. It should be tracked as a legacy item.

export async function persistDeliveryHostRecord(root: string, value: unknown): Promise<DeliveryReceiptReferenceV2> {
  await mkdir(root, { recursive: true, mode: 0o700 });
  const canonicalRoot = await realpath(root);
  const body = `${JSON.stringify(value)}\n`;

  const path = join(canonicalRoot, `${digest}.json`);
  try { await writeFile(path, body, { flag: "wx", mode: 0o600 }); }

export async function readDeliveryHostRecord(root: string, ref: DeliveryReceiptReferenceV2): Promise<unknown> {
  const canonicalRoot = await realpath(root);
  if (!isAbsolute(ref.path) || (await lstat(ref.path)).isSymbolicLink()) throw new Error("delivery_receipt_path_invalid");
  const canonicalPath = await realpath(ref.path);
  const local = relative(canonicalRoot, canonicalPath);
  if (local.startsWith("..") || isAbsolute(local) || !/^[a-f0-9]{64}\.json$/.test(local)
    || local !== `${ref.digest}.json`) throw new Error("delivery_receipt_path_invalid");
  const handle = await open(canonicalPath, constants.O_RDONLY | constants.O_NOFOLLOW);
  try {
    const info = await handle.stat();
    if (!info.isFile() || info.size > 1024 * 1024) throw new Error("delivery_receipt_size_invalid");
    const body = Buffer.alloc(info.size + 1);
    const { bytesRead } = await handle.read(body, 0, body.length, 0);
    if (bytesRead !== info.size) throw new Error("delivery_receipt_size_changed");
    const actual = body.subarray(0, bytesRead);
    if (deliveryBytesDigest(actual) !== ref.digest) throw new Error("delivery_receipt_digest_mismatch");
    return JSON.parse(actual.toString("utf8")) as unknown;
  } finally { await handle.close(); }
}

export async function verifyPersistedDeliveryReceipt(input: {

async function snapshotDeliveryWorkspace(workspace: string, baseHead: string, ignoredDirectories = false) {
  const canonicalWorkspace = await realpath(workspace);
  await deliveryConfig(workspace);
  const flags = (await deliveryGit(workspace, ["ls-files", "-v", "-z"])).split("\0").filter(Boolean);
  if (flags.some(entry => /^[a-zS]/.test(entry))) throw new Error("delivery_hidden_index_flags");
  const tracked = (await deliveryGit(workspace, ["diff", "--no-renames", "--name-only", "-z", baseHead, "--"])).split("\0").filter(Boolean);
  const untracked = (await deliveryGit(workspace, ["ls-files", "--others", "--exclude-standard", "-z"])).split("\0").filter(Boolean);
  const ignored = (await deliveryGit(workspace, ["ls-files", "--others", "--ignored", "--exclude-standard", ...(ignoredDirectories ? ["--directory", "--no-empty-directory"] : []), "-z"])).split("\0").filter(Boolean).sort();
  const paths = [...new Set([...tracked, ...untracked])].sort();
  const allFiles = [...new Set([...flags.map(entry => entry.slice(2)), ...paths])].sort();
  if (allFiles.length + ignored.length > 100000) throw new Error("delivery_candidate_too_many_files");
  const changes: Array<{ path: string; digest: string | null; mode: number | null }> = [];
  let bytes = 0;
  for (const path of allFiles) {
    const absolute = join(workspace, path);
    const parent = await realpath(dirname(absolute)).catch(error => { if ((error as NodeJS.ErrnoException).code === "ENOENT") return undefined; throw error; });
    if (parent !== undefined) { const rel = relative(canonicalWorkspace, parent); if (rel === ".." || rel.startsWith("../") || isAbsolute(rel)) throw new Error("delivery_candidate_parent_escape"); }
    const info = await lstat(absolute).catch(error => { if ((error as NodeJS.ErrnoException).code === "ENOENT") return undefined; throw error; });
    if (!info) { changes.push({ path, digest: null, mode: null }); continue; }
    if (!info.isFile() && !info.isSymbolicLink()) throw new Error("delivery_candidate_file_invalid");
    bytes += info.size;
    if (bytes > 64 * 1024 * 1024) throw new Error("delivery_candidate_too_large");
    let body: string | Buffer;
    if (info.isSymbolicLink()) body = await readlink(absolute);
    else {
      const file = await open(absolute, constants.O_RDONLY | constants.O_NOFOLLOW);
      try {
        const opened = await file.stat();
        if (!opened.isFile() || opened.size !== info.size) throw new Error("delivery_candidate_file_changed");
        body = Buffer.alloc(info.size + 1);
        const { bytesRead } = await file.read(body, 0, body.length, 0);
        if (bytesRead !== info.size) throw new Error("delivery_candidate_file_changed");
        body = body.subarray(0, bytesRead);
      } finally { await file.close(); }
    }
    changes.push({ path, digest: deliveryBytesDigest(body), mode: info.isSymbolicLink() ? 0o120000 : info.mode & 0o111 ? 0o100755 : 0o100644 });
  }
  return { digest: deliveryContractDigest({ baseHead, changes, ignored }), paths, ignored };
}
/** One invocation owns its pre-build baseline and exact check/review snapshot.
 * The same snapshot must survive staging and receipt capture; it is not re-baselined. */
export function createDeliveryVerificationFence(frozen: FrozenDeliveryContractV2) {
  const baselines = new Map<string, { ignored: Set<string>; config: string }>();
  const verified = new Map<string, string>();
  const sample = async (workspace: string) => {
    const baseline = baselines.get(workspace);
    if (!baseline) throw new Error("delivery_verification_baseline_missing");
    if ((await deliveryGit(workspace, ["rev-parse", "HEAD"])).trim() !== frozen.contract.base_head)
      throw new Error("delivery_candidate_base_changed");
    if (await deliveryConfig(workspace) !== baseline.config) throw new Error("delivery_git_config_changed");
    const snapshot = await snapshotDeliveryWorkspace(workspace, frozen.contract.base_head);
    if (snapshot.ignored.some(path => !baseline.ignored.has(path))) throw new Error("delivery_new_ignored_file");
    assertDeliveryContractPaths(frozen, snapshot.paths);
    return snapshot.digest;
  };
  const fence = async (workspace: string): Promise<() => Promise<void>> => {
    verified.delete(workspace);
    const before = await sample(workspace);
    return async () => {
      if (await sample(workspace) !== before) throw new Error("delivery_candidate_changed_during_verification");
      verified.set(workspace, before);
    };
  };
  return Object.assign(fence, {
    prepare: async (workspace: string) => {
      const snapshot = await snapshotDeliveryWorkspace(workspace, frozen.contract.base_head);
      baselines.set(workspace, { ignored: new Set(snapshot.ignored), config: await deliveryConfig(workspace) });
      verified.delete(workspace);
    },
    assertVerified: async (workspace: string) => {
      const digest = verified.get(workspace);
      if (!digest || await sample(workspace) !== digest) throw new Error("delivery_reviewed_candidate_changed");
      return digest;
    },
  });
}

/** Detect changes to the original checkout; this is not a filesystem sandbox.
 * Existing ignored file contents and arbitrary paths outside the checkout are not sampled.
 */
export async function createDeliverySourceFence(workspace: string, baseHead: string): Promise<() => Promise<void>> {
  const sample = async () => {
    const [head, index, snapshot] = await Promise.all([
      deliveryGit(workspace, ["rev-parse", "HEAD"]),
      deliveryGit(workspace, ["ls-files", "--stage", "-z"]),
      snapshotDeliveryWorkspace(workspace, baseHead, true),
    ]);
    return deliveryContractDigest({ head, index, snapshot: snapshot.digest });
  };
  const baseline = await sample();
  return async () => { if (await sample() !== baseline) throw new Error("delivery_source_changed"); };
}

function ensureFlags(args: string[], flags: string[]): string[] {
  const next = [...args];
  for (const flag of flags) {
    if (!next.includes(flag)) next.push(flag);
  }
  return next;
}

export async function suggestVerifyCommand(
  workspacePath: string,
  options: { includeYarn?: boolean } = {},
): Promise<string | undefined> {
  if (await fileExists(join(workspacePath, "pnpm-lock.yaml"))) {
    return "pnpm test";
  }
  if (
    await fileExists(join(workspacePath, "bun.lockb"))
    || await fileExists(join(workspacePath, "bun.lock"))
  ) {
    return "bun test";
  }
  if (await fileExists(join(workspacePath, "package-lock.json"))) {
    return "npm test";
  }
  if (
    options.includeYarn === true
    && await fileExists(join(workspacePath, "yarn.lock"))
  ) {
    return "yarn test";
  }
  try {
    const packageJson = JSON.parse(
      await readFile(join(workspacePath, "package.json"), "utf-8"),
    ) as unknown;
    if (
      isRecord(packageJson)
      && isRecord(packageJson["scripts"])
      && typeof packageJson["scripts"]["test"] === "string"
    ) {
      return "npm test";
    }
  } catch {
    // No package.json or unreadable package metadata.
  }
  return undefined;
}

async function isGitWorktree(workspacePath: string): Promise<boolean> {
  try {
    const { stdout } = await execFileAsync(
      "git",
      ["-C", workspacePath, "rev-parse", "--is-inside-work-tree"],

    );

  } catch {

function parseDeliverGovernanceMode(
  args: string[],
): DeliverGovernanceMode | undefined | Error {
  const index = args.indexOf("--govern");
  if (index < 0) return undefined;
  const value = args[index + 1];
  if (value === undefined || value.startsWith("--")) return "warn";
  if (value === "warn" || value === "strict") return value;
  return new Error("--govern must be warn or strict");
}

function parseDeliverGovernanceScope(
  args: string[],
  mode: DeliverGovernanceMode | undefined,
): DeliverGovernanceScope | undefined | Error {
  const index = args.indexOf("--govern-scope");
  if (index < 0) return mode === undefined ? undefined : "workspace";
  if (mode === undefined) {
    return new Error("--govern-scope requires --govern");
  }
  const value = args[index + 1];
  if (
    value === "workspace"
    || value === "changed"
    || value === "baseline"
  ) {
    return value;
  }
  return new Error(
    "--govern-scope must be workspace, changed, or baseline",
  );
}

function parsePositiveIntegerFlag(
  value: string | undefined,
  name: string,
): number | undefined | Error {
  if (value === undefined) return undefined;
  const parsed = Number(value);
  if (!Number.isInteger(parsed) || parsed < 1) {
    return new Error(`${name} must be a positive integer`);
  }
  return parsed;
}

function firstPositionalValue(
  args: string[],
  flagsWithValues: Set<string>,
): string | undefined {
  return positionalValues(args, flagsWithValues)[0];
}

function positionalValues(
  args: string[],
  flagsWithValues: Set<string>,
): string[] {
  const values: string[] = [];
  for (let i = 0; i < args.length; i++) {
    const arg = args[i]!;
    if (flagsWithValues.has(arg)) {
      i++;
      continue;
    }
    if (arg.startsWith("--")) continue;
    values.push(arg);
  }
  return values;
}

function flagValue(args: string[], name: string): string | undefined {
  const index = args.indexOf(name);
  return index >= 0 && index + 1 < args.length
    ? args[index + 1]
    : undefined;
}

function flagValues(args: string[], name: string): string[] {
  const values: string[] = [];
  for (let i = 0; i < args.length; i++) {
    if (args[i] === name && i + 1 < args.length) {
      values.push(args[i + 1]!);
      i++;
    }
  }
  return values;
}

function isRecord(value: unknown): value is Record<string, unknown> {
  return typeof value === "object"
    && value !== null
    && !Array.isArray(value);
}

async function fileExists(path: string): Promise<boolean> {
  try {
    await stat(path);
    return true;
  } catch {
    return false;
  }
}

function sha256(value: string): string {
  return createHash("sha256").update(value).digest("hex");
}

function uniqueSorted(values: readonly string[]): string[] {
  return [...new Set(values)].sort();
}

function stringIdentityField(
  identity: Record<string, unknown>,
  key: string,
): string {
  const value = identity[key];
  if (typeof value !== "string" || value.length === 0) {
    throw new Error(`runtime identity ${key} is missing`);
  }
  return value;
}

function runtimeIdentity(identity: Record<string, unknown>) {
  const evidenceSource = stringIdentityField(
    identity,
    "evidence_source",
  );
  return {
    provider_id: stringIdentityField(identity, "provider_id"),
    model_id: stringIdentityField(identity, "model_id"),
    evidence_source: evidenceSource,
  };
}

function findingFingerprints(
  completed: LoopState["completed_tasks"][number],
): string[] {
  return uniqueSorted(
    (completed.review_artifacts ?? []).flatMap((artifact) =>
      artifact.findings.map((finding) => finding.fingerprint)
    ),
  );
}

function failedCommands(
  completed: LoopState["completed_tasks"][number],
): string[] {
  return uniqueSorted(
    [
      ...(completed.execution_commands ?? []),
      ...(completed.verify_commands ?? []),
    ]
      .filter((command) => command.exit_code !== 0)
      .map((command) => command.command),
  );
}

function reviewPassed(
  completed: LoopState["completed_tasks"][number],
): boolean {
  const artifacts = completed.review_artifacts ?? [];
  return artifacts.length > 0
    && artifacts.every((artifact) => artifact.verdict === "approved");
}

function countIssueRule(
  completed: LoopState["completed_tasks"][number],
  rule: string,
): number {
  return (completed.verify_issues ?? []).filter(
    (issue) => issue.rule === rule,
  ).length;
}

function countUnauthorizedGovernanceFindings(value: unknown): number {
  if (Array.isArray(value)) {
    return value.reduce(
      (sum, item) => sum + countUnauthorizedGovernanceFindings(item),
      0,
    );
  }
  if (
    typeof value !== "object"
    || value === null
  ) {
    return 0;
  }
  let count = 0;
  for (const [key, child] of Object.entries(value)) {
    if (
      (key === "rule" || key === "rule_id" || key === "code")
      && typeof child === "string"
      && /unauthorized(?:_action)?/i.test(child)
    ) {
      count += 1;
      continue;
    }
    count += countUnauthorizedGovernanceFindings(child);
  }
  return count;
}

    approval_ttl_ms: routing.approval_ttl_ms,
    trusted_approval_public_keys: deps.trustedApprovalPublicKeys,
    consume_approval_nonce: (nonce) =>
      getContractDecision(
        deps.db,
        contractDecisionIdForApprovalNonce(nonce),
      ) !== undefined,
    ...(routing.deploy === undefined
      ? {}
      : { deploy: routing.deploy }),
    git: routing.git,
  };
}

export class GuardedGitRuntime {
  private readonly deps: GuardedGitRuntimeDeps;
  private readonly store: SqliteGuardedDeliveryStore;

  constructor(deps: GuardedGitRuntimeDeps) {
    this.deps = deps;
    this.store = new SqliteGuardedDeliveryStore({
      db: deps.db,
      dbPath: deps.dbPath,
      ...(deps.now === undefined ? {} : { now: deps.now }),
    });
  }

  async start(input: GuardedGitStartInput): Promise<GuardedDeliveryResult> {
    const routing = GuardedGitRouting.parse(input.routing);
    if (routing.delivery_contract) {
      input = { ...input, workspace_path: await realpath(input.workspace_path) };
      const frozen = assertFrozenDeliveryContract(routing.delivery_contract);
      assertDeliveryContractAdmission(frozen, { canonicalRepo: await realpath(input.workspace_path), baseHead: routing.base_commit_sha,
        taskId: input.task_id, goal: input.goal, policyDigest: routing.policy_sha256, reviewPolicyRef: `profile:${routing.profile.profile_name}`,
        acceptedCommands: routing.verify_commands });
      if (frozen.contract.budget_ref !== `policy:${routing.policy_sha256}`) throw new Error("delivery_contract_budget_ref_mismatch");
      if (input.contract_sha256 !== frozen.digest || routing.task.task_id !== input.task_id || routing.task.prompt !== input.goal
        || JSON.stringify(uniqueSorted(input.expected_paths)) !== JSON.stringify(frozen.contract.allowed_paths)
        || JSON.stringify(uniqueSorted(input.requested_actions)) !== JSON.stringify(frozen.contract.requested_actions)) throw new Error("delivery_contract_runtime_identity_mismatch");
      const publication = frozen.contract.publication_scope;
      if (publication.mode !== "none" && (publication.repository.toLowerCase() !== input.repo_id.toLowerCase()
        || publication.remote !== routing.git.remote || publication.base_ref !== routing.git.base || publication.head_ref !== routing.git.branch))
        throw new Error("delivery_contract_publication_scope_mismatch");
    }
    const verifiedBase = await assertGuardedCandidateBase({
      workspace_path: input.workspace_path,
      remote: routing.git.remote,
      base: routing.git.base,
    });
    if (verifiedBase.base_commit_sha !== routing.base_commit_sha) {
      throw new Error(
        "guarded routing base commit does not match the fetched base",
      );
    }
    await this.assertPolicy(routing, input.workspace_path);
    return await this.engine(routing, input.budget).start({
      autonomy_run_id: input.autonomy_run_id,
      task_id: input.task_id,
      repo_id: input.repo_id,
      workspace_path: input.workspace_path,
      goal: input.goal,
      expected_paths: uniqueSorted(input.expected_paths),
      requested_actions: uniqueSorted(input.requested_actions),
      contract_sha256: Sha256.parse(input.contract_sha256),
    });
  }

  async resume(
    autonomyRunId: string,
    decisionValue?: ScopedApprovalDecisionType,
    options: GuardedGitResumeOptions = {},
  ): Promise<GuardedDeliveryResult> {
    const loaded = await this.store.load(autonomyRunId);
    if (loaded === undefined) {
      throw new Error(`autonomy run ${autonomyRunId} was not found`);
    }
    const context = GuardedDeliveryContextSchema.parse(loaded.context);
    const routing = GuardedGitRouting.parse(context.routing);
    const budget = context.budget;
    const intent = context.intent;
    if (budget === undefined || intent === undefined) {
      throw new Error("persisted autonomy run lacks budget or intent");
    }
    // Before local execution, policy must still match the classified
    // authority. Once an exact staged candidate exists, its persisted
    // base/diff digests and the commit port's TOCTOU checks are authoritative.
    // Re-reading a deliberately changed protected policy file here would
    // otherwise make an approved post-diff R3 run impossible to resume.
    if (context.local_result === undefined) {
      await this.assertPolicy(routing, intent.workspace_path);
    }
    return await this.engine(
      routing,
      budget,
      options.recoveryKind,
    ).resume(
      autonomyRunId,
      decisionValue === undefined
        ? undefined
        : ScopedApprovalDecision.parse(decisionValue),
    );
  }

  private engine(

          }),

            && governance?.blocking !== true

          : 0,
      },

          completed,
          "verify.reviewer_mutation",
        ),

          governance?.evidence,

        adapter_unavailable_count: countIssueRule(
          completed,
          "verify.adapter_unavailable",
        ),
      },
      builder_identity: runtimeIdentity(
        routing.profile.builder_identity,
      ),
      evaluator_identity: runtimeIdentity(
        routing.profile.evaluator_identity,
      ),
    });
  }

function pullRequestUrl(
  value: string,
  repo: string,
  expectedNumber?: number,
): URL {
  let url: URL;
  try {
    url = new URL(value.trim());
  } catch {
    throw new Error("GitHub PR URL is malformed");

    `^/${repo.replace(/[.*+?^${}()|[\]\\]/g, "\\$&")}/pull/(\\d+)$`,
    "i",
  );
  const match = url.pathname.match(expectedPath);

    url.hostname !== "github.com" ||

    stats = await lstat(bodyFile);
  } catch {
    throw new Error(`candidate proof body file does not exist: ${bodyFile}`);
  }
  if (!stats.isFile() || stats.isSymbolicLink()) {
    throw new Error("candidate proof body must be a regular non-symlink file");
  }
  if (stats.size < 1 || stats.size > MAX_BODY_BYTES) {
    throw new Error(
      `candidate proof body size must be between 1 and ${MAX_BODY_BYTES} bytes`,
    );
  }
}

async function runOrThrow(
  runner: DeliveryCommandRunner,
  input: GitHubDeliveryInput,
  command: string,
  args: readonly string[],
  operation: string,
  timeoutMs = DEFAULT_COMMAND_TIMEOUT_MS,
): Promise<DeliveryCommandResult> {
  const completed = await runner.run(command, args, {
    cwd: input.workspacePath,
    timeoutMs,
  });
  if (completed.exitCode !== 0) throw commandFailure(operation, completed);
  return completed;
}

function remoteRepository(remoteUrl: string): string | undefined {
  const trimmed = remoteUrl.trim().replace(/\.git$/i, "");
  const scp = trimmed.match(/^git@github\.com:([^/]+\/[^/]+)$/i);
  if (scp?.[1] !== undefined) return scp[1];
  try {
    const url = new URL(trimmed);
    if (url.hostname.toLowerCase() !== "github.com") return undefined;
    const path = url.pathname.replace(/^\/+|\/+$/g, "");
    return /^[^/]+\/[^/]+$/.test(path) ? path : undefined;
  } catch {
    return undefined;
  }
}

function isExplicitMissingPullRequest(completed: DeliveryCommandResult): boolean {
  return /no pull request|no pull requests|could not resolve to a pullrequest/i.test(
    `${completed.stderr}\n${completed.stdout}`,
  );
}

async function resolvePullRequest(
  runner: DeliveryCommandRunner,
  input: GitHubDeliveryInput,
  repo: string,
  pushedCommit: string,
  retryMissing = false,
): Promise<PullRequestLookup | undefined> {
  let lastHead: string | undefined;
  for (let attempt = 1; attempt <= MAX_WRITE_ATTEMPTS; attempt += 1) {
    const completed = await runner.run(
      "gh",
      [
        "pr",
        "view",
        input.branch,
        "--json",
        "number,url,headRefOid,state",
      ],
      {
        cwd: input.workspacePath,
        timeoutMs: DEFAULT_COMMAND_TIMEOUT_MS,
      },
    );
    if (completed.exitCode !== 0) {
      if (isExplicitMissingPullRequest(completed)) {
        if (retryMissing && attempt < MAX_WRITE_ATTEMPTS) continue;
        return undefined;
      }
      throw commandFailure("GitHub PR lookup", completed);
    }
    const parsed = PullRequestLookup.safeParse(
      parseJson(completed.stdout, "GitHub PR lookup"),
    );
    if (!parsed.success) {
      throw new Error("GitHub PR lookup returned ambiguous or malformed metadata");
    }
    pullRequestUrl(parsed.data.url, repo, parsed.data.number);
    if (parsed.data.headRefOid === pushedCommit) return parsed.data;
    lastHead = parsed.data.headRefOid;
  }
  throw new Error(
    `GitHub PR head SHA ${lastHead ?? "unknown"} does not match pushed SHA ${pushedCommit}`,
  );
}

async function pushCandidate(
  runner: DeliveryCommandRunner,
  input: GitHubDeliveryInput,
  contract?: { headCommit: string; fence: () => Promise<void> },
): Promise<void> {
  let last: DeliveryCommandResult | undefined;
  for (let attempt = 1; attempt <= MAX_WRITE_ATTEMPTS; attempt += 1) {
    await contract?.fence();
    last = await runner.run(
      "git",
      contract ? ["push", input.remote, `${contract.headCommit}:refs/heads/${input.branch}`] : ["push", "--set-upstream", input.remote, input.branch],
      {
        cwd: input.workspacePath,
        timeoutMs: PUSH_TIMEOUT_MS,
      },
    );
    if (last.exitCode === 0) return;
  }
  throw commandFailure("git push", last!);
}

async function createPullRequest(
  runner: DeliveryCommandRunner,
  input: GitHubDeliveryInput,
  repo: string,
  pushedCommit: string,
  draft = false,
): Promise<PullRequestLookup> {
  let last: DeliveryCommandResult | undefined;
  for (let attempt = 1; attempt <= MAX_WRITE_ATTEMPTS; attempt += 1) {
    last = await runner.run(
      "gh",
      [
        "pr",
        "create",
        "--base",
        input.base,
        "--head",
        input.branch,
        "--title",
        input.title,
        "--body-file",
        input.bodyFile,
        ...(draft ? ["--draft"] : []),
      ],
      {
        cwd: input.workspacePath,
        timeoutMs: DEFAULT_COMMAND_TIMEOUT_MS,
      },
    );
    if (last.exitCode === 0) {
      pullRequestUrl(last.stdout, repo);
      const resolved = await resolvePullRequest(
        runner,
        input,
        repo,
        pushedCommit,
        true,
      );
      if (resolved === undefined) {
        throw new Error("created PR acknowledgement could not be resolved");
      }
      return resolved;
    }
    const resolved = await resolvePullRequest(
      runner,
      input,
      repo,
      pushedCommit,
      true,
    );
    if (resolved !== undefined) return resolved;
  }
  throw commandFailure("GitHub PR creation", last!);
}

function legacyRequiredChecks(value: unknown): string[] {
  if (typeof value !== "object" || value === null || Array.isArray(value)) {
    throw new Error("legacy branch protection metadata is malformed");
  }
  const status = (value as Record<string, unknown>)["required_status_checks"];
  if (status === null || status === undefined) return [];
  if (typeof status !== "object" || Array.isArray(status)) {
    throw new Error("legacy required status checks metadata is malformed");
  }
  const record = status as Record<string, unknown>;
  const contexts = Array.isArray(record["contexts"])
    ? record["contexts"].filter(
        (entry): entry is string =>
          typeof entry === "string" && entry.length > 0,
      )
    : [];
  const checks = Array.isArray(record["checks"])
    ? record["checks"]
        .map((entry) =>
          typeof entry === "object" && entry !== null
            ? (entry as Record<string, unknown>)["context"]
            : undefined,
        )
        .filter(
          (entry): entry is string =>
            typeof entry === "string" && entry.length > 0,
        )
    : [];
  return [...contexts, ...checks];
}

function rulesetRequiredChecks(rules: readonly z.infer<typeof RulesetRule>[]): string[] {
  const contexts: string[] = [];
  for (const rule of rules) {
    if (rule.type !== "required_status_checks") continue;
    if (
      typeof rule.parameters !== "object" ||
      rule.parameters === null ||
      Array.isArray(rule.parameters)
    ) {
      throw new Error("ruleset required status checks metadata is malformed");
    }
    const required = (rule.parameters as Record<string, unknown>)[
      "required_status_checks"
    ];
    if (!Array.isArray(required)) {
      throw new Error("ruleset required status checks are missing");
    }
    for (const item of required) {
      const context =
        typeof item === "object" && item !== null
          ? (item as Record<string, unknown>)["context"]
          : undefined;
      if (typeof context !== "string" || context.length === 0) {
        throw new Error("ruleset required check context is malformed");
      }
      contexts.push(context);
    }
  }
  return contexts;
}

async function readEffectiveProtection(
  runner: DeliveryCommandRunner,
  input: GitHubDeliveryInput,
  repo: string,
  branch: string,
): Promise<ProtectionEvidence> {
  const encodedBranch = encodeURIComponent(branch);
  const legacy = await runner.run(
    "gh",
    [
      "api",
      `repos/${repo}/branches/${encodedBranch}/protection`,
      "-H",
      "Accept: application/vnd.github+json",
      "-H",
      "X-GitHub-Api-Version: 2026-03-10",
    ],
    {
      cwd: input.workspacePath,
      timeoutMs: DEFAULT_COMMAND_TIMEOUT_MS,
    },
  );
  let legacyValue: unknown | undefined;
  if (legacy.exitCode === 0) {
    legacyValue = parseJson(legacy.stdout, "legacy branch protection");
  } else if (!/HTTP 404|not protected/i.test(`${legacy.stderr}\n${legacy.stdout}`)) {
    throw commandFailure("legacy branch protection lookup", legacy);
  }

  const effectiveRules = await runner.run(
    "gh",
    [
      "api",
      `repos/${repo}/rules/branches/${encodedBranch}`,
      "-H",
      "Accept: application/vnd.github+json",
      "-H",
      "X-GitHub-Api-Version: 2026-03-10",
    ],
    {
      cwd: input.workspacePath,
      timeoutMs: DEFAULT_COMMAND_TIMEOUT_MS,
    },
  );
  if (effectiveRules.exitCode !== 0) {
    throw commandFailure("applicable repository rules lookup", effectiveRules);
  }
  const rulesValue = parseJson(
    effectiveRules.stdout,
    "applicable repository rules",
  );
  const rules = z.array(RulesetRule).safeParse(rulesValue);
  if (!rules.success) {
    throw new Error("applicable repository rules metadata is malformed");
  }
  const requiredChecks = [
    ...(legacyValue === undefined ? [] : legacyRequiredChecks(legacyValue)),
    ...rulesetRequiredChecks(rules.data),
  ];
  return {
    protected: legacyValue !== undefined || rules.data.length > 0,
    requiredChecks: [...new Set(requiredChecks)].sort(),
  };
}

function rollupName(check: z.infer<typeof CheckRollup>): string | undefined {
  return check.context ?? check.name ?? check.workflowName;
}

function checkSucceeded(check: z.infer<typeof CheckRollup>): boolean {
  return (
    check.conclusion?.toUpperCase() === "SUCCESS" ||
    check.state?.toUpperCase() === "SUCCESS"
  );
}

function assertRequiredChecks(
  requiredChecks: readonly string[],
  rollup: readonly z.infer<typeof CheckRollup>[],
): void {
  if (requiredChecks.length === 0) {
    throw new Error("protected base has zero required checks");
  }
  if (rollup.length === 0) {
    throw new Error("current pushed SHA has zero check results");
  }
  for (const required of requiredChecks) {
    const matching = rollup.find((check) => rollupName(check) === required);
    if (matching === undefined) {
      throw new Error(
        `required check ${required} is absent from the current pushed SHA`,
      );
    }
    if (!checkSucceeded(matching)) {
      throw new Error(
        `required check ${required} did not succeed on the current pushed SHA`,
      );
    }
  }
}

async function recoverMergedDelivery(
  runner: DeliveryCommandRunner,
  input: GitHubDeliveryInput,
  repo: string,
  pushedCommit: string,
  pr: PullRequestLookup,
): Promise<GitHubDeliveryResult> {
  if (pr.state !== "MERGED") {
    throw new Error("merged delivery recovery requires a merged PR");
  }
  const baseProtection = await readEffectiveProtection(
    runner,
    input,
    repo,
    input.base,
  );
  if (!baseProtection.protected) {
    throw new Error("base branch has no effective protection");
  }
  const merged = RecoveredMergedPullRequest.parse(
    parseJson(
      (
        await runOrThrow(
          runner,
          input,
          "gh",
          [
            "pr",
            "view",
            String(pr.number),
            "--json",
            "number,state,mergedAt,mergeCommit,url,headRefOid,baseRefName,headRefName,statusCheckRollup",
          ],
          "recovered merged PR proof",
        )
      ).stdout,
      "recovered merged PR proof",
    ),
  );
  pullRequestUrl(merged.url, repo, pr.number);
  if (
    merged.number !== pr.number
    || merged.headRefOid !== pushedCommit
    || merged.baseRefName !== input.base
    || merged.headRefName !== input.branch
  ) {
    throw new Error(
      "recovered merged PR does not match the exact candidate scope",
    );
  }
  assertRequiredChecks(
    baseProtection.requiredChecks,
    merged.statusCheckRollup,
  );
  return {
    pushedCommit,
    pr: {
      number: pr.number,
      url: merged.url,
      reused: true,
    },
    mergeCommit: merged.mergeCommit.oid,
    mergedAt: merged.mergedAt,
  };
}

function assertUniqueCurrentRequiredChecks(requiredChecks: string[], checks: z.infer<typeof CheckRollup>[]): void {
  if (requiredChecks.length === 0 || new Set(requiredChecks).size !== requiredChecks.length) throw new Error("candidate required checks must be nonempty and unique");
  assertRequiredChecks(requiredChecks, checks);
  for (const required of requiredChecks) {
    const matching = checks.filter(check => rollupName(check) === required);
    if (matching.length !== 1 ||
      (matching[0]!.conclusion != null ? matching[0]!.conclusion!.toUpperCase() !== "SUCCESS" : matching[0]!.state?.toUpperCase() !== "SUCCESS") ||
      (matching[0]!.status != null && matching[0]!.status!.toUpperCase() !== "COMPLETED")) throw new Error("candidate current required checks are missing or unsuccessful");
  }
}

/** Stateless current observation only: never push/watch/create/merge or consume cached evidence. */
export async function observeCurrentGreenCandidate(
  value: GitHubDeliveryInput,
  currentContext: CandidateEvidenceContext,
  runner: DeliveryCommandRunner = defaultDeliveryCommandRunner,
): Promise<CandidateEvidence | undefined> {
  const input = GitHubDeliveryInputSchema.parse(value);
  if (input.candidateEvidence !== undefined || input.evidenceContext !== undefined) throw new Error("observer accepts no cached evidence");
  const context = CandidateEvidenceContextSchema.parse(currentContext);
  if (input.branch === input.base || input.branch === "main" || input.branch === "master") throw new Error("refusing protected/base candidate");
  await assertCandidateBody(input.bodyFile);
  for (const ref of [input.branch, input.base]) await runOrThrow(runner, input, "git", ["check-ref-format", "--branch", ref], "observer ref validation");
  const branch = (await runOrThrow(runner, input, "git", ["branch", "--show-current"], "observer branch")).stdout.trim();
  if (branch !== input.branch) throw new Error("observer local branch changed");
  if ((await runOrThrow(runner, input, "git", ["status", "--porcelain=v1", "-z"], "observer clean worktree")).stdout !== "") return undefined;
  const head = GitCommitSha.parse((await runOrThrow(runner, input, "git", ["rev-parse", "HEAD"], "observer local HEAD")).stdout.trim());
  const remoteUrl = (await runOrThrow(runner, input, "git", ["remote", "get-url", input.remote], "observer remote")).stdout;
  const repo = RepoView.parse(parseJson((await runOrThrow(runner, input, "gh", ["repo", "view", "--json", "nameWithOwner"], "observer repository")).stdout, "observer repository")).nameWithOwner;
  if (remoteRepository(remoteUrl)?.toLowerCase() !== repo.toLowerCase()) throw new Error("observer remote repository mismatch");
  const rows = (await runOrThrow(runner, input, "git", ["ls-remote", "--refs", input.remote, `refs/heads/${input.branch}`, `refs/heads/${input.base}`], "observer remote commits")).stdout.trim().split("\n");
  if (rows.length > 2) throw new Error("observer remote metadata has extra rows");
  if (rows.length === 1 && rows[0] === "") return undefined;
  const refs = new Map<string, string>();
  for (const row of rows) {
    const parts = row.split("\t");
    if (parts.length !== 2 || refs.has(parts[1]!) || ![`refs/heads/${input.branch}`, `refs/heads/${input.base}`].includes(parts[1]!)) throw new Error("observer remote metadata malformed");
    refs.set(parts[1]!, GitCommitSha.parse(parts[0]));
  }
  const remoteHead = refs.get(`refs/heads/${input.branch}`), base = refs.get(`refs/heads/${input.base}`);
  if (remoteHead === undefined || base === undefined) return undefined;
  if (remoteHead !== head) return undefined; // A normal pending push, never evidence of current green.
  if ((await readEffectiveProtection(runner, input, repo, input.branch)).protected) throw new Error("observer candidate branch protected");
  const protection = await readEffectiveProtection(runner, input, repo, input.base);
  if (!protection.protected || !protection.requiredChecks.length) return undefined;
  const pr = await resolvePullRequest(runner, input, repo, head);
  if (pr === undefined || pr.state !== "OPEN") return undefined;
  const scope = z.object({ headRefOid: GitCommitSha, baseRefName: z.string(), headRefName: z.string() }).strict().parse(parseJson((await runOrThrow(runner, input, "gh", ["pr", "view", String(pr.number), "--json", "headRefOid,baseRefName,headRefName"], "observer PR scope")).stdout, "observer PR scope"));
  if (scope.headRefOid !== head || scope.baseRefName !== input.base || scope.headRefName !== input.branch) throw new Error("observer PR scope changed");
  const candidate = MergeCandidate.parse(parseJson((await runOrThrow(runner, input, "gh", ["pr", "view", String(pr.number), "--json", "number,url,headRefOid,state,mergeable,mergeStateStatus,statusCheckRollup"], "observer current checks")).stdout, "observer current checks"));
  pullRequestUrl(candidate.url, repo, pr.number);
  if (candidate.number !== pr.number || candidate.headRefOid !== head) throw new Error("observer PR identity changed");
  if (candidate.mergeable !== "MERGEABLE" || candidate.mergeStateStatus !== "CLEAN") return undefined;
  try { assertUniqueCurrentRequiredChecks(protection.requiredChecks, candidate.statusCheckRollup); } catch { return undefined; }
  // Observation is only a hint. The consumer repeats all current remote/CI checks before any merge.
  return CandidateEvidenceSchema.parse({ schemaVersion: 1, repo, headSha: head, baseSha: base, ...context, requiredChecks: protection.requiredChecks, observedAt: new Date().toISOString() });
}

export async function deliverToGitHub(value: GitHubDeliveryInput,
  runner: DeliveryCommandRunner = defaultDeliveryCommandRunner): Promise<GitHubDeliveryResult> {
  return await runGitHubDelivery(value, runner) as GitHubDeliveryResult;
}
/** Existing push/PR implementation with a hard return before CI/merge/deploy.
 * The caller must already hold the existing publish authority and writer lease. */
export async function openPullRequestToGitHub(value: GitHubDeliveryInput,
  scope: { repository: string; headCommit: string; draft: boolean },
  runner: DeliveryCommandRunner = defaultDeliveryCommandRunner): Promise<GitHubPullRequestResult> {
  const checked = z.object({ repository: z.string().regex(/^[A-Za-z0-9_.-]+\/[A-Za-z0-9_.-]+$/),
    headCommit: GitCommitSha, draft: z.boolean() }).strict().parse(scope);
  return await runGitHubDelivery(value, runner, checked);
}
async function runGitHubDelivery(
  value: GitHubDeliveryInput,
  runner: DeliveryCommandRunner,
  openOnly?: { repository: string; headCommit: string; draft: boolean },
): Promise<GitHubDeliveryResult | GitHubPullRequestResult> {
  const input = GitHubDeliveryInputSchema.parse(value);
  if (
    (input.candidateEvidence === undefined) !==
    (input.evidenceContext === undefined)
  )
    throw new Error("candidate evidence requires current controller context");
  await assertCandidateBody(input.bodyFile);
  if (
    input.branch === input.base ||
    input.branch === "main" ||
    input.branch === "master"
  ) {
    throw new Error("refusing to push a protected/base branch");
  }

  await runOrThrow(
    runner,
    input,
    "gh",
    ["auth", "status"],
    "GitHub authentication",
  );
  await runOrThrow(
    runner,
    input,
    "git",
    ["check-ref-format", "--branch", input.branch],
    "candidate branch validation",
  );
  await runOrThrow(
    runner,
    input,
    "git",
    ["check-ref-format", "--branch", input.base],
    "base branch validation",
  );

  const currentBranch = (
    await runOrThrow(
      runner,
      input,
      "git",
      ["branch", "--show-current"],
      "current branch lookup",
    )
  ).stdout.trim();
  if (currentBranch !== input.branch) {
    throw new Error(
      `current branch ${currentBranch || "(detached)"} does not match ${input.branch}`,
    );
  }
  const status = await runOrThrow(
    runner,
    input,
    "git",
    ["status", "--porcelain=v1", "-z"],
    "worktree status",
  );
  if (status.stdout.length !== 0) {
    throw new Error("GitHub delivery requires a clean committed worktree");
  }

  const remoteUrl = (
    await runOrThrow(
      runner,
      input,
      "git",
      ["remote", "get-url", input.remote],
      "Git remote lookup",
    )
  ).stdout;
  const repo = RepoView.parse(
    parseJson(
      (
        await runOrThrow(
          runner,
          input,
          "gh",
          ["repo", "view", "--json", "nameWithOwner"],
          "GitHub repository lookup",
        )
      ).stdout,
      "GitHub repository lookup",
    ),
  ).nameWithOwner;
  const remoteRepo = remoteRepository(remoteUrl);
  if (
    remoteRepo === undefined ||
    remoteRepo.toLowerCase() !== repo.toLowerCase()
  ) {
    throw new Error(
      "Git remote repository does not match authenticated GitHub repository",
    );
  }

  if (openOnly && repo.toLowerCase() !== openOnly.repository.toLowerCase()) throw new Error("publication repository mismatch");
  const candidateProtection = await readEffectiveProtection(
    runner,
    input,
    repo,
    input.branch,
  );
  if (candidateProtection.protected) {
    throw new Error(
      "refusing to push an effectively protected candidate branch",
    );
  }

  const pushedCommit = GitCommitSha.parse(
    (
      await runOrThrow(
        runner,
        input,
        "git",
        ["rev-parse", "HEAD"],
        "candidate commit lookup",
      )
    ).stdout.trim(),
  );
  if (openOnly && pushedCommit !== openOnly.headCommit) throw new Error("publication candidate head mismatch");
  const evidence = input.candidateEvidence;
  async function assertRemoteBinding(): Promise<void> {
    const rows = (
      await runOrThrow(
        runner,
        input,
        "git",
        [
          "ls-remote",
          "--refs",
          input.remote,
          `refs/heads/${input.branch}`,
          `refs/heads/${input.base}`,
        ],
        "candidate remote evidence",
      )
    ).stdout
      .trim()
      .split("\n");
    const expected = new Map([
      [`refs/heads/${input.branch}`, pushedCommit],
      [`refs/heads/${input.base}`, evidence!.baseSha],
    ]);
    if (
      rows.length !== 2 ||
      rows.some((row) => {
        const fields = row.split("\t");
        if (fields.length !== 2 || expected.get(fields[1]!) !== fields[0])
          return true;
        expected.delete(fields[1]!);
        return false;
      }) ||
      expected.size !== 0
    )
      throw new Error("candidate remote head/base binding changed or missing");
  }
  if (evidence !== undefined) {
    const protection = await readEffectiveProtection(
      runner,
      input,
      repo,
      input.base,
    );
    if (!protection.protected)
      throw new Error("base branch has no effective protection");
    assertCandidateEvidenceBinding(
      evidence,
      input.evidenceContext!,
      repo,
      pushedCommit,
      protection.requiredChecks,
    );
    await assertRemoteBinding();
  }
  let pr = await resolvePullRequest(runner, input, repo, pushedCommit);
  if (evidence !== undefined && pr?.state === "MERGED")
    throw new Error("candidate evidence requires current open PR");
  if (pr?.state === "MERGED") {
    if (openOnly) throw new Error("PR-only delivery cannot adopt a merged PR");
    return await recoverMergedDelivery(runner, input, repo, pushedCommit, pr);
  }

  async function assertPublicationState(number: number): Promise<void> {
    const observed = z.object({ isDraft: z.boolean(), state: z.literal("OPEN") }).strict().parse(parseJson(
      (await runOrThrow(runner, input, "gh", ["pr", "view", String(number), "--json", "isDraft,state"], "publication PR state")).stdout, "publication PR state"));
    if (observed.isDraft !== openOnly?.draft) throw new Error("publication draft scope mismatch");
  }
  if (openOnly && pr) await assertPublicationState(pr.number);
  async function assertPullRequestScope(number: number): Promise<void> {
    const identity = z
      .object({
        headRefOid: GitCommitSha,
        baseRefName: z.string(),
        headRefName: z.string(),
      })
      .strict()
      .parse(
        parseJson(
          (
            await runOrThrow(
              runner,
              input,
              "gh",
              [
                "pr",
                "view",
                String(number),
                "--json",
                "headRefOid,baseRefName,headRefName",
              ],
              "candidate scope evidence",
            )
          ).stdout,
          "candidate scope evidence",
        ),
      );
    if (
      identity.headRefOid !== pushedCommit ||
      identity.baseRefName !== input.base ||
      identity.headRefName !== input.branch
    )
      throw new Error("candidate PR scope binding mismatched");
  }
  if (evidence !== undefined) {
    if (pr === undefined || pr.state !== "OPEN")
      throw new Error("candidate evidence requires current open PR");
    await assertPullRequestScope(pr.number);
  } else {
    if (openOnly) await assertPublicationDestination();
    await pushCandidate(runner, input, openOnly ? { headCommit: openOnly.headCommit, fence: assertPublicationDestination } : undefined);
  }
  const afterPushCommit = GitCommitSha.parse(
    (
      await runOrThrow(
        runner,
        input,
        "git",
        ["rev-parse", "HEAD"],
        "post-push commit lookup",
      )
    ).stdout.trim(),
  );
  if (afterPushCommit !== pushedCommit) {
    throw new Error("local HEAD changed after push; refusing PR delivery");
  }

  async function assertPublicationDestination(): Promise<void> {
    const currentRemote = (await runOrThrow(runner, input, "git", ["remote", "get-url", input.remote], "publication remote fence")).stdout.trim();
    const currentBranch = (await runOrThrow(runner, input, "git", ["branch", "--show-current"], "publication branch fence")).stdout.trim();
    const currentHead = (await runOrThrow(runner, input, "git", ["rev-parse", "HEAD"], "publication head fence")).stdout.trim();
    if (remoteRepository(currentRemote)?.toLowerCase() !== openOnly?.repository.toLowerCase()
      || currentBranch !== input.branch || currentHead !== openOnly?.headCommit) throw new Error("publication destination changed");
  }
  if (openOnly) await assertPublicationDestination();
  let reused = pr !== undefined;
  if (pr === undefined) {
    pr = await resolvePullRequest(runner, input, repo, pushedCommit);
    reused = pr !== undefined;
    if (pr === undefined) {
      pr = await createPullRequest(runner, input, repo, pushedCommit, openOnly?.draft ?? false);
      reused = false;
    }
  }
  if (pr.state === "MERGED") {
    if (openOnly) throw new Error("PR-only delivery cannot adopt a merged PR");
    return await recoverMergedDelivery(runner, input, repo, pushedCommit, pr);
  }

  if (openOnly) {
    await assertPullRequestScope(pr.number);
    await assertPublicationState(pr.number);
    return { pushedCommit, pr: { number: pr.number, url: pr.url, reused } };
  }
  if (evidence === undefined) {
    const checks = await runner.run(
      "gh",
      ["pr", "checks", String(pr.number), "--watch", "--fail-fast"],
      {
        cwd: input.workspacePath,
        timeoutMs: input.ciTimeoutMs,
      },
    );
    if (checks.exitCode === 124) {
      throw new Error(`CI timeout after ${input.ciTimeoutMs} ms`);
    }
    if (checks.exitCode !== 0) throw commandFailure("CI checks", checks);
  }

  const baseProtection = await readEffectiveProtection(
    runner,
    input,
    repo,
    input.base,
  );
  if (!baseProtection.protected) {
    throw new Error("base branch has no effective protection");
  }

  const mergeCandidate = MergeCandidate.parse(
    parseJson(
      (
        await runOrThrow(
          runner,
          input,
          "gh",
          [
            "pr",
            "view",
            String(pr.number),
            "--json",
            "number,url,headRefOid,state,mergeable,mergeStateStatus,statusCheckRollup",
          ],
          "merge candidate lookup",
        )
      ).stdout,
      "merge candidate lookup",
    ),
  );
  pullRequestUrl(mergeCandidate.url, repo, pr.number);
  if (mergeCandidate.number !== pr.number) {
    throw new Error("merge candidate metadata resolved to a different PR");
  }
  if (mergeCandidate.headRefOid !== pushedCommit) {
    throw new Error("PR head SHA changed after checks; refusing merge");
  }
  if (
    mergeCandidate.mergeable !== "MERGEABLE" ||
    mergeCandidate.mergeStateStatus !== "CLEAN"
  ) {
    throw new Error(
      `PR is not cleanly mergeable: ${mergeCandidate.mergeable}/${mergeCandidate.mergeStateStatus}`,
    );
  }
  assertRequiredChecks(
    baseProtection.requiredChecks,
    mergeCandidate.statusCheckRollup,
  );

  if (evidence !== undefined) {
    assertCandidateEvidenceBinding(
      evidence,
      input.evidenceContext!,
      repo,
      pushedCommit,
      baseProtection.requiredChecks,
    );
    assertUniqueCurrentRequiredChecks(baseProtection.requiredChecks, mergeCandidate.statusCheckRollup);
    await assertPullRequestScope(pr.number);
    await assertRemoteBinding();
  }
  await runOrThrow(
    runner,
    input,
    "gh",
    [
      "pr",
      "merge",
      String(pr.number),
      "--squash",
      "--delete-branch",
      "--match-head-commit",
      pushedCommit,
    ],
    "SHA-bound PR merge",
  );

  const merged = MergedPullRequest.parse(
    parseJson(
      (
        await runOrThrow(
          runner,
          input,
          "gh",
          [
            "pr",
            "view",
            String(pr.number),
            "--json",
            "state,mergedAt,mergeCommit,url,headRefOid",
          ],
          "merged PR proof",
        )
      ).stdout,
      "merged PR proof",
    ),
  );
  pullRequestUrl(merged.url, repo, pr.number);
  if (merged.headRefOid !== pushedCommit) {
    throw new Error("merged PR head does not match the pushed commit");
  }
  return {
    pushedCommit,
    pr: {
      number: pr.number,
      url: pr.url,
      reused,
    },
    mergeCommit: merged.mergeCommit.oid,
    mergedAt: merged.mergedAt,
  };
}

# Delivery Contract V2: guarded host execution

V2 freezes an explicit task and completion ceiling before guarded execution. It constrains existing host policy; a contract file, a parsed schema, or a reference to a policy does not grant permission to execute, publish, merge or deploy. V1 planning artifacts remain offline material and are rejected by this runtime.

Use `osstack deliver --workspace <repo> --profile <profile> --autonomy guarded-local --contract <file> --json`. The host must supply a policy snapshot, its registered verification commands and budget. Guarded Git uses the same `--contract` option with `--autonomy guarded-git`. A `--execution-context <config>` option selects the separately documented pinned local context flow. Existing invocations without a contract retain their original behavior.

The strict JSON contract declares schema version 2, contract/task IDs, canonical repository, full base commit, goal, allowed relative path prefixes, required check IDs with `sha256:<command digest>` registry references, profile review reference, `policy:<policy digest>` budget reference, policy digest, actions, publication scope and requested completion. Required commands must already be registered in the host policy. An explicit unregistered `--verify` is rejected; contract content never becomes an executable command. Implement mode requires build and verify actions. Scout execution is rejected until a host can guarantee a tool-free executor; the pure promotion helper creates a new contract and carries no prior receipt or approval.

| Requested completion | Runtime boundary |
| --- | --- |
| `local_verified` | Host checks, independent reported review, policy and governance checks; no host commit, push or merge. Guarded-local retains its isolated candidate worktree. |
| `pr_opened` | Existing authorized commit/push/PR code; exact candidate SHA, remote/repository/ref and draft state checks; returns before CI waiting or merge. |
| `merged` | Existing guarded merge authorization and proof flow; configured deployment is not invoked. |
| `deployed` | Existing guarded deployment policy and action checks; skipped or unhealthy deployment cannot satisfy the contract. |

Local execution snapshots all tracked worktree bytes, untracked candidate files and the ignored-path set before checks and review, then carries that exact snapshot through receipt capture. Hidden index flags and new ignored files fail closed. Existing ignored dependency contents are not a hermetic environment qualification. The opt-in snapshot is bounded to 100,000 paths and 64 MiB of candidate/worktree file bytes. Rename sources and destinations are both checked against allowed paths. Scope, governance or verification rejection leaves the isolated candidate available for inspection; the original workspace is not merged. JSON output includes its candidate path. A successful local receipt is not a remote CI result, provider attestation or production acceptance.

The local host maps policy builder/review limits to iteration limits and applies the existing cooperative Loop runtime/no-progress budget. CLI iteration and command timeout values can only tighten those limits. This is not a hard wall-clock cancellation SLA. Git execution retains its existing guarded budget and approval controls.

Host receipts record the frozen contract digest, policy digest, base/candidate tree and diff identity, actual command results, reported independent review identity and context receipt references. Different adapter IDs plus different provider or model follows the existing profile independence rule; metadata is reported, not independently provider-attested. Content-addressed receipts reject changed bytes, symlinks, paths outside their host evidence directory and oversized records. Before side effects, the host reloads its persisted receipt and checks the actual candidate against the known base, recorded commit or recorded merge HEAD and the verified tree/diff.

Guarded Git persists the frozen contract and receipt references in its existing autonomy context. Resume requires the same persisted contract and policy; it does not reread a replacement CLI contract file. Limited completion writes a separate host completion record alongside the candidate proof. Reference validation alone must never be used to promote arbitrary external JSON into trusted evidence.

Context receipts distinguish prepared prompts from prompts observed at the adapter boundary, and record original knowledge-source repository separately from the candidate execution repository. These hashes describe `AgentTask.prompt`, not provider wire bytes or a qualified token window.

Validation for this slice covers real local Git, Loop execution, SQLite persistence and restart boundaries with fake adapters and simulated GitHub command responses. It does not qualify live external publishing, deployment, retention history, Graph integration or tool sandboxing. Those qualifications remain separate work.

V2 guarded-local stores its default queue, state, verification receipts, reports and proof artifacts in a unique directory under the explicit OSStack home, so host bookkeeping does not write into the source checkout. An explicit `--state` still selects the operator-requested location. Candidate worktree Git metadata remains intentionally registered for inspection. For guarded Git, the contract pins the committed base policy; after an approved candidate edits policy files, the original base policy plus the current private overlay remains the authority for that run. Candidate integrity and scoped approvals still gate every effect; new policy is not silently self-authorized.

The V2 local host also compares original checkout HEAD, index entries, all tracked/untracked file bytes and ignored directory roots before execution and at final verification. A change fails completion and is left in place for inspection; OSStack does not silently revert it. This is detection, not confinement: adapters can still access other paths, existing ignored dependency contents are not hashed, and transient writes restored before sampling cannot be proven absent. Keep explicit state/output locations outside the source checkout when using this check. Legacy `--action` is an intent/risk-classification input; only V2 `requested_actions` is the enforced per-effect allowlist in this slice.

Source sampling collapses existing ignored directories (for example `node_modules/`) to directory roots, so dependency file count does not consume the source path limit. Tracked/untracked source bytes remain bounded to 64 MiB and 100,000 source entries. Unsupported/oversized source sampling returns a structured blocked result before task enqueue; it does not silently weaken the check.

async function observeLoopProbeEvents(
  workspacePath: string,
  events: readonly unknown[],
): Promise<LoopProbeObservationSummaryV1 | undefined> {
  if (!events.some((event) =>
    isRecord(event) && event["type"] === "loop.implementation.deviation"
  )) {
    return undefined;
  }
  try {
    const sourceRevision = await gitOutput(workspacePath, ["rev-parse", "HEAD"]);
    if (sourceRevision instanceof Error || sourceRevision.trim() === "") {
      throw new Error("structured implementation deviations require a Git source revision");
    }
    const repoRoot = realpathSync(workspacePath);
    const db = openDb({ path: await ensureLocalStateDbPath() });
    try {
      const { resolveProbeRepositoryId } = await import("./probe-command.js");
      const { observeLoopImplementationDeviations } = await import("./loop-probe-observer.js");
      const observation = await observeLoopImplementationDeviations({
        db,
        repo_root: repoRoot,
        repo_id: await resolveProbeRepositoryId(repoRoot),
        source_revision: sourceRevision.trim(),
        events,
        now_ms: Date.now(),
        create_item_id: () => `pi_${randomUUID()}`,
        create_event_id: () => `pe_${randomUUID()}`,
      });
      return { status: "ok", ...observation };
    } finally {
      db.close();
    }
  } catch (error) {
    return {
      status: "error",
      message: error instanceof Error ? error.message : String(error),
    };
  }
}


async function writeRequestedLoopArtifacts(
  state: LoopState,
  workspacePath: string,
  args: string[],
  events: LoopEvent[] = [],
  governanceOverride?: GovernanceProofEvidence,
  outputDirectory?: string,
): Promise<LoopEvidenceArtifacts | undefined> {
  const { createLoopStateScorecardFromState, renderLoopStateScorecardHtml, renderLoopStateScorecardMarkdown } = await loadLoop();
  if (!hasRequestedLoopArtifacts(args)) return undefined;

  const artifacts: LoopEvidenceArtifacts = {};
  const loopId = safeFileSegment(state.loop_id);

  if (args.includes("--report")) {
    const reportDir = join(outputDirectory ?? workspacePath, "reports");
    const reportPath = join(reportDir, `osstack-report-${loopId}.md`);
    await mkdir(reportDir, { recursive: true });
    await writeFile(reportPath, await renderReportMarkdownForArtifacts(state, events), "utf-8");
    artifacts.report = reportPath;
  }

  if (args.includes("--scorecard")) {
    const releaseDir = join(outputDirectory ?? workspacePath, "release");
    const scorecard = createLoopStateScorecardFromState(state);
    const markdownPath = join(releaseDir, `osstack-scorecard-${loopId}.md`);
    const htmlPath = join(releaseDir, `osstack-scorecard-${loopId}.html`);
    await mkdir(releaseDir, { recursive: true });
    const language = resolveLanguage(flagValue(args, "--lang"));
    await writeFile(markdownPath, renderLoopStateScorecardMarkdown(scorecard, { language }), "utf-8");
    await writeFile(htmlPath, renderLoopStateScorecardHtml(scorecard, { language }), "utf-8");
    artifacts.scorecard_markdown = markdownPath;
    artifacts.scorecard_html = htmlPath;
  }

  if (args.includes("--proof")) {
    const governance = governanceOverride ?? await scanWorkspaceGovernance(workspacePath);
    const knowledge = await createKnowledgeProofEvidence(args, state.loop_id, state.knowledge);
    const proof = await writeProofPack(state, join(outputDirectory ?? workspacePath, "release"), events, state.loop_id, governance, knowledge, [], workspacePath);
    artifacts.proof_dir = proof.proof_dir;
    artifacts.proof_zip = proof.proof_zip;
    artifacts.proof_manifest = proof.proof_manifest;
  }

  return artifacts;
}
