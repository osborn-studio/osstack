# Wave 3: host-bound delivery, execution context, local homes and lessons

This branch depends on PR #239. It implements a local V2 delivery contract through the existing guarded delivery engine, an opt-in pinned execution-context pipeline at the actual adapter invocation, read-only explicit home inventory, and evidence-backed investigation lesson drafts. It does not claim full Firstmate parity, deployment, Graph delivery qualification, remote operation or public message delivery.

The real CLI entrypoint test runs committed host policy, real Git/Loop candidate isolation and the private context receipt writer. It asserts that the source HEAD/content are unchanged, the delivery receipt binds the frozen contract and every context receipt hashes the prompt actually received by the controlled adapter. Adapters are fixtures; no provider quality or external publication is inferred. The component reports and raw audit inputs/results are under contracts/, context/, homes/ and lessons/.

Completion levels are explicit. V2 checks select committed host registry entries, budgets constrain existing execution, publication scope constrains the existing publisher, and merge authority does not grant approval. A final workspace digest fences changes across tests/review/governance/staging. Existing ignored dependency contents remain outside hermetic qualification; same-UID filesystem races and physical process termination are not asserted away. Graph and scout V2 execution are unsupported in this slice.

Home inventory performs bounded reads from explicit same-UID sockets, verifies pinned identity and selected desired fields, and never opens or migrates another home database. It is not an updater. Lessons from ordinary runs are investigation-only drafts with explicit unverified qualification; create-only draft handling preserves manual edits, and promotion remains explicit.

Root integration validation and independent review are recorded separately from component audits. Requested Claude Code CLI model is claude-haiku-5-5; returned model metadata and any unrecognized-model warning are retained, not treated as independent model-weight attestation. Full qualification and exact-head CI must pass before the PR is marked ready.
