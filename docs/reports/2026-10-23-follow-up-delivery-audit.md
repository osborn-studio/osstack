# O2a public delivery component verification

This component implements a local authorization and attempt ledger, with no production provider, external target configuration or authority issuer enabled. Real public delivery, physical power-loss qualification and integrated daemon/bin qualification remain pending.

Three Claude Code CLI static reviews requested `claude-haiku-5-5` with tools, hooks, MCP, plugins, persistence and project setting sources disabled. Raw results report that canonical model and firstParty provider; the CLI also emitted `unrecognized_model`. This is CLI-reported metadata, not independent backend attestation. Raw prompts, manifests, results and detailed dispositions are retained in the task's `follow-up-delivery-next` evidence directory.

The reviews led to preserving consumed grants permanently, logical revocation timestamps, exact provider author binding, UTF-8 body exactness, durable FULL commits, persisted observed-clock high-water and historical scope recovery. The third review found that the shared `withWrite` helper is deferred, contrary to the earlier review framing. The final component now explicitly calls a local IMMEDIATE transaction after the existing disk-space preflight; a held-writer test proves no consuming row read or send occurs without acquiring its write lock. This final P1 fix and a pagination case correction postdate the last static-review snapshot; they are tested, and still require the parent integration's final independent audit. The third raw review must not be described as a clean approval.

Validation: 43 delivery service tests, 23 existing O1 tests, 24 existing DB tests, 13 delivery CLI tests, 12 existing O1 CLI tests and 8 protocol tests pass (123 total). Core/protocol builds, strict type checks and focused Biome checks pass. Known availability boundaries are documented in the guide: a bad forward host-clock excursion quarantines new admission; changing/removing historical destination registrations prevents reconciliation; a transport without lookup cannot automatically recover uncertainty and must not be production-qualified; inspect/list can show adjacent committed attempt/grant observations while mutations remain CAS protected. No unsafe reset, automatic resend or fabricated provider proof is added to hide these limits.
