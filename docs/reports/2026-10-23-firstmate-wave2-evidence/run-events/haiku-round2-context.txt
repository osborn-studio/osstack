FIRST REPORT
# Static audit: bounded run event replay (base 0a7b2ba6)

**Method and limits:** Static reading only. I did not run tests or inspect `db.ts` (`withWrite` transaction mode), `migration42` (indexes, FKs, triggers), `attention.ts`, or `SessionDecision`. Findings marked *conditional* depend on those files. Line numbers are omitted because the sources were provided without them.

## Verdict

**No P0 confirmed** in the new reader or projection. The following hold on reading:

- The reader bounds payloads in SQL (`CASE ... <= 65536`) and bounds IDs and types with `substr`.
- Cursors are validated as safe integers.
- The default-tenant join is applied in both the reader and the projection.
- Writes go through `store.write`, and cursor and subject facts commit in one transaction (the rollback test covers this).
- The projection never writes `approvals`, `clarifies`, or `attention_actions`.

The P1 items below are about the completeness claim, identity fencing, and authority integrity.

## P1

**P1-1. Deleted or mutated processed prefix still reports `complete: true`.**
*Where:* `projectAttentionRun`, anchor check.
*Why:* The anchor only re-hashes seq = cursor. Nothing re-verifies seq 0..cursor-1.
*Failing sequence:* Events 0–5 are processed, so cursor = 5, through_seq = 5, complete = true. Then `DELETE FROM events WHERE run_id='r' AND seq<=3`. On the next tick, the anchor (seq 5) matches. The page after 5 is empty. `max` = 5 is not `< afterSeq` or `< high`, so `sequenceGap` is false. `backlog` is false and `unsupported_events` is 0. Result: `complete: true`, `gap: null`. A fresh `readRunEventPage` from -1 would report `first.seq = 4` as a gap.
*Fix:* On each tick, verify the retained prefix: `COUNT(*) WHERE run_id=? AND seq<=cursor = cursor+1` and `MIN(seq)=0`. Alternatively, store a rolling chain digest checkpoint. Enforce append-only `events` with `BEFORE UPDATE/DELETE ... RAISE(ABORT)` triggers in migration42 (parent-owned). Add tests for prefix deletion and non-anchor mutation.

**P1-2. Task/scope-level source deletion leaves run subjects claiming complete.**
*Where:* `AttentionObserver.scan`, the early-return branch for `!task` or scope digest mismatch.
*Why:* The branch updates `attention_items` and `attention_scopes` and returns. It never quarantines `attention_run_cursors` or rewrites run-subject facts. Run projection never runs in that tick.
*Failing sequence:* A tick sets run facts to `event_replay.complete: true`. Then `UPDATE tasks SET tenant_id='x'` (or delete the task). The next tick hits the early return. Scope `error` is set, but the run subject still reports `complete: true, gap: "retention_unverified"`. This violates "source deletion cannot claim complete".
*Fix:* In the early-return branch, for every run and session subject in the scope, set `gap = COALESCE(gap,'source_missing')` on the cursor and rewrite facts with `state: source_missing`. Add a test that deletes or retenants the task, not only the run.

**P1-3 (conditional on migration42 FKs). Run ID reuse between ticks keeps the cursor and `complete` alive.**
*Where:* `projectAttentionRun` binding, and `insertRun`/`runs` schema.
*Why:* The binding covers `run_id, task_id, session_id, agent_id, capability_id, started_at`. It has no incarnation token. If the run row is deleted and re-inserted with identical identity fields between ticks, the binding matches and no `source_missing` quarantine ever runs.
*Failing sequence:* Tick → complete. `DELETE FROM runs WHERE run_id='r'` (events survive, meaning no cascade). `INSERT INTO runs` with identical fields. Next tick: binding matches, anchor seq 5 still matches, `complete: true`.
*Fix:* Add an immutable per-incarnation token (random UUID set at `insertRun`, stored in migration42) and include it in the binding. Also `RESTRICT` deletion of runs that have events, or cascade events and let the anchor catch it.

**P1-4 (intent needs owner confirmation). Runs that have `agent_sessions` rows are never event-replayed.**
*Where:* `AttentionObserver.scan`, the `rows` query. The run branch has `NOT EXISTS (SELECT 1 FROM agent_sessions ...)`, and the session branch never calls `projectAttentionRun`.
*Failing sequence:* Create a run with a matching `agent_sessions` row. Tick. No `kind='run'` subject is created and no `event_replay` facts appear. The projection is inert for session-bearing runs, which may be the common Hermes path.
*Fix:* Decide whether event replay should cover all runs. If yes, discover run subjects independently of sessions, or invoke `projectAttentionRun` from the session branch. Add a test with both a session row and a run.

**P1-5 (pre-existing, moved verbatim into `run-store.ts`). Approval authority writes are not run-scoped or status-guarded.**
*Where:* `appendEvent`, `approval.resolved` branch (and the clarify equivalent).
*Why:* `UPDATE approvals SET ... WHERE approval_id = ?` has no `run_id` and no `status='pending'` guard.
*Failing sequence:* Approval X belongs to run A and is pending. `appendEvent({run_id:'B', type:'approval.resolved', payload:{approval_id:'X', status:'accepted'}})` sets X to accepted for run A. A later `rejected` resolution can also overwrite an existing accepted one. The new projection then reports run A with no pending approvals.
*Fix:* `UPDATE approvals SET ... WHERE approval_id=? AND run_id=? AND status='pending'`, and throw if `changes !== 1` so the event append rolls back. Same for clarify. This is severity P1 here, and P0 if any execution gate reads `approvals.status` without run scoping (not verified).

## P2

**P2-1. Aggregate page bytes exceed the per-payload intent.** `readRunEventPage` selects payloads for `limit+1` rows, so the lookahead row's up to 64 KiB is transferred to JS but discarded. A page can be ~13 MB, and a tick with 100 admitted runs could transiently materialize about 1.3 GB inside one synchronous transaction. Fix: fetch the lookahead as `seq`-only or with an `EXISTS` check, and consider a per-tick byte budget. Perf qualification is future, so this is a risk, not a violation.

**P2-2. Fence error swallowed and unfenced write performed.** In `scan`'s subject loop, `catch` catches `stale_owner` and calls `this.update(...)` directly on `store.db`, bypassing `store.write`. This is practically unreachable if `withWrite` uses `BEGIN IMMEDIATE` (unverified). Fix: rethrow `stale_owner` and route `update` through `store.write`.

**P2-3. Scope identity is checked after the missing-run branch.** In `projectAttentionRun`, `if (!run)` quarantines and writes facts before the `scope_id` digest check. A forged scope on a missing run mutates state instead of rejecting. Fix: move the digest check above the `!run` branch.

**P2-4. Corrupt cursor facts can stall or silently reset counters.** If `prior` is invalid and `gap` is already set, `gap ??=` is a no-op. Processing continues with `unsupported_events` reset to 0 and the new facts overwrite the old. Completeness is still blocked by the sticky gap, so no false claim results. If `gap` was null, the run is stalled permanently with no repair path. Fix: explicit repair/reset path, plus tests.

**P2-5. One corrupt payload breaks the whole inventory.** `inventory()` calls `JSON.parse(payload_json)` per row with no guard. Fix: per-row try/catch returning an `invalid` marker and degraded coverage.

**P2-6. Sticky gaps have no recovery, and admission slots are never reclaimed.** A transient `authority_reference_missing` or `event_source_binding_conflict` permanently disables `complete` for that run. Completed runs keep their admitted slot forever, so after 100 admissions new runs are never observed. Coverage reports `degraded` (counts), but nothing evicts or re-admits. Cursor rows also grow without cleanup. These are design choices needing an owner decision.

**P2-7. Facts shape is inconsistent.** `state` is an object on the normal path and a string (`"source_missing"`) on the missing-run path. Consumers will break on one shape. Fix: normalize.

**P2-8. `status` events are not gated on `terminal`.** A non-terminal `status` event with `status: "completed"` sets `observed_status` to `completed`. Semantic only, since completeness is not derived from it, but it can mislead consumers.

**P2-9. NULL `payload_json` is reported as oversized.** If the schema permits NULL, `CASE ... ELSE NULL` and `payload_bytes` NULL yield `oversized_event_payload`. The label is wrong, though the outcome (no advance) is correct.

## Test gaps

- No test for prefix deletion or non-anchor mutation (P1-1).
- No test for task deletion or retenancy in the observer (P1-2).
- No test for run ID reuse with identical binding (P1-3).
- No test for runs with `agent_sessions` rows (P1-4).
- No test for cross-run or repeated `approval.resolved` through `appendEvent` (P1-5).
- No test for `throughSeq > max` (sequence-gap path), for event_id or session_id over 4096, for a payload at exactly 65536 bytes, or for NULL payload.
- No test for `done.last_seq` validation, `error` events, `authority_reference_missing`, or `invalid_cursor_facts`.
- No test for admission capacity (100) or inventory pagination and coverage.
- No two-connection test of owner supersession during a tick (P2-2).
- No index or query-plan check for `events(run_id, seq)`, which the MAX, MIN, and range queries assume.

## Limitations

- Retention is not guaranteed. Results describe only the caught-up retained range.
- Liveness is unknown. There is no adapter, network, or executor port in this code.
- Observations do not authorize execution. The projection does not write approvals or actions.
- Performance and soak are not qualified. The 65000 ms scope `deadline` predates this change and was not reviewed as a run-projection deadline.

export function appendEvent(
  db: Database.Database,
  path: string,
  ev: StoredEventInput,
): void {
  withWrite(db, path, (d) => {
    d.prepare(
      "INSERT INTO events(event_id, run_id, session_id, seq, type, created_at, terminal, payload_json) VALUES (?, ?, ?, ?, ?, ?, ?, ?)",
    ).run(
      ev.event_id,
      ev.run_id,
      ev.session_id,
      ev.seq,
      ev.type,
      ev.created_at,
      ev.terminal ? 1 : 0,
      JSON.stringify(ev.payload),
    );

    // Approval / clarify events double-write to their own tables so they
    // survive a daemon restart (Hermes RFC durability requirement) and
    // can be queried via approval.list / clarify.list without scanning
    // the event log.
    if (ev.type === "approval.requested") {
      const p = ev.payload as { approval_id?: string; action_summary?: string; risk?: string };
      if (typeof p.approval_id === "string") {
        d.prepare(
          "INSERT OR IGNORE INTO approvals(approval_id, run_id, status, action_summary, risk, requested_at) VALUES (?, ?, ?, ?, ?, ?)",
        ).run(p.approval_id, ev.run_id, "pending", p.action_summary ?? "", p.risk ?? "medium", ev.created_at);
      }
    } else if (ev.type === "approval.resolved") {
      const p = ev.payload as { approval_id?: string; choice?: string; status?: string };
      if (typeof p.approval_id === "string") {
        if (!["accepted", "rejected", "timed_out"].includes(p.status ?? "")) throw new Error("invalid_approval_resolution");
        const changed = d.prepare(
          "UPDATE approvals SET status = ?, resolved_at = ?, choice = ? WHERE approval_id = ? AND run_id = ? AND status = 'pending'",
        ).run(p.status, ev.created_at, p.choice ?? null, p.approval_id, ev.run_id).changes;
        if (changed !== 1) {
          const prior = d.prepare("SELECT status,choice FROM approvals WHERE approval_id=? AND run_id=?")
            .get(p.approval_id, ev.run_id) as { status: string; choice: string | null } | undefined;
          if (!prior || prior.status !== p.status || prior.choice !== (p.choice ?? null))
            throw new Error("approval_resolution_conflict");
        }
      }
    } else if (ev.type === "clarify.requested") {
      const p = ev.payload as { clarify_id?: string; question?: string };
      if (typeof p.clarify_id === "string") {
        d.prepare(
          "INSERT OR IGNORE INTO clarifies(clarify_id, run_id, status, question, requested_at) VALUES (?, ?, ?, ?, ?)",
        ).run(p.clarify_id, ev.run_id, "pending", p.question ?? "", ev.created_at);
      }
    } else if (ev.type === "clarify.resolved") {
      const p = ev.payload as { clarify_id?: string; answer?: string; status?: string };
      if (typeof p.clarify_id === "string") {
        if (!["answered", "timed_out", "abandoned"].includes(p.status ?? "")) throw new Error("invalid_clarify_resolution");
        const changed = d.prepare(
          "UPDATE clarifies SET status = ?, resolved_at = ?, answer = ? WHERE clarify_id = ? AND run_id = ? AND status = 'pending'",
        ).run(p.status, ev.created_at, p.answer ?? null, p.clarify_id, ev.run_id).changes;
        if (changed !== 1) {
          const prior = d.prepare("SELECT status,answer FROM clarifies WHERE clarify_id=? AND run_id=?")
            .get(p.clarify_id, ev.run_id) as { status: string; answer: string | null } | undefined;
          if (!prior || prior.status !== p.status || prior.answer !== (p.answer ?? null))
            throw new Error("clarify_resolution_conflict");
        }
      }
    }
  });
}

export function finalizeRun(
  db: Database.Database,
  path: string,
  run_id: string,
  outcome: "completed" | "failed" | "cancelled" | "expired",
  completed_at: number,
): void {
  // SQLite UPDATE expressions read pre-UPDATE column values, so we must
  // compute duration in JS using the read-back started_at — not refer to
  // `completed_at` inside the same UPDATE (it would be NULL on first set).
  withWrite(db, path, (d) => {
    const row = d.prepare("SELECT started_at FROM runs WHERE run_id = ?").get(run_id) as
      | { started_at: number }
      | undefined;
    const duration_ms = row ? (completed_at - row.started_at) * 1000 : null;
    d.prepare(
      "UPDATE runs SET outcome = ?, completed_at = ?, duration_ms = ? WHERE run_id = ?",
    ).run(outcome, completed_at, duration_ms, run_id);
    d.prepare(
      "UPDATE tasks SET status = ?, updated_at = ? WHERE task_id = (SELECT task_id FROM runs WHERE run_id = ?)",
    ).run(
      outcome === "completed" ? "done" : outcome,
      completed_at,
      run_id,
    );
  });
}

/**
 * Events for a run, ordered by seq ascending. From daemon.ts (snapshot replay)
 * and bin.ts (persisted loop evidence). `afterSeq` defaults to -1 so a caller
 * that wants every event (bin.ts) gets `seq > -1` — behavior-identical to the
 * unfiltered `WHERE run_id = ?` query, since seq is always ≥ 0. The returned
 * superset includes `terminal`; call sites that ignore it are unaffected.
 */
export function listEventsForRun(
  db: Database.Database,
  runId: string,
  opts: { afterSeq?: number } = {},
): StoredEventRow[] {
  const afterSeq = opts.afterSeq ?? -1;
  return db.prepare(
    "SELECT event_id, run_id, session_id, seq, type, created_at, terminal, payload_json FROM events WHERE run_id = ? AND seq > ? ORDER BY seq ASC",
  ).all(runId, afterSeq) as StoredEventRow[];
}

/** Bounded local/default-tenant reader. Oversized payloads never enter JS. */
export interface BoundedRunEvent extends Omit<StoredEventRow, "payload_json"> {
  payload_json: string | null;
  payload_bytes: number;
}
export function readRunEventPage(db: Database.Database, input: {
  taskId: string;
  runId: string;
  afterSeq: number;
  limit: number;
  throughSeq?: number;
}): {
  events: BoundedRunEvent[];
  nextAfter: number;
  highWatermark: number;
  availableHighWatermark: number;
  hasMore: boolean;
  sequenceGap: boolean;
} {
  if (!input.taskId || !input.runId || !Number.isSafeInteger(input.afterSeq) || input.afterSeq < -1
    || !Number.isSafeInteger(input.limit) || input.limit < 1 || input.limit > 200
    || (input.throughSeq !== undefined && (!Number.isSafeInteger(input.throughSeq) || input.throughSeq < input.afterSeq)))
    throw new Error("invalid_event_page");
  const read = () => {
    const source = db.prepare(`SELECT 1 FROM runs r JOIN tasks t ON t.task_id=r.task_id
      WHERE r.run_id=? AND r.task_id=? AND r.tenant_id IS NULL AND t.tenant_id IS NULL`).get(input.runId, input.taskId);
    if (!source) throw new Error("run_source_not_found");
    const max = (db.prepare("SELECT COALESCE(MAX(seq),-1) seq FROM events WHERE run_id=?").get(input.runId) as { seq: number }).seq;
    const first = db.prepare("SELECT seq FROM events WHERE run_id=? ORDER BY seq LIMIT 1").get(input.runId) as { seq: number } | undefined;
    if (!Number.isSafeInteger(max) || max < -1 || (first && (!Number.isSafeInteger(first.seq) || first.seq < 0)))
      throw new Error("invalid_event_sequence");
    const high = input.throughSeq ?? max;
    const rows = db.prepare(`SELECT substr(event_id,1,4097) event_id,run_id,substr(session_id,1,4097) session_id,
      seq,substr(type,1,257) type,created_at,terminal,length(CAST(payload_json AS BLOB)) payload_bytes,
      CASE WHEN length(CAST(payload_json AS BLOB))<=65536 THEN payload_json ELSE NULL END payload_json
      FROM events WHERE run_id=? AND seq>? AND seq<=? ORDER BY seq LIMIT ?`)
      .all(input.runId, input.afterSeq, high, input.limit) as BoundedRunEvent[];
    const events = rows;
    const nextAfter = events.at(-1)?.seq ?? input.afterSeq;
    const hasMore = db.prepare("SELECT 1 FROM events WHERE run_id=? AND seq>? AND seq<=? LIMIT 1")
      .get(input.runId, nextAfter, high) !== undefined;
    let previous = input.afterSeq;
    let gap = max < input.afterSeq || max < high;
    for (const event of events) {
      if (!Number.isSafeInteger(event.seq) || event.seq !== previous + 1) gap = true;
      previous = event.seq;
    }
    return { events, nextAfter: events.at(-1)?.seq ?? input.afterSeq, highWatermark: high,
      availableHighWatermark: max, hasMore, sequenceGap: gap };
  };
  return db.inTransaction ? read() : db.transaction(read)();
}

function object(json: string): Record<string, unknown> | null {
  try {
    const value: unknown = JSON.parse(json);
    return value !== null && typeof value === "object" && !Array.isArray(value) ? value as Record<string, unknown> : null;
  } catch { return null; }
}
function reduce(event: BoundedRunEvent, state: Observed, store: AttentionStore): string | null {
  if (event.payload_json === null) return "oversized_event_payload";
  if (!event.event_id || event.event_id.length > 4096 || !event.session_id || event.session_id.length > 4096
    || !event.type || event.type.length > 256 || !Number.isFinite(event.created_at)
    || ![0, 1].includes(event.terminal)) return "invalid_event_envelope";
  const payload = object(event.payload_json);
  if (!payload) return "invalid_event_payload";
  if (["status", "run.started", "done"].includes(event.type)) {
    if (typeof payload.status !== "string" || !statuses.has(payload.status)
      || (event.type === "run.started" && payload.status !== "running")
      || (event.type === "done" && (!event.terminal || !["completed", "failed", "cancelled", "expired"].includes(payload.status)
        || !Number.isSafeInteger(payload.last_seq) || (payload.last_seq as number) < 0 || (payload.last_seq as number) > event.seq)))
      return "invalid_event_payload";
    state.observed_status = payload.status;
  } else if (event.type.startsWith("approval.") || event.type.startsWith("clarify.")) {
    const approval = event.type.startsWith("approval.");
    const family = approval ? "approval" : "clarify";
    if (![`${family}.requested`, `${family}.resolved`].includes(event.type)) {
      state.unsupported_events++;
      return null;
    }
    const id = payload[`${family}_id`];
    if (typeof id !== "string" || !id || id.length > 4096) return "invalid_event_payload";
    // Authority stays with the original approval/clarify tables. Events never
    // grant permission or synthesize a Session answer/action.
    const table = approval ? "approvals" : "clarifies";
    const row = store.db.prepare(`SELECT status FROM ${table} WHERE ${family}_id=? AND run_id=?`)
      .get(id, event.run_id) as { status: string } | undefined;
    if (!row) return "authority_reference_missing";
    if (event.type.endsWith(".resolved") && (typeof payload.status !== "string"
      || !(approval ? ["accepted", "rejected", "timed_out"] : ["answered", "timed_out", "abandoned"]).includes(payload.status)))
      return "invalid_event_payload";
  } else if (event.type === "error") {
    if (typeof payload.code !== "string" || typeof payload.terminal !== "boolean") return "invalid_event_payload";
    if (payload.terminal) state.observed_status = "unknown";
  } else if (!informational.has(event.type)) state.unsupported_events++;
  return null;
}

/** One bounded retained-log page. Projection and cursor share the owner-fenced
 * transaction; it never invokes an adapter, resolves an approval, or pins history. */
export function projectAttentionRun(store: AttentionStore, owner: AttentionOwner,
  scope: AttentionScope, runId: string, now: number): void {
  if (!Number.isFinite(now)) throw new Error("invalid_clock");
  store.write(owner, () => {
    const persistedScope = store.getScope(scope.scope_id);
    if (!persistedScope || persistedScope.task_id !== scope.task_id || persistedScope.repo_path !== scope.repo_path)
      throw new Error("attention_scope_conflict");
    const subject = store.db.prepare("SELECT admitted,binding_hash FROM attention_subjects WHERE scope_id=? AND kind='run' AND subject_id=?")
      .get(scope.scope_id, runId) as { admitted: number; binding_hash: string } | undefined;
    if (!subject?.admitted) throw new Error("run_not_admitted");
    if (subject.binding_hash !== attentionDigest([scope.scope_id, "run", runId])) throw new Error("run_subject_binding_conflict");
    const task = store.db.prepare("SELECT created_at FROM tasks WHERE task_id=? AND tenant_id IS NULL")
      .get(scope.task_id) as { created_at: number } | undefined;
    if (!task || scope.scope_id !== attentionDigest([owner.home_id, scope.task_id, scope.repo_path, task.created_at]))
      throw new Error("attention_scope_conflict");
    const run = store.db.prepare(`SELECT r.*,t.created_at task_created_at FROM runs r JOIN tasks t ON t.task_id=r.task_id
      WHERE r.run_id=? AND r.task_id=? AND r.tenant_id IS NULL AND t.tenant_id IS NULL`).get(runId, scope.task_id) as Run | undefined;
    const saved = store.db.prepare("SELECT * FROM attention_run_cursors WHERE scope_id=? AND run_id=?")
      .get(scope.scope_id, runId) as Cursor | undefined;
    const writeSubject = (facts: unknown) => store.db.prepare(
      "UPDATE attention_subjects SET sampled_at=?,generation=?,payload_json=? WHERE scope_id=? AND kind='run' AND subject_id=?"
    ).run(now, owner.generation, JSON.stringify(facts), scope.scope_id, runId);
    const quarantine = (reason: string) => store.db.prepare(
      "UPDATE attention_run_cursors SET gap=COALESCE(gap,?),generation=?,updated_at=? WHERE scope_id=? AND run_id=?"
    ).run(reason, owner.generation, now, scope.scope_id, runId);
    if (!run) {
      quarantine("source_missing");
      writeSubject({ state: "source_missing", reason: "source_missing", process_liveness: "unknown", gap: "history_gap" });
      return;
    }
    const binding = attentionDigest([owner.home_id, scope.scope_id, run.run_id, run.task_id,
      run.session_id, run.agent_id, run.capability_id, run.started_at]);
    if (saved && saved.binding_hash !== binding) {
      quarantine("source_binding_conflict");
      writeSubject({ state: "unknown", reason: "source_binding_conflict", process_liveness: "unknown", gap: "history_gap" });
      return;
    }
    if (saved && (!Number.isSafeInteger(saved.last_seq) || saved.last_seq < -1
      || !Number.isSafeInteger(saved.through_seq) || saved.through_seq < -1)) throw new Error("invalid_event_cursor");
    let cursor = saved?.last_seq ?? -1;
    let anchor = saved?.last_event_hash ?? null;
    let gap = saved?.gap ?? null;
    const state: Observed = { observed_status: null, unsupported_events: 0 };
    const prior = saved ? object(saved.facts_json) : null;
    if (saved) {
      if (!prior || !(prior.observed_status === null || typeof prior.observed_status === "string")
        || !Number.isSafeInteger(prior.unsupported_events) || (prior.unsupported_events as number) < 0)
        gap ??= "invalid_cursor_facts";
      else { state.observed_status = prior.observed_status; state.unsupported_events = prior.unsupported_events as number; }
    }
    let anchorValid = true;
    if (cursor >= 0) {
      const previous = readRunEventPage(store.db, { taskId: scope.task_id, runId, afterSeq: cursor - 1, throughSeq: cursor, limit: 1 }).events[0];
      anchorValid = previous !== undefined && hash(previous) === anchor;
      if (!anchorValid) { gap ??= "event_anchor_changed"; state.observed_status = null; }
    }
    const page = readRunEventPage(store.db, { taskId: scope.task_id, runId, afterSeq: cursor, limit: 200,
      ...(saved && saved.through_seq > cursor ? { throughSeq: saved.through_seq } : {}) });
    if (page.sequenceGap) gap ??= "event_sequence_gap";
    if (anchorValid && gap !== "invalid_cursor_facts") {
      for (const event of page.events) {
        if (event.seq !== cursor + 1) { gap ??= "event_sequence_gap"; break; }
        if (event.session_id !== run.session_id) { gap ??= "event_source_binding_conflict"; break; }
        const error = reduce(event, state, store);
        if (error) { gap ??= error; break; }
        cursor = event.seq;
        anchor = hash(event);
      }
    }
    const backlog = cursor < page.highWatermark || cursor < page.availableHighWatermark;
    const caughtUp = cursor >= 0 && !gap && !backlog && state.unsupported_events === 0;
    // A caught-up cursor verifies newly read rows and the last anchor only.
    // Mutable earlier rows are not continuously re-hashed; never certify history.
    const pending = (table: "approvals" | "clarifies", column: "approval_id" | "clarify_id") => {
      const rows = store.db.prepare(`SELECT ${column} id FROM ${table} WHERE run_id=? AND status='pending' ORDER BY ${column} LIMIT 21`)
        .all(runId) as { id: string }[];
      return { ids: rows.slice(0, 20).map((row) => row.id), truncated: rows.length > 20,
        count: (store.db.prepare(`SELECT COUNT(*) n FROM ${table} WHERE run_id=? AND status='pending'`).get(runId) as { n: number }).n };
    };
    store.db.prepare(`INSERT INTO attention_run_cursors(scope_id,run_id,binding_hash,last_seq,through_seq,last_event_hash,gap,facts_json,generation,updated_at)
      VALUES(?,?,?,?,?,?,?,?,?,?) ON CONFLICT(scope_id,run_id) DO UPDATE SET last_seq=excluded.last_seq,through_seq=excluded.through_seq,
      last_event_hash=excluded.last_event_hash,gap=excluded.gap,facts_json=excluded.facts_json,generation=excluded.generation,updated_at=excluded.updated_at`)
      .run(scope.scope_id, runId, binding, cursor, page.highWatermark, anchor, gap, JSON.stringify(state), owner.generation, now);
    writeSubject({ state: { phase: run.phase, outcome: run.outcome }, ...state,
      reason: gap ? "history_gap" : backlog ? "event_backlog" : state.unsupported_events > 0 ? "unsupported_event_type" : "snapshot_only",
      repo_binding: "unverified", process_liveness: "unknown", gap: gap ? "history_gap" : "retention_unverified",
      event_replay: { cursor, through_seq: page.highWatermark, complete: false, caught_up: caughtUp, gap, completeness_scope: "unverified_retention" },
      pending_approvals: pending("approvals", "approval_id"), pending_clarifies: pending("clarifies", "clarify_id"),
      limitations: ["No historical retention or processed-prefix integrity guarantee", "Event observations do not authorize execution"] });
  });
}


FILE attention-observer.ts
import { classifyAttentionWait, type WaitInput } from "../attention.js";
import { realpathSync } from "node:fs";
import { projectAttentionRun } from "./attention-run-projection.js";
import {
  attentionDigest,
  type AttentionStore,
  type AttentionOwner,
  type AttentionScope,
} from "./attention-store.js";
interface Subject {
  scope_id: string;
  kind: string;
  subject_id: string;
  binding_hash: string;
  source_version: number;
  ordinal_cursor: number;
  admitted: number;
  discovered_at: number;
  sampled_at: number;
  generation: number;
  payload_json: string;
}
interface Source {
  session_id: string;
  run_id: string;
  request_sha256: string;
  agent_id: string;
  native_session_id: string | null;
  repo_path: string;
  version: number;
  state: string;
}
interface Turn {
  turn_id: string;
  ordinal: number;
  decision_json: string | null;
  state: string;
}
/** Bounded synchronous transactions; no adapter, network, or model port. */
export class AttentionObserver {
  constructor(readonly store: AttentionStore, readonly owner: AttentionOwner) {}
  tick(now = Date.now()): void {
    if (!Number.isFinite(now)) throw new Error("invalid_clock");
    this.store.assertOwner(this.owner);
    for (const scope of this.store.listScopes()) {
      try {
        this.store.write(this.owner, () => this.scan(scope, now));
      } catch (error) {
        if (error instanceof Error && error.message === "stale_owner")
          throw error;
        this.store.write(this.owner, () =>
          this.store.db
            .prepare(
              "UPDATE attention_scopes SET error=?,scan_complete=0 WHERE scope_id=?"
            )
            .run(
              error instanceof Error
                ? error.message.slice(0, 300)
                : "source_error",
              scope.scope_id
            )
        );
      }
    }
  }
  private scan(scope: AttentionScope, now: number): void {
    const db = this.store.db;
    const task = db
      .prepare(
        "SELECT created_at FROM tasks WHERE task_id=? AND tenant_id IS NULL"
      )
      .get(scope.task_id) as { created_at: number } | undefined;
    if (
      !task ||
      attentionDigest([
        this.owner.home_id,
        scope.task_id,
        scope.repo_path,
        task.created_at,
      ]) !== scope.scope_id
    ) {
      db.prepare(
        "UPDATE attention_items SET state='source_missing',revision=revision+1 WHERE scope_id=? AND state='open'"
      ).run(scope.scope_id);
      db.prepare(
        "UPDATE attention_scopes SET error='source_missing',scan_complete=0 WHERE scope_id=?"
      ).run(scope.scope_id);
      db.prepare("UPDATE attention_run_cursors SET gap=COALESCE(gap,'source_missing'),generation=?,updated_at=? WHERE scope_id=?")
        .run(this.owner.generation, now, scope.scope_id);
      db.prepare("UPDATE attention_subjects SET sampled_at=?,generation=?,payload_json=? WHERE scope_id=?")
        .run(now, this.owner.generation, JSON.stringify({ state: "source_missing", reason: "source_missing",
          process_liveness: "unknown", gap: "history_gap", event_replay: { complete: false, caught_up: false, gap: "source_missing" } }), scope.scope_id);
      return;
    }
    // A scan advances a durable keyset, then restarts from the beginning. New IDs
    // inserted behind the cursor are picked up on the next pass, never evicted.
    const rows = db
      .prepare(
        `SELECT '0:'||s.session_id AS key,s.session_id AS id,'session' AS kind FROM agent_sessions s JOIN runs r ON r.run_id=s.run_id AND r.task_id=s.task_id
      WHERE s.task_id=? AND r.tenant_id IS NULL AND '0:'||s.session_id>?
      UNION ALL SELECT '1:'||r.run_id,r.run_id,'run' FROM runs r WHERE r.task_id=? AND r.tenant_id IS NULL AND '1:'||r.run_id>?
      ORDER BY key LIMIT 250`
      )
      .all(
        scope.task_id,
        scope.discovery_after,
        scope.task_id,
        scope.discovery_after
      ) as { key: string; id: string; kind: string }[];
    for (const row of rows) {
      if (
        db
          .prepare(
            "SELECT 1 FROM attention_subjects WHERE scope_id=? AND kind=? AND subject_id=? AND admitted=1"
          )
          .get(scope.scope_id, row.kind, row.id)
      )
        continue;
      const count = (
        db
          .prepare("SELECT COUNT(*) n FROM attention_subjects WHERE admitted=1")
          .get() as { n: number }
      ).n;
      const prior = db
        .prepare(
          "SELECT payload_json FROM attention_subjects WHERE scope_id=? AND kind=? AND subject_id=?"
        )
        .get(scope.scope_id, row.kind, row.id) as
        | { payload_json: string }
        | undefined;
      if (prior) {
        try {
          if (JSON.parse(prior.payload_json).reason === "owner_released")
            continue;
        } catch {
          /* Rebuild corrupt observation metadata from its source. */
        }
      }
      let source: Source | undefined;
      let sourceError = false;
      try {
        source =
          row.kind === "session" ? this.source(scope, row.id) : undefined;
      } catch {
        sourceError = true;
      }
      const bound = row.kind === "run" || source !== undefined;
      const admitted = bound && count < 100 ? 1 : 0;
      db.prepare(
        `INSERT INTO attention_subjects(scope_id,kind,subject_id,binding_hash,source_version,admitted,discovered_at,sampled_at,generation,payload_json) VALUES(?,?,?,?,?,?,?,?,?,?) ON CONFLICT(scope_id,kind,subject_id) DO UPDATE SET
        admitted=excluded.admitted,binding_hash=excluded.binding_hash,source_version=excluded.source_version,sampled_at=excluded.sampled_at,generation=excluded.generation,payload_json=excluded.payload_json`
      ).run(
        scope.scope_id,
        row.kind,
        row.id,
        source
          ? this.binding(source)
          : attentionDigest([scope.scope_id, row.kind, row.id]),
        source?.version ?? 0,
        admitted,
        now,
        now,
        this.owner.generation,
        JSON.stringify({
          state: source?.state ?? "unknown",
          awaiting_decision: source?.state === "awaiting_decision",
          reason: sourceError
            ? "source_error"
            : !bound
            ? "binding_unknown"
            : !admitted
            ? "capacity_exceeded"
            : "snapshot_only",
          unresolved_receipts: source ? this.receipts(source.session_id) : [],
        })
      );
    }
    const subjects = db
      .prepare(
        "SELECT * FROM attention_subjects WHERE scope_id=? AND admitted=1 ORDER BY kind,subject_id"
      )
      .all(scope.scope_id) as Subject[];
    for (const subject of subjects) {
      try {
        db.transaction(() => {
          if (subject.kind === "run") {
            projectAttentionRun(this.store, this.owner, scope, subject.subject_id, now);
            return;
          }
          if (subject.kind !== "session") return;
          const source = this.source(scope, subject.subject_id);
          if (!source) {
            this.store.markMissing(
              this.owner,
              scope.scope_id,
              subject.subject_id
            );
            this.update(subject, now, {
              state: "source_missing",
              reason: "source_missing",
            });
            return;
          }
          if (
            this.binding(source) !== subject.binding_hash ||
            source.version < subject.source_version
          ) {
            this.update(subject, now, {
              state: source.state,
              reason: "source_binding_conflict",
            });
            return;
          }
          const turns = db
            .prepare(
              "SELECT turn_id,ordinal,state,decision_json FROM session_turns WHERE session_id=? AND ordinal>? ORDER BY ordinal LIMIT 50"
            )
            .all(source.session_id, subject.ordinal_cursor) as Turn[];
          const latest = db
            .prepare(
              "SELECT turn_id,ordinal,state,decision_json FROM session_turns WHERE session_id=? ORDER BY ordinal DESC LIMIT 1"
            )
            .get(source.session_id) as Turn | undefined;
          let cursor = subject.ordinal_cursor;
          let gap =
            JSON.parse(subject.payload_json).gap === "history_gap" ||
            (latest?.ordinal ?? 0) < cursor;
          for (const turn of turns) {
            if (turn.ordinal !== cursor + 1) gap = true;
            try {
              this.project(scope, source, turn, now);
            } catch {
              gap = true;
            }
            cursor = turn.ordinal;
          }
          if (latest && latest.ordinal <= cursor) {
            try {
              this.project(scope, source, latest, now);
            } catch {
              gap = true;
            }
          }
          const backlogged = latest !== undefined && latest.ordinal > cursor;
          db.prepare(
            "UPDATE attention_subjects SET source_version=?,ordinal_cursor=? WHERE scope_id=? AND kind=? AND subject_id=?"
          ).run(
            source.version,
            cursor,
            scope.scope_id,
            subject.kind,
            subject.subject_id
          );
          const unresolved = this.receipts(source.session_id);
          if (["completed", "failed", "cancelled"].includes(source.state))
            db.prepare(
              "UPDATE attention_items SET state='source_closed',revision=revision+1 WHERE scope_id=? AND session_id=? AND state='open'"
            ).run(scope.scope_id, source.session_id);
          // Only an applied receipt referencing this exact origin turn establishes
          // external continuation. Authorization/risk obligations remain unresolved.
          const items = (
            db
              .prepare(
                "SELECT item_id FROM attention_items WHERE scope_id=? AND session_id=? AND state='open'"
              )
              .all(scope.scope_id, source.session_id) as { item_id: string }[]
          )
            .map((r) => this.store.getItem(scope.scope_id, r.item_id)!)
            .filter(
              (i) =>
                i.session_id === source.session_id &&
                i.state === "open" &&
                !["risk_approval", "task_authorization"].includes(
                  i.decision.continuation?.gate_kind ?? ""
                )
            );
          for (const item of items) {
            const applied = db
              .prepare(
                "SELECT message_id FROM session_messages WHERE session_id=? AND turn_id=? AND direction='inbound' AND state='applied' ORDER BY created_at,message_id LIMIT 1"
              )
              .get(source.session_id, item.turn_id) as
              | { message_id: string }
              | undefined;
            if (applied)
              db.prepare(
                "UPDATE attention_items SET state='continued_externally',external_message_id=?,revision=revision+1 WHERE item_id=?"
              ).run(applied.message_id, item.item_id);
          }
          this.update(subject, now, {
            state: source.state,
            awaiting_decision: source.state === "awaiting_decision",
            version: source.version,
            turn_id: latest?.turn_id ?? null,
            process_liveness: "unknown",
            gap: gap ? "history_gap" : "mutable_snapshot_no_complete_event_log",
            reason: backlogged ? "history_backlog" : null,
            unresolved_receipts: unresolved,
            wait: this.wait(source, latest?.turn_id ?? null, now),
          });
        })();
      } catch (error) {
        if (error instanceof Error && error.message === "stale_owner") throw error;
        this.store.assertOwner(this.owner);
        this.update(subject, now, {
          state: "unknown",
          reason: "invalid_source",
          detail:
            error instanceof Error
              ? error.message.slice(0, 120)
              : "invalid_source",
        });
      }
    }
    const complete = rows.length < 250;
    const undiscovered = db
      .prepare(
        `SELECT 1 FROM agent_sessions s JOIN runs r ON r.run_id=s.run_id AND r.task_id=s.task_id
      WHERE s.task_id=? AND r.tenant_id IS NULL AND NOT EXISTS(SELECT 1 FROM attention_subjects a WHERE a.scope_id=? AND a.kind='session' AND a.subject_id=s.session_id) LIMIT 1`
      )
      .get(scope.task_id, scope.scope_id);

    db.prepare(
      "UPDATE attention_scopes SET discovery_after=?,scan_complete=?,sampled_at=?,deadline=?,generation=?,error=NULL WHERE scope_id=?"
    ).run(
      complete ? "" : rows.at(-1)!.key,
      complete && !undiscovered ? 1 : 0,
      now,
      now + 65000,
      this.owner.generation,
      scope.scope_id
    );
  }
  private source(scope: AttentionScope, id: string): Source | undefined {
    const row = this.store.db
      .prepare(
        `SELECT s.* FROM agent_sessions s JOIN runs r ON r.run_id=s.run_id AND r.task_id=s.task_id JOIN tasks t ON t.task_id=s.task_id
      WHERE s.session_id=? AND s.task_id=? AND r.tenant_id IS NULL AND t.tenant_id IS NULL`
      )
      .get(id, scope.task_id) as Source | undefined;
    try {
      return row && realpathSync(row.repo_path) === scope.repo_path
        ? row
        : undefined;
    } catch (error) {
      if ((error as NodeJS.ErrnoException).code === "ENOENT") return undefined;
      throw error;
    }
  }
  private binding(source: Source): string {
    return attentionDigest([
      source.session_id,
      source.run_id,
      source.request_sha256,
      source.agent_id,
      source.repo_path,
    ]);
  }
  private project(
    scope: AttentionScope,
    source: Source,
    turn: Turn,
    now: number
  ): void {
    if (turn.decision_json === null) return;
    if (turn.decision_json.length > 16384)
      throw new Error("oversized_decision");
    this.store.projectDecision(this.owner, {
      scopeId: scope.scope_id,
      sessionId: source.session_id,
      turnId: turn.turn_id,
      sourceVersion: source.version,
      decision: JSON.parse(turn.decision_json),
      now,
    });
  }
  private wait(source: Source, turnId: string | null, now: number) {
    const db = this.store.db;
    const input: WaitInput = {
      state: source.state,
      turnId,
      version: source.version,
      now,
    };
    const g = db
      .prepare(
        "SELECT grant_id,status,expected_turn_id,expected_version,body_json FROM session_continuation_grants WHERE session_id=? AND status='active'"
      )
      .get(source.session_id) as
      | {
          grant_id: string;
          status: string;
          expected_turn_id: string;
          expected_version: number;
          body_json: string;
        }
      | undefined;
    try {
      if (g)
        input.grant = {
          id: g.grant_id,
          status: g.status,
          turnId: g.expected_turn_id,
          version: g.expected_version,
          expires: Date.parse(JSON.parse(g.body_json).expires_at),
        };
    } catch {
      return { reason: "grant_unreadable", owner: "unknown", blocked: true };
    }
    const attempt = db
      .prepare(
        "SELECT a.* FROM session_continuation_attempts a JOIN session_continuation_grants g ON a.grant_id=g.grant_id WHERE g.session_id=? AND a.status IN ('checking','reserved') ORDER BY a.created_at LIMIT 1"
      )
      .get(source.session_id) as
      | {
          status: string;
          source_turn_id: string;
          source_version: number;
          reservation_version: number | null;
          message_id: string | null;
        }
      | undefined;
    if (attempt)
      input.attempt = {
        state: attempt.status,
        sourceTurn: attempt.source_turn_id,
        sourceVersion: attempt.source_version,
        ...(attempt.reservation_version === null
          ? {}
          : { reservationVersion: attempt.reservation_version }),
        ...(attempt.message_id === null
          ? {}
          : { messageId: attempt.message_id }),
      };
    const message = db
      .prepare(
        "SELECT message_id,state FROM session_messages WHERE session_id=? AND direction='inbound' AND state IN ('accepted','failed') AND message_id NOT IN (SELECT message_id FROM attention_receipt_resolutions) ORDER BY CASE state WHEN 'accepted' THEN 0 ELSE 1 END,created_at LIMIT 1"
      )
      .get(source.session_id) as
      | { message_id: string; state: string }
      | undefined;
    if (message)
      input.message = { id: message.message_id, state: message.state };
    return {
      ...classifyAttentionWait(input),
      grant_id: g?.grant_id ?? null,
      message_id: message?.message_id ?? null,
    };

    return this.store.db
      .prepare(
        "SELECT message_id,state FROM session_messages WHERE session_id=? AND direction='inbound' AND state IN ('accepted','failed') AND message_id NOT IN (SELECT message_id FROM attention_receipt_resolutions) ORDER BY created_at LIMIT 10"
      )
      .all(id);
  }
  private update(s: Subject, now: number, payload: unknown): void {
    this.store.assertOwner(this.owner);
    let old: { gap?: string } = {};
    try {
      old = JSON.parse(s.payload_json) as { gap?: string };
    } catch {
      old = { gap: "history_gap" };
    }
    if (old.gap === "history_gap" && payload && typeof payload === "object")
      payload = { ...payload, gap: "history_gap" };
    this.store.db
      .prepare(
        "UPDATE attention_subjects SET sampled_at=?,generation=?,payload_json=? WHERE scope_id=? AND kind=? AND subject_id=?"
      )
      .run(
        now,
        this.owner.generation,
        JSON.stringify(payload),
        s.scope_id,
        s.kind,
        s.subject_id
      );
  }
  inventory(scopeId: string, now = Date.now(), after = "", limit = 100) {
    if (!Number.isSafeInteger(limit) || limit < 1 || limit > 100)
      throw new Error("invalid_limit");
    const scope = this.store.getScope(scopeId);
    if (!scope) throw new Error("not_found");
    const db = this.store.db;
    const counts = db
      .prepare(
        "SELECT COUNT(*) total,COALESCE(SUM(admitted),0) admitted FROM attention_subjects WHERE scope_id=?"
      )
      .get(scopeId) as { total: number; admitted: number };
    const rows = db
      .prepare(
        "SELECT * FROM attention_subjects WHERE scope_id=? AND kind||':'||subject_id>? ORDER BY kind,subject_id LIMIT ?"
      )
      .all(scopeId, after, limit + 1) as Subject[];
    const current = db
      .prepare("SELECT generation FROM daemon_owner WHERE singleton=1")
      .get() as { generation: number };
    const faulty = db
      .prepare(
        "SELECT 1 FROM attention_subjects WHERE scope_id=? AND (sampled_at<? OR generation<>? OR CASE WHEN json_valid(payload_json) THEN (json_extract(payload_json,'$.reason') IS NOT NULL AND json_extract(payload_json,'$.reason')<>'snapshot_only' OR json_extract(payload_json,'$.gap')='history_gap') ELSE 1 END) LIMIT 1"
      )
      .get(scopeId, now - 65000, current.generation);
    const coverage =
      now < scope.sampled_at
        ? "unknown"
        : scope.generation !== current.generation || now > scope.deadline
        ? "uncovered"
        : !scope.scan_complete ||
          scope.error ||
          counts.total > counts.admitted ||
          faulty
        ? "degraded"
        : "covered";
    return {
      scope,
      coverage,
      subject_total: counts.total,
      admitted: counts.admitted,
      returned: Math.min(limit, rows.length),
      truncated: rows.length > limit,
      next_after:
        rows.length > limit
          ? `${rows[limit - 1]!.kind}:${rows[limit - 1]!.subject_id}`
          : null,
      subjects: rows.slice(0, limit).map(({ payload_json, ...r }) => ({
        ...r,
        facts: (() => {
          try { return JSON.parse(payload_json) as unknown; }
          catch { return { state: "unknown", reason: "invalid_source", gap: "history_gap" }; }
        })(),
      })),
      limitations: [
        "No complete mutable-source history",
        "Process liveness unknown",
        "Coverage is observation, not execution ownership",
      ],
    };
  }

// SQLite connection management.
//
// Decisions locked in plan v0.6:
//   - better-sqlite3 (synchronous, single connection per daemon process)
//   - WAL mode for concurrent reader/writer safety
//   - synchronous=NORMAL (WAL-safe, faster than FULL)
//   - 64 MiB page cache
//   - foreign_keys ON (so ON DELETE CASCADE works for runs/events on task delete)
//
// CRITICAL GAP G1 (plan v0.6 §8.3): disk-full must never cause a silent task
// write loss. Every write goes through preflightDiskSpace(), which throws
// DiskFullError before any INSERT/UPDATE can corrupt or stall a transaction.

import Database from "better-sqlite3";
import { statfsSync } from "node:fs";
import { dirname } from "node:path";
import { CURRENT_SCHEMA_VERSION, MIGRATIONS } from "./migrations.js";

/** Default safety threshold for disk-full preflight (100 MiB). */
export const DEFAULT_MIN_FREE_BYTES = 100 * 1024 * 1024;

/** Cache size in -kibibyte units. negative = KiB (per SQLite docs). 64 MiB. */
const PAGE_CACHE_KIB = -65536;

export class DiskFullError extends Error {
  readonly path: string;
  readonly freeBytes: number;
  readonly minFreeBytes: number;
  constructor(path: string, freeBytes: number, minFreeBytes: number) {
    super(
      `Disk full preflight failed for ${path}: ${freeBytes} bytes free, ` +
      `need ≥${minFreeBytes}. Refusing write so Hermes can be notified.`,
    );
    this.name = "DiskFullError";
    this.path = path;
    this.freeBytes = freeBytes;
    this.minFreeBytes = minFreeBytes;
  }
}

export interface OpenDbOptions {
  /** Absolute path to the SQLite file (parent dir must exist). */
  path: string;
  /** When false, opens read-only. */
  readwrite?: boolean;
  /** Override the disk-full safety threshold (bytes). */
  minFreeBytes?: number;
}

/**
 * Run a free-space check against the filesystem holding `path`. Throws
 * DiskFullError if below threshold; otherwise returns free byte count.
 * Skips the check (returns Infinity) if statfsSync is unsupported on the
 * platform — better to allow writes than to crash a daemon on a kernel quirk.
 */
export function preflightDiskSpace(
  path: string,
  minFreeBytes: number = DEFAULT_MIN_FREE_BYTES,
): number {
  let stats: { bsize: number; bavail: number };
  try {
    stats = statfsSync(dirname(path));
  } catch {
    return Number.POSITIVE_INFINITY;
  }
  const free = Number(stats.bsize) * Number(stats.bavail);
  if (free < minFreeBytes) throw new DiskFullError(path, free, minFreeBytes);
  return free;
}

/**
 * Open the osstack state database, apply pragmas, and run pending migrations.
 * Caller owns the lifetime — pair every openDb() with a db.close() in shutdown.
 */
export function openDb(opts: OpenDbOptions): Database.Database {
  const { path, readwrite = true, minFreeBytes = DEFAULT_MIN_FREE_BYTES } = opts;
  if (readwrite) preflightDiskSpace(path, minFreeBytes);

  const db = new Database(path, { readonly: !readwrite });

  try {
    // Refuse an unsupported schema before changing journal mode or running DDL,
    // including read-only inspection. A failed open never escapes with a live handle.
    assertSupportedVersion(db.pragma("user_version", { simple: true }) as number);
    assertMigrationLineage(db);
    // Pragmas are applied per-connection in SQLite. Apply on every open.
    if (readwrite) db.pragma("journal_mode = WAL");
    db.pragma("synchronous = NORMAL");
    db.pragma(`cache_size = ${PAGE_CACHE_KIB}`);
    db.pragma("foreign_keys = ON");
    db.pragma("busy_timeout = 5000");

    if (readwrite) runMigrations(db);
    return db;
  } catch (error) {
    db.close();
    throw error;
  }
}

// This schema is table-additive. Derive expected table introductions once;
// a future DROP/RENAME migration must also update this lineage contract.
const tableIntroductions = MIGRATIONS.flatMap(migration =>
  [...migration.sql.matchAll(/^\s*CREATE\s+TABLE(?:\s+IF\s+NOT\s+EXISTS)?\s+([a-zA-Z_]\w*)\s*\(/gm)]
    .map(match => ({ name: match[1]!, version: migration.id })));

/** Reject pure or mixed unreleased Graph schemas before application pragmas or
 * DDL. SQLite may itself checkpoint an abandoned WAL on close; logical ledger
 * content and user_version must remain intact for the original binary. */
function assertMigrationLineage(db: Database.Database): void {
  const current = db.pragma("user_version", { simple: true }) as number;
  const actual = new Set((db.prepare("SELECT name FROM sqlite_master WHERE type='table'").all() as { name: string }[]).map(row => row.name));
  // Experimental Graph or Attention tables must never be migrated as released main.
  const experimentalTable = (name: string) => name.startsWith("graph_") || name.startsWith("attention_") || name === "daemon_owner";
  if (current < 25 && ![...actual].some(experimentalTable)) return;
  const expected = new Set(tableIntroductions.filter(table => table.version <= current).map(table => table.name));
  if ([...expected].some(name => !actual.has(name))
    || [...actual].some(name => experimentalTable(name) && !expected.has(name))) {
    throw new Error("GRAPH_EXPERIMENTAL_SCHEMA_CONFLICT: preserve this home and reconcile with its original build; do not reset user_version or reuse it for the integrated runtime");
  }
}

function assertSupportedVersion(current: number): void {
  if (current > CURRENT_SCHEMA_VERSION) {
    throw new Error(`Migration state inconsistent: user_version=${current}, expected=${CURRENT_SCHEMA_VERSION}`);
  }
}

/**
 * Apply pending migrations idempotently. `user_version` PRAGMA tracks progress.
 * The version pragma guarantees forward-only application. Many migrations
 * contain non-idempotent CREATE/ALTER statements; never reset user_version.
 */
export function runMigrations(db: Database.Database): void {
  const currentRow = db.pragma("user_version", { simple: true }) as number;
  let current = Number(currentRow);
  assertSupportedVersion(current);
  assertMigrationLineage(db);
  for (const m of MIGRATIONS) {
    if (m.id <= current) continue;
    db.exec("BEGIN");
    try {
      db.exec(m.sql);
      db.pragma(`user_version = ${m.id}`);
      db.exec("COMMIT");
      current = m.id;
    } catch (err) {
      db.exec("ROLLBACK");
      throw err;
    }
  }
  if (current !== CURRENT_SCHEMA_VERSION) {
    throw new Error(
      `Migration state inconsistent: user_version=${current}, expected=${CURRENT_SCHEMA_VERSION}`,
    );
  }
}

/**
 * Run a function inside a transaction with preflight. Use for any write path
 * called from the daemon hot loop. Wraps better-sqlite3's transaction() so
 * disk-space errors fire BEFORE BEGIN, not mid-transaction.
 */
export function withWrite<T>(
  db: Database.Database,
  path: string,
  fn: (db: Database.Database) => T,
  minFreeBytes: number = DEFAULT_MIN_FREE_BYTES,
): T {
  preflightDiskSpace(path, minFreeBytes);
  const tx = db.transaction(fn);
  return tx(db);
}
