# Claude Sonnet 5.5 审计与处置

实际调用 `claude-sonnet-5-5`，只读审查完整脚本、测试与方法材料，无嵌套执行权限。首轮候选 `9b29a027b8d7f4b1074b7df8ae7f28bf85715707` 结论 REVISE；原始输入、输出、模型使用信息、SHA 绑定和失败测试均保留于交付归档。审计不是独立验收身份或运行时资格。

| 问题 | 处置 |
|---|---|
| F1 packages 杂项普通文件导致绑定失败 | 跳过非目录，符号链接仍拒绝；新增真实目录反例 |
| F2 断言细节被 ERR_ASSERTION 覆盖 | 保留 actual/expected/operator/message，单独记录 invocations 阶段及数量 |
| F3 未持久记录自有进程 | fork 后保留 PID/启动观察，cleanup 区分未启动与未确认退出；PID 本身不构成后续 signal 授权 |
| F4 脱敏测试不足及截断顺序 | 序列化前递归清理字符串；有界流保留跨块 token 前缀，脱敏后截断；磁盘字节反例 |
| F5 测试名称外推完整失败旅程 | 重命名并明确仅组件级失败测试，不冒充完整 cleanup 故障实跑 |
| L4 证据写失败丢业务观察 | stderr 错误回执继续保留已观察结果与 evidence 位置 |
| L6 外层测试超时短于被测运行 | 外层预算增至150秒，覆盖90秒运行与收尾 |

复查还纠正了新增 PID 记录的异步写入可能先于 ready 监听注册的问题：先注册监听，再持久化启动观察。来源 daemon 是当前源码打包，CLI 使用 dist；同时记录两者不代表陈旧 dist 已重新构建，使用说明已明确。

L1（exit/close尾部诊断）、L2（二次中断）、L3（ready 后 IPC error）保留为后续进程生命周期加固项，首轮审计标为非阻塞；当前不声称 runner 被强制杀死后的孤儿进程恢复资格。L5 的凭据不继承字段来自明确白名单，已有环境隔离测试，不改为额外扫描宿主秘密。其余可选建议没有扩入本批。

最终复审与候选验证结论见 delivery.json；首轮 REVISE 不会被覆盖。
