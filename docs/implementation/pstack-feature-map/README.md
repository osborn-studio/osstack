# Offline feature-map selector: bounded W18 delivery

Implemented and locally validated; [PR311](https://github.com/osborn-studio/osstack/pull/311) is Draft/main and publication CI is evaluated separately. Final code commit `5b730756` follows full-regression candidate `9e37bfa0`. No full W18/C0 acceptance or user stage sign-off is asserted.

## What this delivers

A callable, offline selector ranks only local index metadata through the existing public `searchKnowledgePacks` BM25 export. It opens selected leaf bodies after ranking and expands required dependencies. Three actual CLI task leaves describe fixed-five map maintenance, the full skills-check journey, and retained-evidence packet projection/checking. Packet requires journey material; maintenance need not load the whole library. No referenced product command runs merely because its leaf is returned.

The result preserves query/dependency reasons, omitted scope, content hashes, caller-reported freshness/prerequisites, unassigned maintenance ownership and unverified coverage. Local closed formats and bounded regular-file reads reject invalid paths, cycles, missing required leaves, content changes and excess budgets. Empty evidence stays draft; execution remains not_run. This is not a protocol/admission change or a new method/host/runtime permission.

Read [the user instructions](../../verification/features/README.md) for the actual selector and the separately authorized drive recipes. Every source/driver pin identifies actual named file bytes, not arbitrary Git freshness or complete transitive build provenance. This independent expression retains pstack/poteto attribution and Lauren Tan's MIT license pin in the user README.
