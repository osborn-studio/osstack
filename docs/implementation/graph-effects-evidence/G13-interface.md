# G13 interface (implementation in progress)

Protocol exports from @osstack/protocol: GraphCheckpointRequest / GraphCheckpointResponse (Zod schemas + inferred types), GraphCheckpointTransport = (request: GraphCheckpointRequest) => Promise<GraphCheckpointResponse>; parseGraphCheckpointRequest/Response enforce full JSON wire byte cap (8 MiB) before schema validation. Transport must cap raw frame before JSON.parse.

Request is a strict discriminated union: {kind:'get', threadId, namespace, checkpointId?}; {kind:'list', threadId, namespace?, checkpointId?, before?, cursor?:{namespace,checkpointId}, pageSize}; {kind:'put', requestId, threadId, namespace, checkpointId, parentCheckpointId?, checkpoint:string, metadata:string, newVersions:string}; {kind:'writes', requestId, threadId, namespace, checkpointId, taskId, writes:Array<{channel,index,value:string}>}. Opaque strings are bounded CheckpointCodec UTF-8 wire (1 MiB each). No worker scope/owner/generation/revision/identity fields. Reserved negative indexes follow SDK public WRITES_IDX_MAP; ordinary indexes are batch positions. Filter is applied by remote saver to decoded metadata across ALL pages; limit counts matching tuples.

Response: {kind:'get',tuple:GraphCheckpointTupleWire|null}; {kind:'list',tuples:GraphCheckpointTupleWire[],cursor?:{namespace,checkpointId}}; {kind:'put',checkpointId}; {kind:'writes'}. Tuple: {threadId,namespace,checkpointId,parentCheckpointId?,checkpoint,metadata,newVersions,pendingWrites:Array<{taskId,channel,index,value}>}. List order checkpointId DESC then namespace DESC; cursor binds exact pair; namespace omitted means all namespaces of bound run ONLY.

Core planned signature: new GraphCheckpointStore(db); store.execute(fence: GraphRunFence, request: GraphCheckpointRequest): {run:GraphRun,response:GraphCheckpointResponse}. ThreadId must equal fence.graphRunId. Every read/write starts shared G11 BEGIN IMMEDIATE fenced transaction. Host serializes concurrent requests, refreshes fence from current run under transaction (never accepts worker fence), and adopts returned run after writes. Request IDs stable for transport retry; changed payload same ID conflicts; generation/owner/identity/revision/live lease checked before cache. ACK is only returned after commit. Fixed authenticated closure must bind scope/run/program/generation/owner; refresh revision only, never upgrade old worker generation. G12 parent wires authenticated checkpoint port; graph package never imports core.

Remote public export @osstack/graph/checkpointer: new RemoteCheckpointSaver(threadId: string, transport: GraphCheckpointTransport). Constructor transport is trusted bound closure. No destructive deleteThread; explicitly rejects. No automatic retry of unknown transport failures: transport may retry EXACT request object/id. Engine caller retry may generate a new ID; storage semantics remain idempotent for immutable checkpoint and pending-write indices.
