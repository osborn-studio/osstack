# Actual Codex and Claude use

This is a bounded host-assisted workflow: models selected fixed case IDs from supplied expectations; a root-owned runner executed four real product cases, then each model interpreted its own receipts. No model-generated command text was executed. There were exactly two model calls per host and no retries. This is not an autonomous-tool-use or causal-benefit experiment.

Both hosts received the same method/plan bytes in phase1. Planning referenced a0be527a. Before execution, independent review found the symlink entry bug; root repaired R1–R3 and executed candidate4f6c3c8f. Phase2 explicitly disclosed this candidate transition. Historical planning was not relabeled as planning against the new SHA. The method materials are bound by the input manifest; this does not establish that every proposed method revision is validated.

Each host had its own healthy and missing-ref fixture. All four driver runs returned0, while real product exits were respectively0 and1. Root recomputed each evidence manifest, confirmed raw stdout matched retained receipt bytes, checked selected cases and observed fixture absence. Source/build identities refer to execution-time files; tracked generated knowledge/dist outputs were subsequently restored for publication. They are not a reproducible-build certificate.

## Preserved failures and limits

The first Claude selection had seven limitations. The v2 validator rejected it because an undisclosed format rule allowed at most five. Root identified this as a harness defect: v3 raised only this count limit to ten and exposed it in the prompt specification. Exact original responses were revalidated without changing their contents or making another model call. Case IDs, expected product exits, allowed fields, per-string and total-size bounds stayed unchanged. The original v2 rejection remains a failure record; the v3 result is a posthoc harness repair, not a retroactive clean experiment.

Both final interpretations correctly distinguished a passed missing-ref verification from recovery of the missing source. Both refused to promote direct child exit and fixture removal into proof that all descendants had terminated. That conservatism matches the declared limit. Claude exceeded the prescribed500-word final-response budget; retain it as unmet format criterion, not an all-criteria PASS.

Codex used actual CLI0.160.1; the exact model was unavailable in the observed metadata. Claude used actual CLI2.1.291 and response modelUsage identifies claude-sonnet-5-5. Both phases had zero observed tool calls. No model version is inferred from a requested name alone. Only healthy and missing-ref were exercised for host assistance; independent script testing covers the other cases separately.
