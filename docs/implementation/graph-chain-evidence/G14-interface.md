# G14 proposed integration contract (2026-09-14)
Ownership: CLI graph-worker-manager.ts + test; graph worker-entry.ts + existing tests, narrowly named worker-runtime.ts/client.ts as needed; protocol graph-worker.ts + test, explicit index/generate/schema additions. No daemon/core/broker/checkpoint/doc/status edits.

GraphWorkerManager({programs, workerEntry?, executable?, heartbeatTimeoutMs?, shutdownTimeoutMs?, terminationTimeoutMs?, maxInFlight?, maxLogBytes?}). programs: trusted registrations {id,modulePath,digest}; digest = SHA256 of exact self-contained ESM source bytes, equal identity.compiledProgramDigest. Registration snapshots bytes; child imports those exact bytes via data URL, never worker-selected paths. Program exports async run(context); runtime wraps with public Functional entrypoint + RemoteCheckpointSaver + durability:sync. context = {action(request),checkpoint,signal,input,resume?,task}; task is installed public Functional task API; self-contained program source uses this instead of unverified imports. No full compiler.

start({binding:{scope,graphRunId,generation,owner,identity},programId,input:StartGraphRequest,resume?,authorize:()=>{leaseExpiresAt:number},register:(connection,binding)=>void,action:(connection,request,{signal})=>Promise<WorkerActionResponse>,checkpoint:(connection,request)=>Promise<GraphCheckpointResponse>}) returns handle immediately with connection, binding, ready Promise<void>, result Promise<JSON>, exit Promise<GraphWorkerExitEvidence>, cancel(reason?),stop(reason?), logs(). register is synchronous before init reaches child; parent dynamically registers both existing ports there. authorize must synchronously check current durable full identity/generation/owner/revocation and return current lease expiry; manager also checks expiry. Runs are reserved synchronously before spawning. Replacement requires observed old child exit, higher generation, same immutable scope/run/program/input. No automatic lease acquisition or renewal and no broker resource release.

IPC: dedicated fd3 duplex framing (4-byte big-endian length), raw cap before body allocation/JSON.parse; stdout/stderr drained into bounded separate tails. Bounded outstanding RPCs and outbound writable buffer; no unbounded pending queue. Envelopes bind exact full identity. Per-worker abort signal reaches action callback. Cancel/revoke/expiry/heartbeat stops new work immediately; graceful deadline -> SIGTERM -> SIGKILL, bounded evidence timeout returns unconfirmed (never fabricated exit). Actual ChildProcess exit event is evidence; close is not awaited (inherited pipes). Spawn/early exit settles all promises with attached internal rejection handlers.

Parent requirements: persist/verify real worker exit evidence before GraphRunStore stoppedWorker receipt; independently stop/reconcile broker executor and isolate workspace before takeover. authorize callback must inspect durable fence for every request and after awaits. Existing GraphRunStore cannot yet cancel pre-worker or clean expired owner without evidence: parent owns any required mutation. No second FSM added here.

Implementation follow-up: exact context additionally exposes `binding`; options additionally expose separate `startupTimeoutMs` (default10000) so heartbeats cannot prolong handshake forever. Public package worker resolution uses ESM import.meta.resolve (not require.resolve). Final contracts, integration requests, test results and limitations are in G14-handoff.md.
