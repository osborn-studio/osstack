# G16 interface (pre-implementation)

Core graph/artifact-store.ts exports GraphArtifactStore, GraphFreezeInput, GraphFreezeAuthority, GraphArtifactManifest.

new GraphArtifactStore(absolutePrivateRoot)
freeze(input, authority): Promise<protocol candidate_ready>
verify(artifactDigest): Promise<GraphArtifactManifest>
restore(artifactDigest, { rootPath, directoryName }): Promise<{worktreePath,candidateRevision,tree}>

GraphFreezeInput = { artifactId, scope: GraphScope, runId, generation, owner, workspaceLeaseRef, repoId, commonDir, worktreePath, baseRevision, implementationReceiptRef, producerStopEvidenceRef }.
All fields are supplied by trusted host registration/ledger, NEVER copied from worker paths/booleans. Exact input is immutable, hashed and bound to artifactId. baseRevision is exact expected current HEAD. Capture uses raw worktree bytes (tracked plus untracked nonignored), preserves executable/symlink/deletion/binary semantics, rejects submodules/nested repositories and shallow sources. Candidate has baseRevision as parent, but neither source index/refs nor published branches are changed. Full reachable history is exported.

GraphFreezeAuthority = { lease: object, verifyLease(input, lease), verifyImplementationReceipt(input), verifyProducersStopped(input) }. Every callback is mandatory, may resolve asynchronously, MUST resolve undefined, and must throw on denied/stale/unknown. Lease is the already-held canonical G10 action lease, never nested acquisition; host verifies object identity, writer/canonical repo scope, generation/owner and live authority. Receipt verifier checks actual persisted successful implementation and its exact workspace/run scope. Stop verifier resolves ALL independent producer receipts and rejects incomplete/unknown evidence. Rechecked before capture, before durable publication, and after durable publication before returning ready; no bool stopped accepted. Host holds lease throughout and prevents new producers until freeze returns. This service cannot authenticate an arbitrary host callback; callbacks are process-local trusted capabilities. Input is deep snapshotted before await.

Disk layout: content-addressed immutable manifest + self-contained candidate.bundle; atomically published artifact directory and artifactId binding, fsynced files and directories where supported. Replay requires identical input and source tree and verifies saved bundle. Corruption fails closed. verify/restore use digest pinning and a fresh object database with fsck; original repo, worktree and all original objects may be deleted. No automatic artifact GC. Restore exclusively creates one exact child of canonical existing root and refuses existing, symlink, traversal destinations.

Agents worktree.ts adds graphRetention?: { runId, scopeKey, generation, workspaceLeaseRef } to CreateWorktreeOptions. Before allocation, persist immutable retention record in canonical git common dir keyed by exact worktree path; lock created git worktree. Generic cleanupWorktree and cleanupOrphanedWorktrees always preserve any recorded graph worktree (including damaged metadata: fail closed). Record survives module/process restart, is outside worker checkout, and is never cleared by finally. quarantineGraphWorktree(handle, reason) adds durable quarantine metadata; it does not kill producers or invent evidence. cleanupGraphWorktree(handle, { artifactDigest, verifySafe }) is the only explicit bypass: trusted verifier must re-resolve all producer stop evidence, validate durable exported artifact and canonical G10 ownership for the exact immutable retention record and digest; must resolve undefined. Retention stays conservative even if freeze fails. No automatic artifact GC.

Parent edits: add lazy-accessible core artifact-store export/package boundary and agents named exports as needed. No SQL migration needed: immutable disk artifacts/retention are not a scheduler and need no DB table. Parent owns broker freeze registration, concrete authority/evidence resolvers, lease hold/recheck lifecycle, retention-before-producer allocation, and record candidate_ready only after freeze returns. No other producer of candidate_ready. Parent may call core restore then register fresh restored workspace with retention before allowing any producer. No changes to daemon/broker, migrations, package exports, G14/G15, statuses or docs in this task.

Implementation clarification: store parent and restore root must exist; the current implementation supports non-shallow SHA1 repositories and UTF-8 filenames. The result and refs are deeply frozen. Restore creates an independent repository, then parent registers canonical identity and retention before executing producers. Crash-stale ID locks fail closed; verify/restore remain available. Detailed final guarantees and limits are in G16-handoff.md.
