Add host-side git hardening and safe file writes for the contained Mission path (M3). `runHardenedGit` runs git from an argv array with no shell, a minimal environment (PATH, HOME, LANG/LC_*; every ambient `GIT_*` stripped; system and global config disabled; replace objects off), a fixed `core.hooksPath`/`core.fsmonitor`/`core.attributesFile` override, bounded output, a timeout and an AbortSignal. `inspectRepoConfig` reads repository-scoped config with includes expanded, returns a canonical digest and stable rejection codes for keys that run programs or change transport; `assertRepoConfigUnchanged` re-checks the digest. `createNoCheckoutWorktree` adds a worktree with no checkout and materializes the start commit's blobs host-side (symlinks, submodules and unsafe paths rejected, exec bits kept, index refreshed so status is clean). `commitPlumbing` commits explicit paths with hash-object/update-index/write-tree/commit-tree and a compare-and-swap `update-ref`, never running filters or hooks. `safeWriteFile`/`safeRemoveFile`/`safeReadFile` refuse symlinked components, symlink and hard-link targets, and write via fsynced same-directory temp files verified by sha256. Existing Loop worktree helpers are unchanged.
